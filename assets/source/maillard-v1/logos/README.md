## 권리·사용 조건

Twitch 및 Glitch는 Twitch Interactive, Inc.의 브랜드이고, 치지직/CHZZK는 NAVER의 브랜드이며, SOOP는 주식회사 숲의 브랜드입니다. 로고·상표의 권리는 각 권리자에게 있습니다. 이 프로젝트 또는 생성 이미지에 대한 후원·제휴·승인을 뜻하지 않습니다.

공식 파일 다운로드 가능 여부와 게임 공개 배포 허가는 별개입니다. 이 수집 작업에서 외부 사용 허가를 취득하지 않았습니다.

- 네이버 공식 안내는 로고의 임의 형태·색상 변형, 제휴 등으로 오인시키는 사용, 상업적 사용을 금지한다고 명시합니다. 실제 사용 전 위 안내를 확인해야 합니다.
- [SOOP 브랜드 가이드](https://res.sooplive.com/policy/contents/brand_guide.html)는 플랫폼 외부 브랜드 이용에 명시적 서면 동의가 필요하다고 안내합니다. 공개 게임에 원본/변형 로고를 사용하려면 해당 조건을 별도로 확인해야 합니다.
- Twitch 로고 사용 조건은 공식 브랜드 패키지의 가이드와 [Twitch 상표 가이드](https://www.twitch.tv/p/en/legal/trademark/)를 확인해야 합니다.

`assets/source/`는 기존 배포 패키저의 원본 제외 대상입니다. 원본 참고 파일 확보가 런타임 반영 또는 배포 승인까지 완료했다는 뜻은 아닙니다.
