기준 PNG는 기존 v2와 동일하며, 네 프레임 모두 셀 x≥70 RGBA 변경0픽셀이다. 몸·얼굴·포즈·망토는 보존됐다. 비교 이미지에서 깃대 연결부 손상·망토 잘림·셀 경계 접촉은 없다. 가시 변경1909/2109/2007/1936픽셀로 metadata와 일치한다. 192셀2×2,피벗[138,180],시간380/260/380/260ms 유지. 검수 시점 실제 runtime PNG는 기존 v2로, 후보는 미통합 상태다. 이는 사용자 최종 외형 승인과 별개다.
