# 청소부 코사크 대기 춤 v5

사용자 후속: 태극기 망토·붉은 삼각 천 깃발이 더 분명히 펄럭이고 코사크 대기가 정적으로 보이지 않게 한다. 기존 v4 얼굴·검정 눈썹·안경·큰 코·입 없음·붉은 두건과 셔츠·짧은 다리·좁은 허리를 유지한다. 서기·웃음·공격은 수정하지 않는다.

Codex 내장 imagegen2회: `prompt.txt`로8프레임 생성(`initial-raw.png`), `cape-edit-prompt.txt`로 태극 망토 파동만 강조한 후속 수정(`raw.png`). 정확한 백엔드 모델 ID/요금은 미제공이다. 최초안은 붉은 깃발과 다리는 움직였지만 흰 망토 실루엣이 약해 후속안으로 대체됐다. 참조는 v4깃발 수정 원본과 `references/anchor-2cols-4rows.png`이며, 가이드는 기준 중립 프레임을 make_anchor_layout.py로 반복한 것뿐이다.

Runtime: `assets/battle/janitor-hero-idle.png`,384×768 RGBA,192px셀2열4행,행 우선8프레임,피벗[138,180]. 프레임 시간은100/120/280/140/100/120/280/140ms로 총1.28초다. 접기→발차기 진입→유지→회수, 반대쪽 동작의2주기다. 짧은 다리의 접기/차기는 명확하나 작은3/4시점에서 해부학적으로 왼발/오른발이라는 식별은 제한적이다.

`export.py`는 원본 알파240미만 주변광만 제거하고 남은 알파를255로 고정한다. RGB/포즈/천 주름을 새로 그리지 않고 전체 공통0.37배율 NEAREST와 몸 기준점 정렬만 적용한다. 프레임별 bbox 확대/축소는 없다. 몸 키 약75.48~79.92px(원래약77~79px), 자연스러운 접기 차이는 유지한다. 별도의 게임 표시 배율은 이 PNG에 굽지 않았다.

원래 크기 비교 `preview-native.png`, 확대 `preview-2x.png`, 이전 몸 크기 대조 `before-after.png`, 루프 `dance.gif`를 확인했다. 흰 망토 바깥끝의 x위치는 측정영역에서45~71px로 변화하며 말림/늘어남이 보이고, 붉은 천의 자유 끝도 크게 오르내린다. 알파는0/255,8프레임 모두 원본/출력 경계 접촉 없음. 모든 출력 bbox는 `metadata.json`에 기록한다.

부모 담당이 확대 시트와 이전 비교를 보고 외형/동작을 확인한 후 runtime 적용을 승인했다. 독립 검수는 모든8장 차이·망토/깃발 펄럭임·정체성·투명도·크기·시간을 확인했으며, 작은 화면의 좌우 발 구분은 위 한계로 남겼다. 실제 게임8프레임 재생·표시 배율은 통합 담당 검수 범위다.

재현: 저장소 루트에서 `uv run assets/source/janitor-hero-dance-v5/export.py` (runtime 대기PNG도 갱신).
