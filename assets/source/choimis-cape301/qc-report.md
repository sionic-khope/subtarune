# BUILD301 자산 검수

생성 원본3장과 최종12프레임 확대 시트를 직접 확인했다. 얼굴의 흰머리·눈썹·안경·코·치아 입·얼굴 점이 읽히고 대기4장의 망토 실루엣이 서로 다르다. 손 올림은 내림→가슴 앞→머리 위→hold 순서이며 쵸소는 손 준비→합장→전방 발사→후속 hold다. 쵸소2/3은 유사한 발사 자세의 hold 변형이며 네 개의 독립 공격이라고 주장하지 않는다.

모든 최종 셀은 실제 alpha0/255이며 빈 셀·셀 가장자리 접촉·잘림·paste clamp가 없다. 발 y152와 각 시트의 공통배율을 유지했다. 대기/손 올림은 하위10% 발 픽셀 중앙값72, 쵸소는 양발 범위 중앙72 근처(반픽셀 반올림 포함)다. 쵸소의 기존 중앙값 정렬로 생긴0→1 머리 좌우 점프를 양발 범위 중앙으로 교정하고 최종 확대 시트를 다시 확인했다.

이전 runtime 보존본과 새 대기의 표시 크기 비교는71.346px→99.96px, +40.106%다. 새 자산에 세로 늘이기를 적용하지 않았다. 160셀/피벗80의 최초 시도는 대기2의 망토 초과로 exporter assertion에서 거절됐고, 공통피벗72로 옮긴 최종본이 같은 경계 검사에서 통과했다.

재현 스크립트4개의 Python 문법 검사와 programming no-excuse 검사 통과. 이미지 export를 직접 실행해 PNG/프레임/QC/GIF를 얻었다. exporter3개는 cape295 재사용의 단일 자산 변환 책임, runtime-comparison은 표시 배율 비교 책임이다. 타입 우회·새 프레임워크·의미 없는 테스트를 추가하지 않았다. 로컬 LSP 훅은 작업 호출 cwd 밖 경로를 거절했으므로 Python 문법 검사로 별도 확인했다.

검수 범위는 자산과 연결 좌표까지다. 게임 전체 검사나 브라우저 실제 동작 검증은 수행하지 않았으며 독립 검수와 사용자 승인도 별도다.
