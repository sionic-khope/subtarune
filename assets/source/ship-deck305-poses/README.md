# BUILD305 · 갑판 주먹 동작

형섭·경섭·빠맨의 기존 걷기 외형을 참조한4프레임 동작이다. 각 캐릭터 원본은 내장 `image_gen`으로1회씩 생성했다. 실제 모델 ID와 비용은 공개되지 않아 unknown이다. 원본은 캐릭터별 `raw-sheet.png`, 정확한 생성 지시는 이 폴더의 `<이름>-prompt.txt`에 보존한다.

## 런타임 계약

| 캐릭터 | 파일 | 공통 원본→출력 배율 | 걷기 기준 높이 | 실제 출력 본체 높이 |
| --- | --- | --- | --- | --- |
| 형섭 | `assets/sprites/hyungsub-deck-fist.png` | 100/467 | 100px | 100/100/100/100px |
| 경섭 | `assets/sprites/gyeongsub-deck-fist.png` | 99/476 | 99px | 98/98/99/99px |
| 빠맨 | `assets/sprites/ppaman-deck-fist.png` | 95/484 | 95px | 96/95/96/96px |

모두512×128 RGBA, 가로4프레임, 셀128×128, 공통 발 피벗 `(64,120)`이다. 순서는 원본2×2의 좌상→우상→좌하→우하: 중립→팔꿈치 굽힘→주먹 모으기→주먹 내밀어 유지. 런타임 배율0.5로 걷기와 동일한 몸 크기를 쓴다. 실제 발 중앙은63.5~64.5px의 격자 반올림 범위이며 본체 하단 exclusive y120이다. GIF 검수 시간220/180/180/420ms는 실제 장면의 타이밍 계약과 별개다.

걷기 높이는 현재 `assets/sprites/<이름>.png`의 정면0번 실제 알파 bbox에서 측정했다. 캐릭터별 공통 배율 하나를 모든 포즈에 적용했으며 프레임별 bbox 맞춤 확대·축소는 하지 않았다.1px 높이 차이는 최근접 정수 격자 샘플링과 원본 포즈 차이로 남겼다.

## 알파와 추출

원본의 RGBA 값을 그대로 보존한다. 알파128 기준은 본체 bbox와 신발 기준점 측정에만 사용하며 출력 알파를 이진화하지 않는다. 각 본체 bbox 주변에 원본32px의 여백을 포함해 crop한 뒤 최근접 축소·정수 이동만 수행한다. crop 바깥의 희미한 배경 픽셀만 제외했으며 alpha≥128 본체 픽셀은 한 개도 잘리지 않았다. 프레임별 제외된 낮은 알파 픽셀 수와 정확한 원본 사각형은 각 `qc.json`에 기록했다. 팔레트 양자화·색 보정·수작업 그리기는 없다.

형섭·경섭 원본은1230×1278, 빠맨은1237×1271이며 원본 홀수 크기의 사분면 경계는 반올림 좌표로 분리한다. 어떤 원본 열·행도 누락하지 않는다. 원본 도구 저장 위치는 다음과 같으며 이 폴더의 보존본 SHA-256을 `qc.json`에 기록했다.

- 형섭: `exec-4eefa8c7-2a96-4d28-833c-6b05689bcef2.png`
- 경섭: `exec-928d2b39-44b5-46cf-80ee-1440d736b958.png`
- 빠맨: `exec-4972330f-c8cf-46ff-b181-00cccdfdffab.png`

보존 원본은 이 디렉터리의 캐릭터별 `raw-sheet.png`이며, 아래 식별자는 내장 이미지 생성 결과를 추적한다.

## 재현·검수

```sh
uv run assets/source/ship-deck305-poses/export.py
```

캐릭터별 `sheet-transparent.png`, `frame-0.png`~`frame-3.png`, `preview-3x.png`, `animation-preview-3x.gif`, `qc.json`을 제공한다. `walk-comparison-1x.png` 및 확대본은 현재 걷기0번과4개 새 포즈를 같은 발 높이에서 비교한다. GIF만 포맷 특성상 색상 인덱싱을 수행하며 런타임 PNG는 원본 RGBA 샘플을 보존한다.

검증 결과: 세 시트 각각512×128·서로 다른4프레임.12프레임 모두 출력 경계 알파0, clamp0, alpha≥128 원본 픽셀 crop 손실0. 별도 검사에서 모든 출력 이미지 부분을 원본 crop→NEAREST 결과와 바이트 단위 비교해 RGBA 일치를 확인했다. 실제 출력 알파 수준은 형섭204종·경섭235종·빠맨215종으로 원본의 반투명도를 유지한다. 추출 실행 성공, Python 규칙 검사 위반0. 장면 등록·재생·최종 사용자 승인은 통합 담당의 검수에 따른다.
