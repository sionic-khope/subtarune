# 영클 TV 정지 일러스트 140

현재 채택한 내장 이미지 생성 원본은 `exec-7ae486d9-89a8-4542-adb7-1cb19e02bc83.png`이며1774×887 RGB `raw-sheet.png`로 보존했다. 최신 사용자 요청에 맞춰 거친 도트 질감, 큰 머리, 짓궂은 표정과 치아, 더 가는 몸통·팔·손을 가진 정지 장면9종이다. 이전 원본은 `raw-draft1.png`(첫6장), `raw-draft2.png`(부드러운 표정 수정6장), `raw-draft3.png`(몸을 가늘게 하기 전 도트9장)에 보존했다.

장면 순서는 smirk(소용돌이), laugh(ㅋ), greet(ㅎㅇ), oh(오), taunt(ㅋ), shrug(소용돌이), bye(ㅂ), yes(ㅇ), surprise(!)다. 서로 다른 구도·손동작·남색 실내 배경을 유지한다. 장면 파일은 `assets/illustrations/youngcle-tv-<표정>.png`, 대응 초상화는 `assets/portraits/youngcle_tv_<표정>.png`다. surprise는 후속 사용을 위해 준비한 표정이다.

## 추출 계약

- 장면: 불투명 RGB258×119, TV 안쪽 화면 크기와 같다. 원본 패널 전체를 NEAREST로128×64 논리 도트 이미지로 추출하고, 다시 NEAREST로238×119에 확대하여 `(10,0)`에 놓는다. 좌우10px는 RGB(12,24,48) 남색이다. 장면의 배경을 제거하거나 인물 바운딩박스로 크기를 다시 맞추지 않는다. 회전·프레임 애니메이션·코드로 그린 추가 그림은 없다.
- 실제 구분선에 맞춘 열 영역: `[0,590]`, `[592,1182]`, `[1184,1774]`. 행 영역: `[0,295]`, `[297,590]`, `[592,887]`. 끝 좌표는 제외 경계다. 패널 사이 구분선만 제외했다.
- 최종 처리 전체는 NEAREST만 사용한다. 색 평균·안티앨리어싱·팔레트 양자화는 없다. `logical-<표정>.png`는128×64 도트 원본이다.
- 초상화: 같은 장면의 얼굴을 긴 변43도트 이내로 NEAREST 축소하고48×48 논리 캔버스에 둔다. 얼굴 영역에서만 남색을 투명화하고 기존 `monoPortrait`와 같은 밝기0.38·흰 실루엣 외곽 규칙을 적용한 뒤, 정수2배로96×96 RGBA 파일을 만든다. 게임의48픽셀 격자와 정확히 맞아 눈 글자 안쪽의 작은 빈 공간을 보존한다. TV 장면에는 이 배경 제거·흑백 변환을 적용하지 않는다.

## 재현

```sh
uv run assets/source/youngcle140/export.py
```

위 스크립트가 보존된 원본에서 패널9장, 논리 도트9장, 최종 장면9장, 초상화9장, 검토용 합성 이미지와 `export-meta.json`을 만든다. 얼굴 자르기 영역·장면별 배율·남색 여백 위치는 스크립트와 메타데이터에 기록했다.

이 작업은 불투명 장면 전체의 추출이므로 마젠타 배경 제거·몸 바운딩박스 맞춤을 수행하는 스프라이트 처리기는 실행하지 않았다. 사용자의 전체 TV 장면 규격이 그 기본값보다 우선한다. 새 그림·포즈·배경은 후처리 코드로 만들지 않았다.
