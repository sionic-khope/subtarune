# 기념사진 카메라 (BUILD306)

내장 image_gen으로 새 정면 카메라 소품을 생성했다. 이미지 backend/usage/실청구액은 도구에서 제공하지 않아 unknown이다. 원본은 processed/raw-sheet.png, 게임 파일은 assets/props/ship-photo-camera.png (96×96 RGBA)다. 카메라 몸체·청록 렌즈·작은 플래시와 위쪽 매달림 부품이 있으며 환경/캐릭터/글자는 없다. 기존 소품을 덮어쓰지 않았다.

실제 프롬프트: Create ONE compact 2D pixel-art game prop sprite: a hovering old-fashioned still-photo camera lowered from the ceiling for a ship lounge group photograph. Front-facing, large readable round cyan glass lens facing the viewer, charcoal dark rectangular camera body with silver bevels, a small cream flash cube on top-left, tiny red shutter button on top-right, narrow dark suspension bracket at top. NO tripod, NO people, NO environment, NO cast shadow, NO text or logos. True crisp low-resolution 16-bit RPG pixel art with thick dark stepped outlines, few solid shade bands, chunky visible square pixels, not photorealistic or painterly. Compact recognizable silhouette suitable for reducing to roughly 48x40 game pixels. Entire camera inside central 65% of square canvas with ample margins. Background exactly uniform solid #FF00FF magenta for chroma key, no magenta in camera. One single asset only, no grid, no alternate views.

도구는 마젠타 대신 투명 배경을 반환했으며 알파를 보존했다. 상단 매달림 줄만 원본 위 끝에 연결되며 카메라 본체는 온전하다. 생성 스킬의 generate2dsprite.py process --target asset --mode single --rows 1 --cols 1 --cell-size 96 --single-size 96 --fit-scale 0.94 --align center --component-mode all로 최근접 축소/중앙정렬했다. 알파 bbox15,3..78,79; output-edge0, clamped0, empty0. 원본 상단 줄 접촉은 의도된 매달림으로 기록하며 strict-QC 합격이라고 주장하지 않는다. runtime은 한 장을 기존 slide로 하강/회수하고 셔터는 기존 photo_shutter를 재사용한다.
