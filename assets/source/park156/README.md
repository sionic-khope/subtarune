## Reproduction

```sh
uv run assets/source/park156/process.py
```

The main script processes the two action sheets, then runs `process-single.py` for the three single assets. An optional argument names the original `exec-*.png` directory when refreshing the preserved copies. Both scripts declare Pillow/Numpy dependencies inline. The installed standard processor must exist at `~/.codex/skills/generate2dsprite/scripts/generate2dsprite.py`.

Every asset first runs the standard `generate2dsprite.py process` pipeline. Its exact arguments, logs, cleaned source and QC metadata are saved under `<asset>/standard/`. Runtime files are resized from the cleaned source, not the standard interpolated thumbnail. Sprite geometry uses nearest-neighbor only; the two non-pixel illustrations intentionally use uniform LANCZOS to retain smooth cut-in/glass edges. Each `<asset>/runtime-contract.json` records actual output geometry and pivots.

## Alpha and framing boundaries

- Razma/judge are RGB magenta originals. Standard color-key cleanup plus a narrow low-green magenta fringe filter removes the background while retaining white hair and pink eyes/skull/bells. Final sprite alpha is binary.
- Sword is native RGBA. Its alpha is thresholded at128, with no color-key deletion. All gold/black artwork comes from the source.
- Glass is native RGBA. Only alpha below8 is cleared to discard near-invisible exterior specks; all other alpha values remain intact through resampling. Its pale pink rose is not color-keyed.
- Objection is RGB magenta. The standard key uses25color-distance/100connected-edge thresholds. It is not passed through the sprite hue filter or a binary-alpha postpass. Resizing creates smooth transparent edges while preserving the face's glasses, U-shaped nose and absent mouth.
- The objection standard run uses `--allow-source-edge-touch` solely for the generated source's hat/waist framing inspected by the main agent. The user has not separately approved this generated crop. Output edge contact and paste clamping remain forbidden. Other assets use strict QC without source-edge exceptions.
