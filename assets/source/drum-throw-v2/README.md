# 일반 흰 드럼통 투척음 보강 (BUILD252)

2026-09-20 사용자 “일반 흰 드럼통 던지는 소리가 약하고 마음에 안 듦, 조금 강렬하게” 반영. `assets/audio/sfx/drum_throw.mp3` 한 파일을 교체했다. 이전 버전은 `drum_throw_v1.mp3`로 보관한다. 충돌·보라 폭발·루드 버스터·BGM은 변경하지 않는다.

기존 DELTARUNE `wing.mp3`(snd_wing)의 공기 어택과 프로젝트 합성 `baron_slam.mp3`의 짧은 저음 몸통을 혼합했다. 새로운 합성·다운로드·목소리 생성은 없다. 원본 출처는 `design/audio/references.md`의 snd_wing·바론 육중한 몸통 타격 항목을 따른다. 게임 샘플 재배포 허가는 확인되지 않았다.

재현: `sh assets/source/drum-throw-v2/build.sh`. 이전 v1 전체 제작 스크립트도 투척음은 이 제작기로 위임한다.

- 공기층: wing을 0.90배 피치/속도, 앞 0.32초, 90–3200Hz, gain 2.0. 이전 1800Hz 저역통과보다 어택의 중역을 살린다.
- 몸통층: baron_slam 앞 0.24초, 45–420Hz, gain 0.35, 0.08초부터 0.16초 감쇠.
- 전체: 3ms 어택, 0.14초부터 0.18초 감쇠, peak limiter 0.56(자동 증폭 없음), MP3 q2, 44.1kHz 모노.

전체 디코드 오류 0, 클리핑 없음. 재생 gain 0.75·파형 묶음당 1회·쿨다운 0.25초를 유지할 것을 권장했다. 볼륨 추가 증폭 없이 파일의 어택과 저음만 보강한다. 현재 패턴은 보라 드럼통 발사에도 같은 키를 사용하므로 그 발사음도 바뀌지만 보라 착탄/폭발은 그대로다. 흰 드럼통만 다르게 연결할지는 패턴 담당 범위다.
