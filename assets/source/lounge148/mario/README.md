# 마리오 · 사용자 제공 원본 사용

최신 사용자 지시 “이거쓰면돼”에 따라 첨부 원본만 사용했다. 직접 도트 제작 계획은 중단했으며 새 그림이나4방향 애니메이션을 만들지 않았다. `reference.png`는 제공된400×400 RGBA 원본이다. 실제 알파가 있고 불투명 색은 빨강·황금색·올리브색3개다.

`tools/sprites/mini_mario148.py`는 투명 바깥 여백을 bbox50,0,350,400으로 자르고 NEAREST로42×56에 조정한 뒤64×64투명 캔버스의11,4에 놓는다. 원본 색과 알파를 보존하며 검정색 삭제·재색칠·외곽선 추가·팔레트 양자화는 하지 않는다. 소스와 결과의 RGBA색 집합이 정확히 같은지 검사한다.

런타임: `assets/sprites/mini_mario.png`, 단일64×64 PNG, 그림 bbox11,4,53,60, 피벗32,60. `stillScale:0.5`와 기존 CHAR_SCALE1.43일 때 실제 그림 높이56×0.5×1.43=40.04px다. 시트로 등록하지 않는다. 사용자 제공 옆모습1장이다.

재현: `uv run --with pillow --with numpy python tools/sprites/mini_mario148.py`.

`preview.png`를 직접 확인했다. 원본 모자·코·콧수염·옷·포즈가 유지됐으며 투명 여백만 정리됐다. 원본은 보존했다.
