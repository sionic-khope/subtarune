# 영클 · BUILD134 자산

내장 `image_gen` 두 번으로 이동 시트와 철제 크루즈 군함을 각각 생성했다. 스크립트는 배경 제거·프레임 추출·최근접 크기 조정·투명 PNG/GIF에만 사용했다.

사용자 원본: 스튜디오 `assets/references/youngcle134/original.png`. 영클은 큰 분홍 머리, 하나의 큰 흰 눈과 검정 눈동자, 붉은 볼·작은 빨간 입, 파란 셔츠·녹색 가슴 표시, 남색 반바지·검정 신발을 유지한다. 사용자 변경은 전체 갈색 머리를 없애고 **한 가닥 갈색 곱슬머리**로 바꾸는 것이다. 새 능력·대사·관계는 추가하지 않았다.

- `youngcle.png`: 최종 투명256×256,64×64셀,4열×4행. 행 down/up/left/right,열 기본/발A/기본/발B,150ms 권장. 이번 등장 장면에서는 캐릭터를 보여주지 않고 후속 작업용으로 보관한다.
- `youngcle-iron-cruise.png`: 최종 투명768×384,선수는 오른쪽. 알파 영역 `[8,28,759,356]`, 중앙 기준점 `[384,192]`, 최하단 기준 y356. 외눈 선수 장식·곡선 안테나·청색/은색 철판·다층 크루즈 갑판·포탑이다. 바다·연결다리·소유주 캐릭터는 이미지에 포함하지 않는다.
- `walk/`, `ship/`: 원본, 내장 생성 프롬프트, 처리 중간물과 자동QC. `walk/*-strip.png`, `walk/{down,up,left,right}.gif`는 최종 이동 PNG를 나눈 재생 미리보기다. `*-on-teal.png`는 알파 확인용이며 게임용으로 쓰지 않는다.

처리 계약: `generate2dsprite.py process`(Pillow+NumPy,uv)로 마젠타 제거. 걷기4×4,64셀,fit0.83,trim0,feet,shared-scale,largest,strict-QC; 군함1×1,768셀,fit0.98,trim0,center,largest,strict-QC. 기본trim4는 마지막 행 곱슬머리에 닿아 trim0으로 바꿨으며 원본은 자르지 않았다.

최종 걷기는 프로젝트 공통 샘플링 규칙에 따라 원본1254×1254에서313×313 고정셀을 추출하고, 각 방향4장에 동일한 공통영역과 NEAREST 샘플링을 적용했다. 행별 공통영역은 `[71,18,239,297]`, `[70,15,239,296]`, `[72,11,238,290]`, `[71,1,236,274]`; 모든 행의 공통 배율은0.18861209964412812,바닥 y59다. 개별 프레임마다 확대 배율을 바꾸지 않는다. 오른쪽/아래쪽 남은2px는 마젠타 여백이다.

최종 걷기의 마젠타 경계 잔여색을 결정론적으로 제거했다. 두 단계에서 알파가 있고 `(R>G+15,B>G+15,abs(R-B)<65)`인 픽셀, 이어 `(R>G+10,B>G+10,B>=0.7*R)`인 픽셀을 투명화했다. 분홍 피부와 붉은 볼은 유지된다.

군함 최종 추출: 제공된 처리기의 중간물은 LANCZOS를 쓰므로 런타임 PNG로 사용하지 않는다. `ship/raw-sheet-clean.png`의 동일한 원본영역 `[30,168,1508,817]`을752×330으로 한 번 NEAREST 축소하여768×384 캔버스 `(8,27)`에 배치했다. 원래 투명영역2px 이내에서만 `(R>G+10,B>G+10,B>=0.7*R)` 잔여1725픽셀을 투명화하고, `(R>G+4,B>G+4,B>=0.6*R)` 어두운 외곽694픽셀의 R을G로 낮췄다. 이어 투명영역8px 이내 난간/선수 경계에 남은 동일한 마젠타 조건196픽셀도 R만G로 낮췄다. 녹색·청색 철판과 분홍 볼 내부는 보존한다. 재생성·팔레트 양자화는 없다.

최종 군함 알파는0/255 두 값뿐이다: 완전투명158901,완전불투명136011,반투명0픽셀. 알파 영역은 `[8,28,759,356]`이며, 최종 경계8px 내 위 기준 마젠타 잔여는0이다. `warship-nearest-final-black.png`/`warship-nearest-final-teal.png`로 검정·청록 합성에서 곡선 안테나·난간·선수/선체 전체 경계를 확인했다. 소스 폴더의 이전 `single-1.png`/`sheet-transparent.png`/기존 합성 이미지는 처리 이력이며 런타임으로 쓰지 않는다.

QC: 이동16프레임 모두 유효, 생성원본·처리결과 셀 접촉0,붙여넣기 잘림0. 자동 body-scale CV0.03010,anchor-y std0.02641. 군함도 원본/출력 경계 접촉0,잘림0. 최종 투명 PNG를 청록 단색 배경에 합성하여 외눈·곱슬머리·상하좌우·피부/의상 색과 군함 전체 실루엣·마젠타 잔여 제거를 눈으로 확인했다. 실제 게임 등장 장면의 위치/타이밍/상호작용 검증은 게임 구현 담당의 몫이다.
