# 드럼통의 악마: 정장·긴 팔·긴 허리

사용자 교정: “정장입고있어야하고 더 팔길이 이런거 길이감 길어야해 허리도.”

내장 image_gen으로 생성한 master, idle, attack 원본과 정확한 프롬프트를 보존한다. 모델의 정확한 ID·요금·해상도 설정은 도구가 공개하지 않아 unknown이다. 정체성은 파란 가로 드럼통 머리, 날카로운 이빨, 검정 정장·흰 셔츠·검정 넥타이, 가늘고 긴 팔, 드럼통 전완과 긴 발톱, 길고 좁은 허리, 다리 없음이다.

## 재현

`uv run assets/source/drum-devil-v1/export.py`

1254×1254 RGBA 원본에서 각 몸체의 연결된 알파 성분을 분리한다. 명목상 627px 격자를 넘은 온전한 손을 자르지 않기 위한 분할이며 새 픽셀을 그리지 않는다. 10,000px 미만의 분리된 반투명 잡점만 제외한다. 원본의 몸체 알파와 색은 유지한다. 모든 8개 프레임은 0.34 공통 배율과 NEAREST를 사용하며 프레임별 bbox 맞춤 확대·축소는 하지 않는다. 허리 밑동을 수동 확인한 sourceRoot로 정렬한다.

최종 시트: 512×512, 2열×2행, 256×256 셀, 행 우선 0–3, 공통 피벗 **[148,238]**. 공격의 긴 왼쪽 뻗기를 보존하기 위해 피벗을 셀 가운데보다 오른쪽에 둔다. `field.png`는 idle 0과 동일하다. 대기는 220ms×4 loop. 공격은 준비180ms→최대 준비220ms→타격140ms→복귀260ms one-shot이며, 검수 GIF만 반복한다.

## 확인 결과와 한계

- 최종 PNG 8프레임을 눈으로 확인: 손·발톱·머리·허리가 모두 들어 있으며 정장과 긴 비율 유지.
- 최종 alpha bbox: 대기 약181–198×176–183px, 공격170–200×157–198px. 자세 차이는 보존한다.
- 최종 셀 경계 접촉 0, paste clamp 0. 가장 좁은 여백은 타격 왼쪽9px.
- 공격 머리가 대기보다 시각적으로 약8–10% 작아 보이는 생성 차이가 있으며 별도 프레임 배율로 보정하지 않았다.
- `preview-transparent.png`/`preview-dark.png`: 위 대기, 아래 공격. `yoplait-comparison-native.png`는 두 PNG의 원래 픽셀 배율 비교이며 게임의 캐릭터별 drawScale은 적용하지 않았다.
- PNG가 RGBA라는 것을 디코드 확인했고 원본의 실제 alpha를 사용했다. GIF만 형식 제약에 따른 팔레트화와 alpha128 이진 처리가 있다.
- exporter 실행 및 no-excuse 검사 통과. 자동 LSP는 이 linked worktree 경로를 cwd 외부로 인식하여 실행하지 못했다.
- 이 문서는 제작자 확인이다. 독립 검수·게임 표시 검수·사용자 승인은 별도다.
