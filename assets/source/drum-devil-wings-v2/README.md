# 드럼통의 악마: 검은 촉수 날개

요청: “드럼통 악마 등뒤 검은색 질감센 촉수 여러개 달아서 날개마냥 더 웅장하게.” 이전 정장·긴 팔·긴 허리 지시는 유지한다.

내장 image_gen 편집으로 생성했다. idle 참조는 `../drum-devil-v1/idle-raw.png`(정체성/자세), attack 참조는 새 idle 원본(정체성/도트/배율/촉수)와 `../drum-devil-v1/attack-raw.png`(공격 자세)이다. 정확한 프롬프트는 이 폴더의 `*-prompt.txt`, RGBA 원본은 `*-raw.png`이다. 모델의 정확한 ID·요금·품질 설정은 도구가 공개하지 않아 unknown이다. 이전 무촉수 결과는 v1 폴더에 보존한다.

## 재현과 런타임 계약

`uv run assets/source/drum-devil-wings-v2/export.py`

- 1254×1254 원본에서 알파가 1/255보다 큰 4개 대형 연결 성분을 추출한다. 거의 보이지 않는 alpha1 fringe가 이웃 포즈를 연결하므로 그 값만 분할에서 제외한다. 몸체 색·알파를 그대로 보존하고 새 픽셀을 그리지 않는다.
- 공통 NEAREST 배율 **0.44**, 8프레임 모두 동일하다. 프레임별 bbox 맞춤 확대·축소는 없다.
- 최종 시트 **768×768, 2×2, 384×384 셀**, 행 우선 0–3. 공통 허리 피벗 **[216,350]**. field PNG는 idle 0의 투명 여백만 XYWH **[72,116,272,240]**으로 자른 **272×240**, 피벗 **[144,234]**이다. 몸체 픽셀과 배율은 동일하며 `field-transparent.png`에 사본을 보관한다. 대화 중 전체 PNG 높이 제약을 만족시키기 위한 여백 crop이고 전투 시트는 변경하지 않는다.
- runtime 경로는 기존 `assets/enemies/drum-devil-{idle,attack,field}.png`를 교체한다. 기존 256셀이나 [148,238] 피벗으로 읽으면 안 된다.
- 대기 220ms×4 loop; 공격 준비180→최대 준비220→타격140→복귀260ms one-shot. 공격 GIF만 검수용으로 반복한다.
- 몸체가 날개 bbox 때문에 작아지지 않도록 출력 셀을 넓혔다. 머리 폭은 약61px(이전 약60px), 머리부터 허리까지 약178px(이전 약180px)로 눈으로 대조했다. 게임 drawScale은 기존 몸체 배율을 유지해야 한다. 캔버스 전체를 이전 256셀 표시 폭에 맞추면 몸체가 작아진다.

## 검수

최종 8프레임을 `preview-dark.png`/`preview-transparent.png`로 확인했다. 정장·흰 셔츠·넥타이와 파란 머리/전완 드럼통, 긴 팔·발톱·허리는 모두 유지된다. 여섯 개의 굵고 거친 검은 촉수가 등 뒤에서 부채꼴로 퍼지며, 얼굴과 셔츠가 앞에 보인다. 대기 촉수는 작은 굽힘, 공격은 몸체 타격에 따라 함께 기울어진다.

최종 출력 bbox는 대기 약256–262×223–235px, 공격251–267×216–238px이다. 경계 접촉과 paste clamp는 모두 0. 최소 여백은 타격 왼쪽34px이며 가장 낮은 fringe도 셀 하단까지30px 남는다. 허리 밑동의 sourceRoot는 원본 중앙 밑동의 실제 알파 하단을 측정해 기록했다. 자세 압축·상체 기울기는 보존한다.

PNG 원본 알파를 사용한다. GIF만 형식 제약 때문에 255색 및 alpha128 이진 처리를 한다. `yoplait-comparison-native.png`는 네이티브 PNG 픽셀 비교이며 런타임 캐릭터별 drawScale은 적용하지 않았다.
