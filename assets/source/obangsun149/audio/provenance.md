# 오방순 목소리 자산

사용자 방향은 낮고 두툼한 여성의 ‘흐에에에’다. macOS 기본 한국어 여성 TTS Yuna로 해당 발성만 합성했다. 첨부 사진 속 인물의 실제 음성이나 외부 녹음을 사용하지 않았으며, 특정 실존 인물의 목소리 복제가 아니다.

재현: 저장소 루트에서 `node tools/audio/obangsun149_voice.mjs`. Node와 ffmpeg/libmp3lame이 필요하다. 원본 AIFF가 있으면 재사용하고, 없으면 macOS `say -v Yuna -r 145`로 생성한다. BUILD148 럭키가이의 TTS→가공→정규화→MP3→반복 미리듣기 방식을 사용하며 기존 생성기의 측정 함수를 재사용한다.

음높이/속도0.74배(−5.21반음), 추가 템포0.94배, 65Hz 하이패스·3800Hz 로우패스, 250Hz 저음2dB 보강과 부드러운 압축을 적용했다. 모든 계수와 원본/결과 SHA256은 `manifest.json`에 있다. 첫 밝은 후보(0.84배)는 전달 전0.74배로 조정했다.

- `obangsun-yuna-hueee.aiff`: TTS 원본22050Hz 모노.
- `obangsun-full.wav`: 전체 발성, 0.97943초, 44100Hz 모노.
- `obangsun-source.wav`: 인코딩 전250ms 블립, 8ms 어택·35ms 릴리스, PCM16.
- `../../../audio/voices/obangsun.mp3`: 게임 전달 파일, 250ms, 44100Hz 모노, libmp3lame quality2.
- `obangsun-preview.wav`: 디코드된 블립을0.85게인·270ms 간격으로8회 반복한 청취용 파일.

측정: 디코드11025표본/250ms, peak0.28200(−10.99dBFS), RMS−18.02dBFS. 중간 모음75~125ms 구간의 자기상관 기반 기본음 추정은238.38Hz(상관0.9942)다. 전체 발성의 대표 음높이나 음색 선호를 확정하는 수치는 아니다. MP3 양끝 절댓값은0.00023미만으로 큰 경계 클릭이 없으며, 유한 표본·피크0.3미만 검사를 통과했다. `node --check`도 통과했다. LSP는 외부 worktree 경로 제한으로 실행되지 않았다.

추후 파일 음성 연결 제안: `rate:1, level:0.85, cut:false, minGap:0.27`. 합성 폴백이 필요하면 `freq:238, wave:'triangle', dur:0.25, jitter:3, gain:0.18, cutoff:1800`을 시작값으로 쓸 수 있으나 파일의 자연스러운 발성과 동일한 소리는 아니다. 이번 작업에서는 화자 키 등록·NPC 배치·대사를 추가하지 않았다.

자동 검증은 형식과 파형을 확인한 것이다. 음색의 최종 선호 확인은 Codex 내부 브라우저의 미리듣기에서 진행한다. 제작 중 외부 브라우저·시스템 오디오 자동 재생은 하지 않았다.
