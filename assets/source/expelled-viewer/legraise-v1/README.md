# 악질맨 누워서 다리 들기

2026-09-13 후속 연출용 4프레임. 같은 악질맨 원본을 참고해 `image_gen`으로 생성한 새 포즈이며 원본은 `raw-sheet.png`입니다. 포즈 순서는 두 다리를 낮게 들기 → 중간 → 수직에 가깝게 → 중간입니다.

## 런타임

- `assets/sprites/expelled-viewer-legraise.png`: 192×192, 96×96 셀, 2열×2행, 행 우선 4프레임.
- 공통 엔진 피벗 `[48,88]`, 실제 머리 중심은 약 `[24,68]`입니다.
- 고정 원본 배율 `0.14578352180936993`: 기존 reveal/crouch/knockdown과 같습니다. 포즈별 확대·몸통 왜곡·팔레트 양자화 없음.
- 각 셀에서 원본 머리 중심을 측정하여 같은 출력 위치로 평행 이동합니다. 다리 각도가 달라져도 포즈 전체 바운딩 박스로 가운데 정렬하지 않습니다.
- 등·팔 바닥은 출력 y=87–89 부근에 유지되며 프레임이 셀 밖으로 나가지 않습니다.
- 생성 원본의 세 번째 수직 자세는 골반·몸통이 다른 자세보다 약7–10출력 픽셀 더 뻗습니다. 머리를 고정하면 남는 원화 차이이며, 이를 숨기기 위한 부분 변형은 하지 않았습니다.

## 재현·검토

`pipeline-meta.json`은 제공된 generate2dsprite 처리기의 크로마키·컴포넌트·소스 QC입니다. 런타임은 기본 Lanczos 결과를 쓰지 않고, `export-runtime.py`가 정리된 원본에서 nearest-neighbor로 다시 출력합니다. 마젠타 혼색 잔여만 정리하며 검은 몸과 흰 윤곽을 보존합니다.

저장소 루트에서 `uv run assets/source/expelled-viewer/legraise-v1/export-runtime.py`로 재현합니다.

- `runtime-qc.json`: 원본 머리 기준점·고정 배율·평행 이동·프레임 바운딩 박스.
- `runtime-0.png`~`runtime-3.png`: 투명 개별 프레임.
- `contact-preview.png`: 네 포즈를4배 확대해 비교.
- `rooted-legraise.gif`: 180ms×4프레임 무한 반복, 검토용4배 확대. GIF는 미리보기일 뿐 게임은 투명 PNG를 씁니다.

기존 웅크림·등장·춤·쓰러짐 PNG는 수정하지 않았습니다. 이 폴더는 다리 들기 이미지와 재현 계약만 소유합니다.
