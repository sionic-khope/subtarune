# 청소부 히든 보스 (멸공의 깃발) 스프라이트·이펙트 (janitor-hidden)

요청: 델타룬 챕터4 제르손 전투(https://www.youtube.com/watch?v=hjIyeUT_mXc)를 패러디하는 히든 보스 “청소부”용 그림. 승인된 청소부 전투 그림(`assets/battle/janitor-hero-{idle,attack,stand}.png`, `assets/props/janitor-hero-flag.png`)과 같은 사람·도트·배율로 만든 발차기 몸 시트, 그리고 제르손식 순간이동 회오리, 초승달 휘두르기 궤적, 흰 별 탄환이다. 전부 **오른쪽을 봄**(적 쪽에서는 코드가 flipX). 이 폴더는 이미지 자산까지만 다룬다(ready, not integrated). 전투 코드 연결은 다른 담당이 한다.

`audio/` 는 다른 세션의 사운드 작업물이라 이 문서 범위가 아니다.

## 만든 방법

- 공급자/모델: OpenGateway `openai/gpt-image-2.5-sunburst`, quality high, `images/edits` 참조 1장. 4회 호출, 반려 0. 프롬프트·usage 는 `prompts.md`.
- 제르손 참고: `ref/gerson.mp4`(720p, yt-dlp)에서 61.7–63.4초를 잘라 `ref/frame-*.png` 를 만들었다(초승달 휘두르기 62.03초, 회오리 62.30–62.50초, 등껍질이 남기는 흰 별 62.60초). `refs.py` 가 이 프레임을 마젠타 위로 키잉해 모양 참조(`whirl-ref.png`, 좌우 반전 `slash-ref.png`, `star-ref.png`)를 만든다. 프롬프트는 모양만 따르고 색은 청소부 색(빨강·흰·남색)으로 바꾸게 했다. 발판(불릿 보드) 차기는 훑어본 구간에서 뚜렷한 장면을 찾지 못해 발차기 자세는 요청 문장과 공격 앵커로만 만들었다.
- 발차기 앵커: `kick-anchor.png` = 승인 `janitor-hero-attack.png` 0번(준비) 프레임을 3× NEAREST 로 768×512 셀 4칸에 같은 자리(발 기준 → 셀 [430,430])에 둔 것. gpt 가 셀 0(준비)을 앵커와 같은 bbox 로 다시 그려서 배율 3.0 이 그대로 맞다(스크립트가 ±6 raw px 안인지 검사한다).
- 축소: yongjun-sans `process2.py` 의 **블록 투표**(게임 픽셀마다 F×F raw 블록의 과반 알파·최빈 색 묶음·어두운 선 우선, 결과 색은 실제 raw 픽셀 중앙값)를 `process.py` 에 복사해 썼다. 각 raw 는 먼저 `tools/sprites/sheet_processor.py --strict-qc` 를 통과했고(`<이름>/standard/`), 그 `raw-sheet-clean.png` 가 픽셀 원본이다.
  - 발차기: 앵커 기하 그대로(F 3.0, 가로 위치는 공격 시트와 같은 좌표), 격자 위상 0/⅓/⅔ 탐색, 디딤발 맨 아래 행을 y 236 에 맞추는 정수 이동만(발차기 프레임 +10 px, gpt 가 그 칸을 30 raw px 높게 그림).
  - 이펙트: 효과마다 배율 하나·셀 기준 원점 하나·격자 위상 하나(프레임 사이 흔들림 없음). 회오리 F 4.409(어두운 선 규칙 끔: 남색 띠가 번지지 않게), 초승달 F 3.163(어두운 선 lum<90), 별 F 21.2(배율·위상 탐색, 블록 순도 0.891).
  - 정리: 마젠타 번짐 제거, 흰/회백 가장자리가 마젠타와 섞여 생긴 연분홍 픽셀은 같은 밝기의 차가운 회색으로(이펙트에만 해당, 발차기·별은 0개), 작은 떨어진 점 제거.
- 재현(저장소 루트): `uv run assets/source/janitor-hidden/refs.py` → (생성은 `prompts.md`) → `uv run assets/source/janitor-hidden/process.py kick whirl slash star preview`. 시험 실행은 `--no-export`(이 폴더에만 씀).

## 검수 (작성자 자체 확인, 사용자 승인 전)

- raw 4장과 export 4장을 모두 Read 로 확인했다. 최종 PNG 는 시그니처·크기·RGBA·이진 알파·마젠타 0·분홍 0·셀 경계 미접촉을 스크립트로 검사했다.
- `kick-compare-4x.png`: 승인 공격 0번 | 처리한 준비 셀 | 발차기 0 | 발차기 1 을 같은 크롭·같은 배율로 바닥선과 함께 놓았다. 준비 셀이 공격 0번과 같은 자리·같은 크기(알파 차이 79 px, 윤곽 잡음 수준). 두 발차기 프레임의 머리·안경·몸통 크기가 같고 디딤발이 같은 바닥선에 있다. 정체성 유지: 빨간 두건(뒤 리본), 둥근 안경, 검은 눈썹, 큰 U자 코, 입 없음, 수염 자국 점, 흰 깃 빨간 셔츠, 검은 반바지, 아주 짧은 다리, 흰 양말·검은 신, 태극기 망토, 갈색 깃대의 붉은 삼각 천 깃발.
- `kick.gif`: 공격 준비 → 준비(wind-up) → 발차기 → 준비 재생(같은 셀·피벗). 들기 → 차기가 읽힌다.
- `preview-2x.png`: 네 파일을 어두운 전투 배경과 밝은 배경에 1× 로 놓고 2× 확대.

## 알려진 한계

- 발차기 1번은 머리 꼭대기가 준비 자세보다 5 px 높다(바닥~두건 81 px, 공격 시트 76 px). 디딤다리를 펴고 선 자세 차이다. 머리·몸통 크기는 6× 나란히 보기에서 같다.
- 요청 문장은 “흰 수염”이었지만 승인된 청소부 그림에는 수염이 없고 검은 수염 자국 점과 입 없음이다. 승인 그림대로 유지했다.
- 초승달 외곽선은 진회색(#4A4458 계열)이고 바깥 가장자리에 1 px 들쭉날쭉이 조금 있다. 어두운 전투 배경에서는 외곽보다 밝은 채움이 모양을 만든다. 회오리의 남색 띠도 어두운 배경에서는 대비가 낮다(요청 색 그대로).
- 2톤(`whiteSprite`) 미리보기는 만들지 않았다. 상자 안 탄막에서 별을 원색 그대로 쓰면 흰 별 + 검은 외곽 그대로다.
- `ref/gerson.mp4`(약 20 MB)와 다른 세션이 받은 `ref/gerson-nohit-*.mp4`(약 41 MB)는 `.gitignore` 에 걸리지 않는다. 커밋 전에 넣을지 정해야 한다(이 작업은 커밋하지 않았다).
- 비용: 응답에 cost·job id 없음 → 실결제액 미확인.
