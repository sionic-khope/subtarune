# 뚜울라 이동 자산

제리 느낌의 큰 둥근 귀·갈색 몸·크림색 배·긴 꼬리를 가진 4방향 이동 캐릭터다. 사용자 이름은 **뚜울라**다. 원본은 내장 이미지 생성 결과이며 정확한 제작 지시는 `prompt-used.txt`에 보관한다.

- 최종: `ttuulla.png`, 256×256 RGBA, 64×64 셀 4열×4행.
- 행: down → up → left → right. 각 행 4프레임, 180ms, 피벗 [32,60].
- 확인: `preview.png`, 방향별 `down.gif`, `up.gif`, `left.gif`, `right.gif`, `qc.json`.
- 재현: 같은 폴더에서 `uv run reprocess.py`. 보관한 `process-nearest.py`를 호출한다.

원본의 행 간격이 불균등해 맞춤 행/열 구간으로 16장을 추출한 뒤, 크기 변경 없이 350px 공통 셀에 재배치했다. 모든 원본 몸체 픽셀은 추출 영역 안에 있다. 공통 배율 0.2314049587로 NEAREST 축소하고 발끝을 y59에 맞췄다. 개별 프레임 배율 조절·그림 덧그리기·테두리 침식은 하지 않았다. 투명화는 기존 magenta 키 제거이고 연결 요소는 모두 보존한다.

확대 검토 후 귀·머리·꼬리 외곽의 자홍색 잔여물을 추가 정리했다. 기존 고양이 파이프라인과 같은 R>G+35, B>G+35 조건을 쓰되, 투명 픽셀에 8방향으로 직접 맞닿은 외곽에만 적용해 R/B를 G로 중화한다. 알파·도형·위치·분홍 귀 안쪽·입 안쪽은 유지한다. 정확한 프레임별 처리 개수와 보존 검사는 `qc.json`에 기록한다.

엄격 QC: 빈 프레임0, 셀 경계 접촉0, 붙여넣기 잘림0, 신체 크기 CV0.03152. 16장 모두 밑동 y60(exclusive), 실제 높이53~56px다. 귀와 꼬리 전체를 최종 확대 시트에서 확인했다. GIF는 각4프레임이다.

`processed/`는 균등 분할로 머리/발이 잘린 이전 실패 초안이다. 최종 추출은 `processed-v2/`이며 이전 폴더는 이력으로 남긴다. 게임에는 자산만 전달하며 NPC·대사·전투 등록은 포함하지 않는다.
