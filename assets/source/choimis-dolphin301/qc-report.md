# 돌고래 자산 QC

최종128×32 PNG를 확대해 직접 확인했다. 출수/정점/입수/꼬리 물보라 네 자세가 구별되며 눈·등지느러미·꼬리·파란 몸과 흰 배가 유지된다. 분리된 물방울은 all-component 추출로 보존됐다.

실제 RGBA 알파는0/255, 네 프레임은 모두 고유하다. 불투명 bbox는 `[2,5,29,30]`, `[2,11,30,30]`, `[5,6,27,30]`, `[6,17,25,30]`. 셀 경계 접촉과 잘림이 없고 마지막 물보라의 낮은 높이를 보존했다. 공통배율은0.07017543859649122다.

원본은1268×1241로 정확한 정사각형이 아니다. 기존 처리기와 같은634×620 셀로 분할하며 버려지는 마지막1행의 alpha128 이상 픽셀이0임을 검사했다. 프레임별 축소나 몸체 합성은 없다.

exporter 실행, 최종PNG 디코드·규격·alpha·고유프레임 검사, Python 문법 및 programming no-excuse 검사 통과. 게임 장면 검증과 독립 시각 검수는 별도다.
