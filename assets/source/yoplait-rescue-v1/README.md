# 요플래 구출 장면 포즈

Codex 내장 이미지 생성 결과 세 장을 배경 알파 정리·최근접 축소·피벗 정렬만 적용했다. 그림의 얼굴·의상·검·포즈를 코드로 다시 그리지 않았다. 실제 생성 프롬프트와 도구 설정 기록은 제작 담당이 이 폴더에 함께 보관한다.

- `raw/kneel.png`: 한쪽 무릎을 꿇고 검을 바닥 쪽에 내린 생성 원본.
- `raw/surprised.png`: 같은 무릎 자세에서 오른쪽을 보며 고개를 들어 놀란 생성 원본. 결과는 `assets/battle/yoplait-surprised.png`, 96×96, 피벗 `[48,89]`다. 뒤돌아보기와 같은 전체 배율0.125로 몸체 크기를 유지하며, 보이는 크기89×72px, 머리 폭40.62px/높이38.62px이다. 각도 차이로 머리 폭이 좁지만 몸체를 확대해 보정하지 않는다.
- `raw/lookback.png`: 같은 무릎 자세에서 왼쪽으로 고개를 돌려 놀란 생성 원본.
- `assets/battle/yoplait-kneel.png`, `assets/battle/yoplait-lookback.png`: 96×96 RGBA 단일 프레임, 공통 피벗 `[48,89]`, 표시 배율 1.
- `preview.png`: 왼쪽부터 기존 형섭 전투 대기(실제 배율 0.25), 무릎, 오른쪽 놀람, 뒤돌아보기. 4배 최근접 비교.
- 재현: 저장소 루트에서 `uv run assets/source/yoplait-rescue-v1/export.py`.

원본 알파 240 미만의 부드러운 주변광만 제거하고 남은 알파는255로 고정했다. RGB 색 보정·팔레트 양자화·윤곽 재도색은 없다. 독립 생성된 놀람 원본의 몸체가 더 크므로 무릎0.15, 놀람0.125의 균일 배율로 각각 전체 그림을 축소한다. 포즈별 높이에 맞춰 채우는 방식이 아니다.

기존 형섭 대기는 보이는 높이 약87px, 머리 폭 약46px다. 무릎은89×66px(머리 폭 약45.15px), 놀람은90×73px(머리 폭 약43.88px)로, 머리 규모는 기준의약98%/95%이고 무릎의 자연스러운 낮은 높이는 유지된다. 머리 치수는 원본에서 직접 확인한 랜드마크의 근사치다. 생성된 고개 각도 때문에 머리 높이는무릎42.9px/놀람38.88px로 다르다.

두 포즈의 최하단은셀 y89 직전이며 무기 끝까지 셀 안에 들어간다. `[48,89]`는 캔버스 바닥 중앙 기준이고, 오른쪽으로 길게 뻗은 검 때문에 몸의 중심은 그보다 왼쪽이다. 배경 알파·포즈·입 없는 얼굴·검 연결·나란한 표시 크기를 미리보기로 확인했다. 이 제작 검수는 게임 장면 재생 검증과 별개다.
