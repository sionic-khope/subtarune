# 자산 검수

- 생성 raw 및 최종4배 시트의 모든 셀을 직접 열어 확인했다. 사각 안경 내부는 단순하게 정리됐고, 흰머리/긴 코/치아 입/GAP/분홍 상하의가 같은 인물로 읽힌다.
- 손은 목 뒤 망토 모서리와 이어지고 한쪽 무릎이 들려 있다. 망토는4프레임에서 뚜렷하게 확장·상승·하강·회수된다. 땅/그림자/꽃잎 없음.
- 같은 픽셀 배율 비교 이미지에서 몸체는 기존보다 약4%작다. 새 자세의 넓은 망토 때문에 프레임별 몸 크기를 바꾸지 않았으며 피벗은80,152를 유지했다.
- 최종 RGBA alpha값은0/255만 존재, 비어 있는 셀0, output edge-touch0, paste-clamp0, 고유RGBA프레임4. 최우측끝157로160px셀 안에3px여백.
- GIF 두 종류를 내보냈다. 이 자산검수는 모든 정지프레임/동일배율 비교와 수치 QC이며 실제 엔진 루프와 장면 연결은 상위 작업에서 검증한다. 사용자 최종 외형 승인과 동일하지 않다.
