# 플라워리 외형 근거

사용자 참조는 [나무위키 플라워리](https://namu.wiki/w/%ED%94%8C%EB%9D%BC%EC%9B%8C%EB%A6%AC). 원본 접근 제한 후 [같은 문서 미러](https://dark.namu.moe/w/%ED%94%8C%EB%9D%BC%EC%9B%8C%EB%A6%AC)와 [Deltarune Wiki의 Flowery](https://deltarune.wiki/w/Flowery)를 대조했다. 델타룬 챕터5의 **Flowery / フラウリィ**, 테마 `Your Dad's Best Friend`인 인간형 꽃 캐릭터이며 언더테일의 꽃얼굴 Flowey와 구별한다.

- `flowery-overworld.png`: [원본](https://deltarune.wiki/images/Flowery_overworld.png),40×120. 금발·가느다란 인간형 몸·흰 셔츠·녹색/주황 조끼·갈색 바지·어깨 뒤 검은 코트.
- `flowery-face.png`: [원본](https://deltarune.wiki/images/Flowery_face.png),58×96. 감은 웃는 눈·뾰족하게 올라간 머리·미소의 인상.
- `flowery-intro.png`: [원본](https://deltarune.wiki/images/Flowery_screenshot_intro.png),1280×720. 코트를 어깨에 걸고 다른 손을 머리 쪽에 든 과장된 자신감 있는 자세와 별 반짝임.

이 파일들은 제작 참고 원본이다. 최미스의 확정 얼굴/GAP 정체성을 바꾸는 근거가 아니며 새 외형에서는 가느다란 비율·자신감 있는 자세·반짝임 등의 요청 범위만 참고한다. 원본 권리는 각 권리자에게 있다.
