# 최미스 BUILD294 패턴 전용 그림

이 폴더는 BUILD294 전투 패턴에 쓰는 신규 그림 네 종류의 제작 계약이다. 모두 Codex 내장 `image_gen`으로 별도 생성했고, 저장소 공용 `tools/sprites/sheet_processor.py`와 이 폴더의 `export.py`로 공통 배율·피벗을 적용했다. 이미지 backend의 정확한 모델 ID·품질명·seed·비용·usage는 도구가 공개하지 않아 `unknown`이다. 외부 유료 API는 호출하지 않았다.

## 런타임 전달

| --- | --- | --- | --- | --- |
| 쵸소 코스튬 천혈 몸체 | `assets/enemies/choimis-choso.png` | 320×320 RGBA, 160px 셀, 2×2, 4장 | 좌상0 손 준비 → 우상1 손 모음 → 좌하2 발사 → 우하3 조준 유지; `220,260,150,260ms`, one-shot | `(80,152)` |

| 분홍 패션 의상 | `assets/props/choimis-fashion.png` | 192×192 RGBA, 96px 셀, 2×2, 4장 | 좌상0 표범 → 우상1 얼룩말 → 좌하2 체크 아이돌 → 우하3 하트·별; `180,180,180,220ms`, sequential | 셀 중심 `(48,48)` |

쵸소 시트는 몸체 전용이다. 천혈 빔·핏방울·충돌 이펙트는 런타임/별도 FX가 소유하며 이 시트에 굽지 않았다. 최미스의 흰 머리·검은 눈썹·사각 안경·긴 코·볼 점·별도 치아 입을 유지하고, 쵸소의 붉은 얼굴 띠와 검보라 의상만 상태 변형으로 적용했다. 랩 시트는 모든 프레임의 마이크를 입 중앙에 유지한다. 패션 팩은 사람·마네킹·신체가 없는 빈 의상 네 종류다.

## 소스와 검수

- `choso/`, `rap/`, `fashion/`: 각각 `raw-sheet.png`, 실제 `prompt-used.txt`, 알파 이진화 원본, 공용 처리기 결과, 최종 투명 시트, 독립 프레임, GIF, 4배 미리보기, `qc-meta.json`을 포함한다.
- `comparison-all-2x.png`: BUILD292 승인 중립과 쵸소·랩 전 프레임, 패션 네 종류를 같은 최종 배율로 나란히 둔 비교다.
- 최종 alpha 값은 세 시트 모두 `{0,255}`이며 마젠타 색키 제거는 하지 않았다. 출력 경계 접촉·paste clamp·빈 프레임은 모두 0이다.
- 쵸소 평균 몸체 높이는 122.25px, CV 0.0068이고 랩은 123px, CV 0이다. BUILD292 승인 평균 122.5px와 같은 규모다.
- 네 프레임은 각 시트에서 RGBA 바이트 기준 모두 서로 다르다.
- 시각 확인: 쵸소 손 모으기/전진 발사 자세, 붉은 얼굴 띠, 최미스 얼굴 정체성; 랩의 중앙 마이크와 네 제스처; 패션의 네 개 서로 다른 빈 분홍 의상을 확인했다.

알려진 한계: 생성 시트의 손 모양은 저해상도 도트로 단순화됐고, `GAP` 글자는 랩 프레임에서 마이크·손에 일부 가려진다. 이는 동작 판독과 정체성을 해치지 않는다. 사용자 최종 외형 승인과 게임 내 패턴 연결·플레이 검수는 별도다.

## 재현

```sh
uv run assets/source/choimis-sky294/pattern-art/export.py /absolute/path/to/subtarune
```

`export.py`는 raw를 덮어쓰지 않고 알파를 128 기준으로 이진화한다. 각 시트에 공통 NEAREST 배율을 적용하고, 캐릭터는 발 밑변을 `(80,152)`에, 의상은 셀 중심에 맞춘다. 마지막으로 위 네 runtime PNG와 비교/GIF/QC 메타데이터를 다시 만든다.
