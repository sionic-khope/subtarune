# Udyr ability reference for memory308 battle work

Sources consulted on 2026-09-23:

- Riot champion page: <https://www.leagueoflegends.com/en-us/champions/udyr/>
- Riot Data Dragon 15.18.1: <https://ddragon.leagueoflegends.com/cdn/15.18.1/data/en_US/champion/Udyr.json>

Riot's champion page identifies Udyr as **the Spirit Walker** and names the
four stance abilities. The Data Dragon descriptions provide the battle-facing
effects below; these are research notes, not a request to clone League values
or add unspecified mechanics.

| Ability | Data Dragon battle behavior |
| --- | --- |
| Wilding Claw (Q) | Gains attack speed; next two attacks deal bonus physical damage. Recast adds more attack speed and calls lightning on the next two attacks. |
| Iron Mantle (W) | Gains a shield; next two attacks heal. Recast grants a larger shield and max-health-based healing over the next seconds. |
| Blazing Stampede (E) | Gains movement speed; first attack against each target stuns. Recast gives more movement speed and brief immobilize immunity. |
| Wingborne Storm (R) | Creates a nearby glacial storm that damages and slows. Recast empowers it to track enemies and add damage. |

The official page also states that Udyr's four basic abilities swap stances;
recasting renews one with ultimate benefits, and the next two attacks after an
ability gain attack speed.
