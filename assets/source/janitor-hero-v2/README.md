# 청소부 영웅 구출 자산 v2

생성 도구: Codex 내장 이미지 생성. 백엔드 모델 ID·비용은 제공되지 않아 단정하지 않는다. `raw/`는 채택된 생성 PNG, `prompts/`는 실제 제출 프롬프트다. `master.png`는 승인 체형을 고정하는 참조이며 긴 다리·큰 배의 다른 반려 초안은 포함하지 않는다.

| runtime | 셀/배열 | 피벗 | 표시 배율 |
| --- | --- | --- | --- |
| `assets/battle/janitor-hero-idle.png` | 192px, 2×2, 좌상→우상→좌하→우하 | `[138,180]` | 1 |
| `assets/battle/janitor-hero-laugh.png` | 192px, 단일 | `[138,180]` | 1 |
| `assets/battle/janitor-hero-stand.png` | 192px, 단일 | `[138,180]` | 1 |
| `assets/props/janitor-hero-flag.png` | 192px, 단일 | `[96,96]` | 1 |

대기 시간은 `.38,.26,.38,.26`초로 총1.28초 반복한다. 한쪽 발차기→모으기→반대 발차기→모으기의 생성 포즈이며 웃음/서기는 별도 정지 포즈다. 독립 GIF는 `idle.gif`, 원래 크기 비교는 `idle-frames-native.png`, 네 자산 나란한 검수는 `preview-native.png`다.

몸체 높이는 대기 약77px, 웃음 약79px, 서기 약78px로 기존 형섭 전투87px보다 조금 작다. 깃발까지의 전체 높이81~128px를 몸 키로 오해하여 정규화하지 않는다. 대기 원본은 공통0.235, 웃음·서기는 공통0.115 배율로 전체 그림을 최근접 축소했다. 원본별 생성 해상도 차이를 몸통/머리 해부학으로 맞췄으며 신체 일부를 별도로 늘이거나 그리지 않았다. 가로 깃발은0.11배율, 보이는 크기181×59px다.

RGBA 원본의 알파240미만 주변광을 제거하고 남은 알파를255로 고정했다. RGB·팔레트·얼굴·의상은 재도색하지 않았다. 192셀 내부 무기 끝까지 여백이 있으며 최소2px 이상 확보했다. 깃발은 어깨 뒤에서 왼쪽으로 크게 뻗기 때문에 몸 기준 피벗을 셀 중앙보다 오른쪽으로 둔다. 대기 시 깃발 최하단은 발 기준보다3~4px 아래까지 내려오며 신체 접지는180px다.

재현: 저장소 루트에서 `uv run assets/source/janitor-hero-v2/export.py`.

exporter 실행·프레임 크기/경계 검사·금지 패턴 검사 통과, 제작자가 원래 크기 미리보기를 직접 확인했다. 독립 자산 검토와 실제 게임 장면 검수 결과는 별도로 기록한다. 이 폴더의 제작 검수만으로 게임 연결 완료를 주장하지 않는다.
