# 전투 모션 원본 v1

사용자가 내장 이미지 생성 도구 사용에 동의한 뒤 만든 캐릭터별 대기 4장 + 공격 4장이다. GPT Image 2.5로 모델을 고정한 결과라고 주장하지 않는다.

| 원본 | 캐릭터·장비 | 프롬프트 |
|---|---|---|
| hyungsub.png | 형섭, 한손 칼. 입 없이 안경·눈·큰 코만 유지 | hyungsub-prompt.txt |
| gyeongsub.png | 경섭, 두 손으로 잡는 큰 도끼 | gyeongsub-prompt.txt |
| ppaman.png | 빠맨, 파란 둥근 구슬이 달린 한손 마법봉 | ppaman-prompt.txt |

1536×1024 RGB PNG, 단색 마젠타 배경이다. **PNG 파일 자체는 투명이 아니다.** 생성 도구가 최초 요청의 투명 배경을 체크무늬로 그려서, 배경만 단색으로 다시 생성했다. 게임 로더에서 `BATTLE_PREVIEW.colorKey`에 맞는 마젠타만 투명 처리해 캐시한다. 인물 색을 양자화하거나 기존 걷기 PNG를 덮어쓰지 않는다.

`src/data/battle-sprites.js`에 실제 소스 사각형·발 기준점·시간이 있다. 명목상 4×2 배열이지만 무기 효과와 신발이 경계를 넘으므로 폭/4로 일괄 자르면 안 된다. 형섭 공격의 2·3번째 프레임은 인접 프레임 조각이 들어오지 않도록 데이터의 `exclude` 영역도 적용한다.

이 자산과 미리보기는 전투 **표현** 준비다. 적, HP, 턴 순서, 피해량, 승패, 본편 전투 시작 이벤트는 아직 구현하지 않았다.
