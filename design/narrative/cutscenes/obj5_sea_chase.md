# 오른쪽 해안과 바론 바다 추격

2026-09-12 사용자 브리핑과 후속 슈팅 개선을 구현한 범위다. 클리어 후에는 [마이야르호 등장](obj5_maillard.md)으로 이어진다.

1. 납치로 동상이 치워진 obj2 오른쪽 출구 → obj5. 약2.7초 달리는 풀숲길 → 상자와 기존 협동 뗏목.
2. 빠맨이 상자를 살펴보고 원래 상자의 뚜껑을 연 뒤 `obj5_chase.js`의 원문 두 줄을 말한다. 대사 중에는 전원 정지한다. 경섭 대사가 닫힌 후 짧은 쉼 → 나무총 한 번 획득 → 한 명씩 형섭 자동 승선·빠맨/경섭 수영 → 나머지 두 줄 → 오른쪽 자동 이동. 화면이 짧게 하얘진 상태에서 바다 장면으로 교체해 뗏목 크기 전환을 가린다.
3. `{seaChase:true}`가 별도 실시간 장면을 시작한다. 기존 `Battle`의 메뉴·HP·턴 규칙은 변경하지 않는다.
4. 바다를 향해 이동 → 오른쪽의 왼쪽 보는 바론과 입에 물린 용준 → 구조 요청/총 안내 → 실제 C 한 발 → 붉은 명중 반응·포효 → 지정 Rakuichi Buster로 전환.
5. 위/아래 자유 이동, C 연사. 발사 간격0.18초·바론HP400이며 실제 보이는 몸과 탄환 충돌로만 피해를 입힌다. 명중 수/목표 수 텍스트는 표시하지 않는다. 둘 사이 거리를 넓혀 입에서 날아오는 산성 브레스와 파도 사이를 피하면서 쏜다. 바론은 수면 아래에 하체가 잠기고 앞쪽 포말·물결이 겹친다.
6. HP를70% 깎아30% 이하가 되면 한 번만 포효하고 이동22% 증가·공격 간격24% 단축의 후반 단계로 전환한다. 준비 예고와 회피할 틈은 유지한다. 새 시도에서는 후반 단계도 초기화한다.
7. 피격5회면 `으아악` → 떠내려감 → 원래 뗏목 앞 → `재도전할까?` 선택지. 피격 후1초 무적으로 한 브레스에 즉시5회 판정되지 않는다. 재도전은 바론HP/생명/탄/후반단계를 초기화하고 총·이전 스토리 진행은 보존한다. 거절하면 해안에서 대기할 수 있다.
8. 클리어 플래그를 세우고 총·공격 UI·탄환을 치운 채 살아 있는 바론·용준·파티와 바다 움직임을 유지한다. 기존 컷신 대기자가 풀리면 마이야르호 등장14줄을 시작한다. 이전 클리어 저장은 새 연출을, `obj5_maillard_done` 완료 저장은 갑판을 복원한다.

조절점은 `src/data/baron-sea-chase.js`, 장면 수명/렌더링은 `src/scenes/baron-sea-chase.js`, 맵은 `tools/maps/obj5.py`다. 세이브/QA 플래그는 `obj5_gun_taken`, `obj5_chase_started`, `obj5_chase_cleared`. Q 지점은 obj5/obj5_sea/obj5_after.
