# 영클 휴게실 플랜B

Canon level: Established

## 진입과 무대

`youngcle6` 첫 진입에서 자동으로 시작한다. 따듯한비데·미니마리오·럭키가이·파크가디언은 이 비트 동안과 완료 뒤에도 숨겨 두며 충돌하지 않는다. TV 앞에는 쥰희와 박용준만 보이고, 주인공·경섭·억빠맨은 첫 대화 뒤 왼쪽에서 들어와 TV를 함께 올려다본다.

쥰희는 TV 앞까지 다가간 뒤 짧게 몸을 당겨 박치기하고, 접촉 순간 `thud`와 화면 진동을 한 번 낸다. 꺼진 TV에서 영클의 “아시발”이 들린 직후 전원음과 함께 화면이 켜지고 기존 `storage_show`가 시작된다. TV 배경은 기존 방송 화면과 같은 고정 배경이며 대사별로 `middle_finger`, `question`, `questions`, `facepalm` 정지 그림만 바뀐다. 손으로 얼굴을 치는 장면은 짧은 마른 `thud`를 한 번 재사용한다.

## 천사문 확인

영클이 왼쪽 천사문을 언급하면 0.65초 암전 뒤 실제 `youngcle1` 타일맵을 별도 오프스크린 맵으로 굽고, 원래 좌표의 벽 그림과 천사문을 같은 순서로 합성한 화면을 1.25초 보여준다. 현재 맵·플레이어·동료·세이브 위치는 바꾸지 않는다. 0.72초 페이드로 원래 TV 구도로 돌아온다.

## 플랜B 철창

“... ... ...” 뒤 96×160 전자 철창 두 개가 화면 위에서 동시에 떨어진다. `whoosh`는 하강 시작에 한 번, `plug`와 낮춘 `thud`는 두 철창이 쥰희·용준에게 동시에 닿는 순간 각각 한 번만 난다. 실제 철창 PNG를 재사용한 반투명 잔상 다섯 장이 두 철창의 위쪽 궤적에 남는다. 충돌 순간 음악을 끄고 0.28초 멈춘 뒤, 두 철창이 각 인물을 안에 둔 채 1.05초 동안 화면 아래로 완전히 데려간다. 페이드나 순간이동은 사용하지 않는다.

## 종료 상태

TV가 꺼진 뒤 플레이어·경섭·억빠맨만 남는다. 카메라·줌·동료 추종을 복원하고 `youngcle_factory`를 다시 재생한 다음에만 `youngcle_lounge_plan_b_done`을 기록한다. 완료 세이브로 재입장하면 쥰희·용준은 생성되지 않고 사건도 반복하지 않는다. 컷신 도중 맵 전환·타이틀·Q 초기화가 일어나면 TV, 천사문 컷어웨이, 철창과 잔상을 모두 정리하며 완료 플래그는 기록하지 않는다.

QA는 사건 직전 `youngcle6`과 완료 뒤 `youngcle6_after_plan_b` 두 지점을 사용한다. 두 지점 모두 기존 파티와 퍼즐·상점 영구 강화 상태를 보존한다.
