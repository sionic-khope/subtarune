## 구현

| 원문 | 구현 | 값 |
|---|---|---|
| 마지막 이전 맵, 오른쪽으로 쭉 | `tools/maps/jjajang_walk.py` 52×12, 5~6행 한 줄 길. 굽이 길 위 문 → 왼쪽 입구, 오른쪽 문 → 검은 소나무 숲 왼쪽 입구(소나무 숲의 아래 줄기는 되돌림) | 검은 소나무 디자인, dim 0.08, my_castle_town 이어짐 |
| 중간쯤 | 25~26열 트리거, 한 번만(`jjajang_walk_started`/`jjajang_walk_done`) | |
| 어이 잠깐 → 청소부 멈춤, 요플래 한 발짝 앞, 간격, 뒤돌아봄 | 대사 뒤 `{move:'player', by:[2,0]}`(한 칸) — 컷신 중 동료는 따라오지 않아 청소부는 그 자리 → `{face:'player', dir:'left'}` | |
| 대사 넷 | 원문 그대로, 청소부 목소리·초상. “껄껄” 뒤 웃음 모션 + 거슨 웃음 | |
| 끝 | 플래그 → 요플래 오른쪽 보기 → `{regroup}` | |

시프트/X 는 실제로 천천히 걷기 키(`Player.slowMul`, 기본이 달리기)라 대사와 조작이 맞는다. QA `jjajang_walk`(연출 직전). 검사: `tests/unit/jjajang-walk.test.mjs`, `tests/playtest/jjajang-walk.mjs`.
