# 섭리오 진입 (youngcle9 토관 → `subrio` 씬)

규칙과 수치는 [docs/battle/subrio.md](../../../docs/battle/subrio.md)가 원본이다. 이 문서는 연출 순서만 남긴다.

1. 비데 방 토관에 C → ‘토관 안으로 몸을 밀어 넣었다.’ → 토관 소리 → 방 BGM 0.8초 페이드아웃 → 카메라가 스크린 중심, 줌 2.3(1.1초) → 0.4초.
2. 흰 베젤 오버레이 페이드인(0.6초). 안은 검정. Query? 브금 시작(1.2초 페이드인).
3. `SUBRIO` 로고가 천천히 떠오름(0.8→3.4초), 부제. 6.2초 뒤 또는 C.
4. 나레이션 4줄(한 글자씩, 나레이션 음성). 각 줄 완독 2.4초 뒤 자동, C로 즉시/다음.
5. ④ ‘직업을 선택해주세요~’ 위에 남고 아이콘 3개 순차 페이드인 → 포인터 3개 → 대사 6줄 → 커서 대본(띡띡·띠링) → 마지막 나레이션.
6. 슈우웅(whoosh) 흰 플래시 → Query? 정지 → SWORD 시작 → 세 명 낙하(띠링 ×3) → 조작.
7. **스테이지 진행**(2026-09-15 사용자 확정: 1~3단계 보라·청록·파랑, 마지막 비데 보스전): 깃발에 닿으면 `STAGE CLEAR!` + 빰빠밤 2.2초 → 0.5초 검게 → 검은 카드 `STAGE 2 / 청록 섬`(띠링) 1.9초 → 다음 섬이 밝아지며 세 명 다시 낙하 → 조작. 3단계 깃발 뒤 카드는 `FINAL STAGE / 따듯한비데`.
8. **보스전**: 파랑 무대(양쪽 벽). 세 명 낙하 후 1.2초 뒤 오른쪽 하늘에서 따듯한비데가 떨어져 쿵(흔들림) → 나레이션 상자 ‘따듯한비데가 나타났다!’ → 1.4초 노려봄 → 다가와 도끼를 치켜들었다 내려찍고, 못 잡으면 손바닥에서 물줄기 세 발. 창 12방에 번쩍이며 쓰러져 깜빡이다 사라지고 `CLEAR!`(승리음) → 3.6초 뒤 검게 → 방으로 복귀(`subrio_cleared`). 주인공 하트가 다 닳으면 쓰러졌다가 시작점에 다시 낙하하고 보스는 제자리로 돌아가 다시 포효(HP 유지).
9. Esc → 언제든 오버레이 페이드아웃 → 방 카메라·줌 복귀 → 방 BGM(클리어 아님).
