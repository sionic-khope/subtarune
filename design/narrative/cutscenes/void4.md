# 컷신: void4 (보라맵4 — 긴 뗏목 길, 억빠맨, 레버 다리)

**트리거**: 도착지 착지 트리거 1회(`void4_arrived`) / 레버 C(`void4_lever`) / 억빠맨 C(`void4_ppaman`)
**장소**: `void4` (배경: 멀리서 지글지글 끓는 보라 불, 바람 소리)   **등장**: 억빠맨(빠맨 스프라이트·초상화·목소리, 물 한가운데 낮은 기둥 위, 정면)

## 비트 (사용자 브리핑 2026-09-10, 텍스트 그대로)
1. 뗏목을 타고 오른쪽으로 ~12초(억빠맨 앞뒤 6초씩). 중간에 억빠맨을 쌩 지나친다.
2. 도착 → 카메라가 억빠맨으로 클로즈업. 억빠맨: "어 ㅅㅂ" / "형 구해줘요 ㅅㅂ 저 여기 갇혔어요." / "저기 저기 뭔가 다리를 내리는 레버가 있는거같아요"
3. 카메라 → 도착지 위 발판의 레버 클로즈업 → 주인공으로 복귀 ("오케이" 는 사용자 요청으로 제거)
4. 도착지 오른쪽 작은 문은 자물쇠로 잠김("자물쇠로 잠겨 있다" — 임시). 문 옆 4칸 계단 위 레버 C → 다리가 드르르르륵(rumble) 떨어지며 쿵!(thud, 흔들림) → 다리 연결.
5. 다리 위를 오래 걸어 억빠맨에게 C → **억빠맨 대화** (`void4_ppaman.js`, 사용자 브리핑 2026-09-10 텍스트 그대로)
   - "안녕하세요 형. 구해주셔서 감사해요" → 선택지 [여긴 어디 / 왜 여기 / 물어볼건 없다]
   - 1 여긴 어디: "저도 잘 모르겠어요" / "음.. 뭔가 형 방송을 보고있었는데" / "그 뒤로.. 갑자기 뭐가 막 막 퍼엉 퍼엉 팍 우르르 쾅쾅" / "그런뒤에 제가 꺄아아아아아악 해보니까 흐음 우르르 펑펑" / "펑 하고 다시 돌아와서" / (의성어 20상자 0.16s 씩) / 형섭 머리 위 `...` 말풍선 / "했어요." / (나레이션) "... ㅂㅅ새끼같다" / "어쨋든 그래요 형." → "더 물어보실거 있으세요?"(반복)
   - 2 왜 여기: "정신을 차려보니 이 보라색 땅이였고 뭔가 방황을 했어요" / "아 근데 오기전에 다른 사람들도 여기 있던거 같더라구요 몇명 본거같아요" / "뭔가 이상한 현상이 있었나... 일단 빨리 저도 나가고싶어요" → "더 물어보실거 있으세요?"(반복)
   - 3 물어볼건 없다: "형 저도 동행해도 괜찮을까요?" / "여기서 빨리 나가는걸 목표로 하죠" → **[억빠맨이 동료가 되었다]** → 뒤에서 같이 걷는다.
   - 해석: 인사는 처음 한 번만, 다시 말 걸면 바로 선택지. 가입 후엔 동료라 말 걸기 없음.
