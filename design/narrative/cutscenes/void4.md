# 컷신: void4 (보라맵4 — 긴 뗏목 길, 억빠맨, 레버 다리)

**트리거**: 도착지 착지 트리거 1회(`void4_arrived`) / 레버 C(`void4_lever`) / 억빠맨 C(`void4_ppaman`)
**장소**: `void4` (배경: 멀리서 지글지글 끓는 보라 불, 바람 소리)   **등장**: 억빠맨(빠맨 스프라이트·초상화·목소리, 물 한가운데 낮은 기둥 위, 정면)

## 비트 (사용자 브리핑 2026-09-10, 텍스트 그대로)
1. 뗏목을 타고 오른쪽으로 ~12초(억빠맨 앞뒤 6초씩). 중간에 억빠맨을 쌩 지나친다.
2. 도착 → 카메라가 억빠맨으로 클로즈업. 억빠맨: "어 ㅅㅂ" / "형 구해줘요 ㅅㅂ 저 여기 갇혔어요." / "저기 저기 뭔가 다리를 내리는 레버가 있는거같아요"
3. 카메라 → 도착지 위 발판의 레버 클로즈업 → 주인공으로 복귀 ("오케이" 는 사용자 요청으로 제거)
4. 도착지 오른쪽 작은 문은 자물쇠로 잠김("자물쇠로 잠겨 있다" — 임시). 문 옆 4칸 계단 위 레버 C → 다리가 드르르르륵(rumble) 떨어지며 쿵!(thud, 흔들림) → 다리 연결.
5. 다리 위를 오래 걸어 억빠맨에게 C → "안녕하세요형" (여기까지)

## 끝난 뒤 상태
- `void4_arrived`(트리거), `bridge_down`(side flag, 재로드 시 다리 유지·레버 ON). 문은 아직 잠김. 다음 비트 브리핑 대기.

## 형섭 대사 표기
보라맵이므로 형섭 줄("오케이")은 나레이션 스타일(이름·초상화 없음).
