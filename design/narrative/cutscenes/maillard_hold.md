# 마이야르호 선창 도착

상태: Established. 2026-09-12 사용자 대사와 연출 지시를 그대로 구현한다.

## 공간과 연결

기존 `maillard_deck` ID는 세이브 호환을 위해 유지하되 실제 공간은 배 아래의 닫힌 나무 선창이다. 기존 `maillard_deck.png` 바닥과 새 선체 목재 벽·탑승구·오른쪽 계단을 사용한다. 바다·태양·바깥 배경은 쓰지 않는다. 브금은 기존 `wind`다. 외부 갑판/선장실은 후속 브리핑 범위이므로 만들지 않는다. 오른쪽 계단 C는 이번 마지막 나레이션만 표시한다.

## 비트

1. 전함 장면의 흰 화면 아래 맵 교체. 플레이어와 동료들을 숨기고 나무 탑승구에 준비한다.
2. 흰 화면이 0.8초 걷힌 뒤 형섭·경섭·빠맨이 한 명씩 걸어나온다.
3. 빠맨과 경섭의 안부 대사. 화면 밖 왼쪽 용준의 목소리, 왼쪽에서 천천히 입장한다. 주인공들은 실제 화자인 왼쪽을 본다(브리핑의 왼쪽 입장/오른쪽 바라보기 충돌은 화자 응시로 해석).
4. 사용자 원문 대사로 배의 정체·경섭의 비밀·탈출을 말한다. 새 대사나 설정을 추가하지 않는다.
5. 용준이 마지막 대사 뒤 오른쪽으로 달린다. 카메라가 따라가 계단 통로에서 사라지는 것을 0.55초 확인하고 돌아온다.
6. 빠맨 마지막 대사, `갑판으로 올라가자.` 나레이션. 조작 복귀.

## 플래그와 연동

- `obj5_maillard_done`: 전함 공개 연출 완료. 기존 의미 유지.
- `maillard_hold_done`: 선창 대화 완료. 맵 `enter`는 이 플래그로 1회 실행한다. 과거 갑판 세이브와 Q `maillard_deck`는 미완료 상태라 새 대화를 재생한다.
- 자연 도착 시 `finishMaillardArrival()`는 `enter:false`로 맵만 바꾸고, 전함 스크립트 종료 콜백에서 `runMapEnter()`를 실행한다. 흰 화면 복귀는 선창 스크립트가 담당한다.
- 위치는 `hold_hatch`, `hold_stage`, `hold_stairs` 기준 상대 좌표. 이동은 공통 `freeSpot` 경로를 사용한다.

## 확인

집중 단위 감사: 외부 배경 없음·wind·진입 1회·QA 진행 보존·용준 달리기/카메라/제거. 실제 브라우저: 흰 전환→순차 등장→왼쪽 용준 진입→원문 대화→오른쪽 계단 퇴장→카메라 복귀·조작과 이어하기를 확인한다.
