# 최미스 도주·짜장면 사건

Canon: Established(사용자 순서·대사·충돌·변신 직전 흰 화면). Provisional(도주 중 세 짧은 비명, 흰 화면 뒤 기존 외형의 오라 상태에서 조작 복귀). BUILD290.

## 진입과 종료

밤 절벽 마지막 경섭 대사 직후 `choimis_runaway`가 이어진다. 요플래를 숨긴 채 기존 벚꽃 숲8→7→6을 차례로 보여주고, 도미조림·도현을 처음 만난 숲5의 실제 큰 나무에 도달한다. 임의로 새 맵·변신 외형·보스전을 추가하지 않는다.

마지막 “난 알파메일이 되는거야!!!” 뒤 변신음과 흰 화면을 1초 유지한다. 다음 지시 전 입력 잠금을 남기지 않도록 기존 최미스 외형과 오라를 다시 보여주고 요플래 조작을 복구한다. 이는 전투 시작이나 파티 재합류가 아니다.

## 대사

도주 비명 세 줄은 사용자의 “이런 느낌” 범위에서 작성한 임시 대사다: “흐어어어 난 몰라 ㅠㅠㅠ”, “으어어어 도망가야 해 ㅠㅠㅠ”, “난 몰라아아 ㅠㅠㅠ”. 아래 대사는 사용자 원문이다.

```text
억빠맨: 어 괜 괜찮아요?
경섭: 어 미스야 너 여기까지 튀어온거야?
최미스: 아니 기껏 도망쳤더니 이게 뭐람
최미스: 크으윽...
경섭: 미스야 일단 진정하고
최미스: 어라 저건 뭐지
최미스: 짜..장면?
경섭: 저걸 먹으면 안돼!
최미스: 네 안먹어요
억빠맨: ...?
경섭: ? 아 그러니
최미스: 네 저 다이어트하려구요.
억빠맨: 오
경섭: 그래 뭐.. 잘됐네
도미조림: 아.
억빠맨: 아.
도미조림: 내 짜장면 ㅠㅠㅠ 흐미~~
경섭: ...
억빠맨: 진짜 ㅈ된거같은데요
경섭: 어 어떡하지..
억빠맨: 뭘 어떻게해요 족쳐야죠.
최미스: ...
최미스: 흐흐흐 이 힘은..
최미스: 뭐야 . 이짜장면 대박이잖아..
최미스: 난 알파메일이 되는거야!!!
```

## 상태와 검증

- `choimis_runaway_started`: 밤 절벽에서 도주 연결 시작. `night_cliff_scene_done`·`sakura8_right_open`도 여기서 확정한다.
- `choimis_tree_crashed`: 나무 실제 접촉 뒤 설정. 숲5 재방문에도 큰 나무는 복구되지 않는다.
- `choimis_jjajang_eaten`: 그릇 위 착지 뒤에만 아이템 하나 제거. `dark_jjajang_taken` 저장 복원 규칙의 `unless`로 먹은 아이템이 되살아나지 않는다.
- `choimis_runaway_done`: 흰 화면 유지 후 확정. 숲5에 기존 최미스·경섭·억빠맨 NPC와 오라만 유지하며 이벤트를 반복하지 않는다. 파티 편성·HP·돈·다른 아이템은 불변이다.
- QA: `choimis_runaway`, `choimis_runaway_crash`, `choimis_runaway_aura`, `choimis_runaway_after`.
- 단위: `choimis-runaway.test.mjs`, `choimis-chase-maps.test.mjs`, `jjajang-night-cliff-story.test.mjs`.
- 실제 입력 전체 경로: `tests/playtest/run.sh jjajang-night-cliff`. 재사용 후속 검사: `tests/playtest/run.sh choimis-runaway`. 공통 도우미 `tests/playtest/lib/choimis-runaway.mjs`는 실제 렌더 프레임을 기록하여 나무 비행·요플래 낙하·그릇 구름·도미 충돌·소비·오라·흰 화면을 관찰한다.
