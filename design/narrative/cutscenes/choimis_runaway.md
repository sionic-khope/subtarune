# 최미스 도주·짜장면 사건

Canon: Established(사용자 순서·대사·낙하 충돌·변신·도주·일행 추적). Provisional(도주 중 세 짧은 비명). BUILD292 피드백 반영.

## 진입과 종료

밤 절벽 마지막 경섭 대사 직후 `choimis_runaway`가 이어진다. 요플래를 숨긴 채 기존 벚꽃 숲8→7→6을 차례로 보여주고, 도미조림·도현을 처음 만난 숲5의 실제 큰 나무에 도달한다.

“난 알파메일이 되는거야!!!” 뒤 새 다섯 줄 동안 기존 외형·보라 오라를 유지한다. 마지막 “헤헤 헤헤 스으으으으으으으으읍”이 끝난 뒤 변신음과 흰 화면을 1초 유지한 상태에서 `choimis_flower`로 바꾼다. 새 외형 대사·회전 승천·오른쪽 퇴장 뒤 경섭·억빠맨이 동료로 복귀한다. 전투는 시작하지 않는다. BUILD290 완료 저장은 숲5 재입장/이어하기에서 흰 화면 이후 부분만 한 번 이어 재생한다.

## 상태와 검증

- `choimis_runaway_started`: 밤 절벽에서 도주 연결 시작. `night_cliff_scene_done`·`sakura8_right_open`도 여기서 확정한다.
- `choimis_tree_crashed`: 나무 실제 접촉 뒤 설정. 숲5 재방문에도 큰 나무는 복구되지 않는다.
- `choimis_jjajang_eaten`: 그릇 위 착지 뒤에만 아이템 하나 제거. `dark_jjajang_taken` 저장 복원 규칙의 `unless`로 먹은 아이템이 되살아나지 않는다.
- `choimis_runaway_done`: 흰 화면 유지 후 확정. 이전 BUILD290 저장을 새 후반부로 연결하는 경계다.
- `choimis_flower_done`: 도주·빠맨 마지막 대사·동료 복귀까지 완료. 숲5 재방문에서 씬 NPC·오라가 남지 않으며 완료 후반부를 반복하지 않는다.
- QA: `choimis_runaway`, `choimis_runaway_crash`, `choimis_runaway_aura`, `choimis_flower`(BUILD290 완료 상태 이행), `choimis_runaway_after`, `jjajang_night_coast1/2/3`.
- 음성: 사용자 지정 다섯 문장(“안녕하세요 형들”, “스읍 미스”, “나 섹시해”, “GAP티 입을래?”, “난 가재맨 고닉”)은 지정 원본 목소리를 참조해 합성하여 인사·스읍·섹시·옷·고닉 대사에 연결한다. 화면의 기존 대사는 유지한다. C로 텍스트를 넘겨도 실제 오디오 종료 전 다음 줄로 진행하지 않는다. 녹음 반응이 붙은 대사는 노드 전체가 `voice:'none'`이며 녹음이 끝나도 같은 줄의 기본 말소리를 재개하지 않는다. 나머지 줄은 낮춘 Flowey 말소리를 사용한다. 맵·타이틀·QA 중단에서 오디오·잔상·꽃가루를 정리하고, 중단된 사전 로드는 음성을 뒤늦게 시작하지 않는다.
- 단위: `choimis-runaway.test.mjs`, `choimis-chase-maps.test.mjs`, `jjajang-night-cliff-story.test.mjs`.
- 실제 입력 전체 경로: `tests/playtest/run.sh jjajang-night-cliff`. 재사용 후속 검사: `tests/playtest/run.sh choimis-runaway`. 공통 도우미 `tests/playtest/lib/choimis-runaway.mjs`는 실제 렌더 프레임을 기록하여 나무 비행·요플래 낙하·그릇 구름·도미 충돌·소비·오라·흰 화면을 관찰한다.
