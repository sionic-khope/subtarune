# 컷신: void4_key (잠긴 문 → 레버 열쇠 → 철컥) + 낙석 맵

**트리거**: `void4` 오른쪽 작은 문 아래에서 **C**(`door` `interact:true` + lockedScript, 밟아서는 아무 일 없음). 동료 가입 전엔 "자물쇠로 잠겨 있다."
**등장**: 억빠맨(동료)

## 비트 (사용자 브리핑 2026-09-10, 텍스트 그대로)
1. 문 아래에서 C → 억빠맨: "어라 문이 잠겨있네요" / "흠.. 아까 레버에 뭐 없으셨어요?"
2. 억빠맨이 선두로 계단을 올라 레버 앞으로, 주인공이 뒤따라 올라감(카메라는 주인공)
3. 억빠맨: "음음 이 레버를" → (나레이션) "억빠맨은 레버를 뽑아버렸다"(레버 사라짐, 딸깍) → 억빠맨: "이걸 열쇠로 쓰면 되지않을까요?" → "열쇠?를 얻었다."(인벤토리 `열쇠?`)
4. 다시 문에서 C → (철컥 sfx) "철컥! 문이 열렸다." → 억빠맨: "ㅎㅎ" → 검은 페이드 → `void5`, **브금 Scarlet Forest 시작**

## 낙석 맵 (void5 → void6 → void7 → void8)
- 일직선 보라 길(화면 두세 배 길이), 살짝 어두움, 멀리 보라 불. 입구에서 8타일 지나 첫 낙석, 낙석(40px, 캐릭터보다 넓게)이 5타일 간격으로 늘어서 2초 리듬으로 떨어짐. 떨어지기 전 바위 폭의 평행한 세로 스포트라이트가 자리를 비추고, 바위는 화면 위에서 길 전체를 쓸고 내려온다(어느 줄에 있든 바위가 지나갈 때만 맞음). 소리 없음.
- void5 3개(순차) → 오른쪽 끝에서 아래로 내려가면 void6 6개(2개씩 한 박자) → 아래로 void7 9개(3개씩) → 오른쪽 끝 뚫림 → void8(빈 착지, 다음 브리핑 대기)
- 맞으면 붉은 섬광 + 왼쪽으로 슬라이드(동료도 같이, 체력 없음).
