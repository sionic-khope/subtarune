## 구현

| 원문 | 구현 | 값 |
|---|---|---|
| 파란 토리이 한두개 | 길 1(`jjajang_chin1`, 150열): 토리이 14열 → 달리기(88열 앞 제동, 장애물). 길 2(`jjajang_chin2`, 210열): 토리이 14열·96열 → 달리기 둘(78열·160열 앞) | `meta.runs`, 속도 420 |

| 찢는듯한 공격 | `chin_tear`: 찢길 자리의 들쭉날쭉한 점선 + 발톱 자국이 0.5초 깜빡(예고, 무해) → 틈이 벌어져(폭 26, 검은 속 + 흰 찢긴 가장자리) 0.35초 위험. 가로·세로·대각선 1.05초마다. 회피 = 예고선에서 비켜남. 소리 델타룬 snd_wallclaw | |
| 드럼통 던지기 | `chin_drum`: 착지 표식(타원, 0.55초) 뒤 위에서 떨어져 바닥에서 한 번 튕기고 굴러감(snd_metalhit·snd_bell_bounce_short) / 3번째마다 점선 호(0.45초) 뒤 그 호를 따라 위쪽을 지나감(snd_wing). 0.8초 간격. 드럼통 그림은 소품을 흰 2톤으로 | |

| 전투 대사 | `speak` = 씨2발년아 / 씹구멍 씹구멍 / 찍찍찍찍찢 (원문 그대로, 말풍선 소리 snd_squeaky). appear/idle/die 나레이션은 엔진 형식상 필요(미지정) | |
