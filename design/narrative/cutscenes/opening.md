# 컷신: opening (오프닝)

**트리거**: 타이틀에서 C → `game.startGame()` → `flags.opening_seen` 없으면 자동
**장소**: 검은 화면 → `room`(우이동 반지하)   **등장**: 주인공, ??? (고양이)

## 비트
1. 검은 화면 나레이션 — "20XX년." / "평화로운 우이동, 한 반지하에서..." / "..." / "아무 일도 일어나지 않을 것 같은 그런 날이었다."
2. 반지하 방 페이드인(1.6s). 주인공 침대 옆.
3. "* ......" / "* 눈을 떴다. 오늘도."
4. 한 칸 내려와 아래를 봄. "* 창밖에서 발소리가 들린다." + 화면 흔들림 + 문 소리
5. 고양이가 문에서 들어와 주인공 앞까지. 서로 마주봄.
6. "* 야옹." / "* 야아옹." / "* 문이 잠겨 있었을 텐데." / "* 따라오라는 뜻 같다."
7. 고양이 문 앞으로 이동. 끝 → 플레이어 조작 가능. 문 밟으면 마을.

## 끝난 뒤 상태
- `flags.opening_seen = true`, 맵 `room`, 고양이(`opening_cat`)는 문 앞에 남음 (말 걸면 `cat` 스크립트)
