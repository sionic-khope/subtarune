# 보라맵9 뱀길 (→ ↓ ← ↓ →) — 체크포인트 이벤트 4종

**사용자 브리핑 2026-09-10**: "점프 배웠으니까 응용한 다음 맵. → 물길에 벽과 움직이는 벽, 그다음 ↓, ←, 다시 ↓, →. 각 체크포인트마다 색다른 이벤트(돌·꽃 같은), 웃기고 이상해도 됨, 유형은 제각각."
**대사는 전부 내가 씀** (사용자 텍스트 없음). 억빠맨 없이 오면 나레이션만.

| 착지 | 유형 | 흐름 |
|---|---|---|
| B (→ 끝) | 선택 + 물리 개그 | 나레이션 "수상한 버튼이다. '누르지 마시오'" → 억빠맨 "형 저거 누르면 어떻게 될까요" [누른다 / 안 누른다] → 억빠맨이 가서 "꾹" → 흔들림 → "...아무 일도 일어나지 않았다." → "에이 뭐야" → 옆에 바위 하나 떨어짐 → "......" / "다신 안 누를게요". 다시: "저 이제 안 눌러요" |
| C (↓ 끝) | 3지선다 퀴즈 | "억빠맨의 특징은?" [바보 / 천재 / 억빠] → 바보: "네? 형 저 여기 있는데요" / "정답이었다." · 천재: "오 형 보는 눈 있으시네요" / "오답이었다." · 억빠: "...그건 제 이름이잖아요" / "표지판이 조용히 정답 처리했다." |
| D (← 끝) | 점프 연출 | "물웅덩이다." → "제가 건너뛰어 볼게요" → 포물선 점프(jump.mp3) → 첨벙 → "억빠맨은 웅덩이 한가운데 착지했다." → "...젖었어요" → "갈길 가야겠다." 다시: "아직 발 젖어 있어요" |
| E (↓ 끝) | 아이템 개그 | "상자다." → 열면 "텅 비어 있다." → "아 그거 제가 아까 먼저 열어봤어요 헤헤" → "......" → "안에 먼지 있었어요" → **먼지를 얻었다.** 다시: "빈 상자다." |
| F (→ 끝) | 출구 | 오른쪽 가장자리 → void10(빈 착지) |

## 벽
- 고정 / 옆으로 미끄러짐(`oscillate dx`) / 오르내림(`oscillate dy`, 물길 안팎) / 세로 물길 넓은 벽. 간격 300px 이상.
- 점프 규칙은 void8 과 같다(C, 억빠맨이 뒤에서 헤엄칠 때만). 세로 물길에선 억빠맨이 뗏목 위쪽(뒤)에서 따라온다.
