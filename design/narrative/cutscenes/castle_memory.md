# 기억의 방 · BUILD308

## BUILD309 후속

각 방의 진행 길 약1/4·1/2·3/4 지점에 기존 어두운 비석을 둔다. 밑동은 통로 가장자리이며 C로 반복 조사한다. 이름·초상 없이 나레이션 음색으로 아래 원문을 출력하고, 위치 보정·완료 플래그·보상은 없다.

| 방/비석 | 원문 |
| --- | --- |
| 첫 방1 | 나도 사실은 이런대우가 싫었어. 나도 올라가고싶었어. |
| 첫 방2 | 이렇게 하면 사람들이 좋아해주니까 그런거였어 |
| 첫 방3 | 왜 나에게 창녀라고 하는거야? |
| 둘째 방4 | 자꾸 높이있는녀석들과 비교하지마, 나를 봐달란말이야 |
| 둘째 방5 | 하지마, 난 그런사람이 아니라고, 오해하지 말아줘 |
| 둘째 방6 | 사실은 말이야, 나도 양지에 가고싶었어. |

세 적의 전신 색은 가재맨 그림자 팔레트로 통일하며 HP50는 유지한다. 공격 빈도25% 증가·이동탄15~21% 가속과 지속 위험 강화를 적용하되 예고0.6초·피해15를 유지한다. 성 이후 QA에는 강화 상점 구매 효과가 포함되어 공격5, 전원 HP180/200/170으로 시작한다. 반복 초기화에 중첩하지 않는다. 최신 자산 계약은 `assets/source/memory309/`다.

상태: 두 방·표지판·표준 조우와 최종 자산을 연결했고, 전체 검사3249개·동선39개·최종 추가 브라우저85개와 독립 시각2인 검수를 통과했다. 커밋·메인 반영·배포 완료 기록은 [STATE](../../../docs/STATE.md)에서 별도로 확정한다.

사용자 확정: 동쪽 회랑 끝에 작은 별도 닫힌 문과 오른쪽 표지판. 닫힌 문은 C로 진입하고 표지판은 C로 아래 세 줄만 보여 준다.

| 화자 | 원문 |
| --- | --- |
| 억빠맨 | 음.. 기억의 방이라고 적혀있어요 |
| 경섭 | 무슨뜻일까 |
| 억빠맨 | 일단 들어가보시죠 |

표지판 종료 후 기존 필드 조작으로 돌아간다. 문 C는 기존 철컥음 → 검정 페이드0.55초 → `gajaeman_memory1.start` → 공개0.6초다. 두 동료와 현재 상태를 보존하고 `castle_right` 음악을 이어간다. 재조사는 같은 대사이며 해제 조건이나 새로운 스토리 완료 플래그를 만들지 않는다.

첫 방은 위→오른쪽→위→왼쪽, 기본218.4px/s에서 중심 경로약14.5초다. 중간 가로 길의 섭루토는 표준 필드 조우이며 승리하면 `gajaeman_memory1_seobruto_defeated`로 재입장에도 제거된다. 왼쪽 끝의 열린 길은 방향키로 둘째 방 동쪽 입구에 연결된다.

둘째 방은 왼쪽→위→오른쪽→위, 중심 경로약16.85초다. 지뢰섭은 아래 가로 길, 우디르섭은 다음 가로 길의 별도 표준 조우다. 각각 `gajaeman_memory2_jiroesub_defeated`, `gajaeman_memory2_udyrsub_defeated`를 쓴다. 세 적은HP50이며 전투곡 `castle_battle`, 배경 `castle_memory`, 승리 뒤 기존 필드 음악 복귀를 사용한다. 끝은 북쪽 막힌 벽이며 다음 문·봉인 해제·후속 사건은 미지정이다.

왕복 스폰은 자동 출구 영역 밖이다. 동쪽 회랑의 새 문은96×128px이며 문턱은y128이다. 기존 북쪽y64 저장은 표준 `freeSpot` 복원에서 아래 안전한 바닥으로 이동한다. QA 바로가기는 `castle_memory_door`, `gajaeman_memory1`, `memory_seobruto`, `gajaeman_memory2`, `memory_jiroesub`, `memory_udyrsub`, `memory_end`다.

지역 표현은 오른쪽 회랑과 두 방이 같은 검정 석재·기둥·낮은 보라 이끼/용암광을 잇는다. 벽은 전용 `▦`/`castle308_wall.png`를 사용해 로비의 기존 `▥` 벽을 보존한다. 문과 새 환경의 생성 원본·파일 규격은 [환경 계약](../../../assets/source/memory308/environment/README.md), 세 적의 고정 외형과 각 자산 계약 연결은 [README](../../../README.md#기억의-방-캐릭터-기준-build308)에 둔다. 지정 전투곡의 원본/변환 기록은 [음원 계약](../../../assets/source/memory308/audio/README.md)을 따른다.

다음 검수는 `?qa=castle_memory_door`에서 방향키로 닫힌 문 앞까지 접근한 뒤 C 진입·두 방 왕복·각 조우 승리 후 저장/재입장을 실제 입력으로 확인하는 것이다. 표지판 세 줄은 별도 조사로 끝나야 하며 중앙 봉인문이나 새 스토리 단계가 열리는 것으로 처리하지 않는다.
