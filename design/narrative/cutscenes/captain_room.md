# 선장실 진입

Canon: Established. 사용자 요청의 대사·문 확인과 선장실 인테리어만 구현한다.

1. `maillard_saloon`의 김은별컴퍼니 C 대화는 즉시 시작한다. 억빠맨과 지정10줄을 주고받고 `maillard_eunbyeol_seen`을 저장한다. 재대화는 마지막 응원1줄이다.
2. 오른쪽 정면 큰 문 C 조사는 지정 나레이션3노드를 표시한다. 네/아니오 선택, X 취소. 거절은 위치·스토리 상태를 바꾸지 않는다.
3. 네는 `plug`와 검은 페이드로 `maillard_captain.start`에 위를 보며 들어간다. 기존 라운지 음악을 유지한다.
4. 선장실은 비어 있는 중앙 바닥과 가장자리 조타륜·항해도·수납장, 오른쪽 큰 바다창을 갖춘다. 자동 이벤트·적·전투는 없다.
5. 남쪽 문 C는 `maillard_saloon.from_captain`으로 복귀한다. 김은별컴퍼니의 완료 상태는 유지한다.

대사 원문은 `src/data/cutscenes/captain_room.js`, 좌표·충돌은 맵 생성기가 단일 기준이다.
