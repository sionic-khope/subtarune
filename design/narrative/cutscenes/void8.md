# 컷신: void8 (점프 뗏목 — 억빠맨 수영)

**트리거**: `void8` 뗏목 `raft8` 에 C(onBoard) / 도착(onArrive). **등장**: 억빠맨(동료)
**사용자 브리핑 2026-09-10, 텍스트 그대로**

## 비트
1. 뗏목에 타면 요플래만 타고 **출발하지 않음**. 억빠맨(선착장): "..." / "그냥 전 수영해서 갈게요" → 물가로 걸어가 첨벙 → 뗏목 뒤에서 **얼굴만** 내밀고 같이 이동
2. 오른쪽으로 ~4초 → **몸만한 벽**에 쿵(thud·흔들림) → 억빠맨: "어라" / "형.. 음 제가 어떻게든 해볼게요. c를 눌러서 신호를 주시면"
3. 안내 창 **"C를 눌러보자"** (텍스트로 못 넘김, C 로만)
4. C → 억빠맨이 뒤에서 뗏목을 들고 **점프**(델타룬 점프음 `jump.mp3`, 2블럭 높이, 1초) → 넘어감
5. 이후 **정상 조작**: 오른쪽으로 계속 가며 같은 벽 4개, C 점프로 피함(안 누르면 쿵 하고 멈춤 → 멈춘 채 C 로 넘어감)
6. 도착: 요플래는 뭍 안쪽, 억빠맨은 물가 쪽에서 마주 봄(위치 반전 요청 반영) → 억빠맨 **강아지 물 털듯 타다다닥**(흔들림 + 파란 점, 새 스프라이트 없음)
   → "네? 수영할 수 있었으면 처음부터 제가 나오면 되지 않았냐구요?" / "... ... ..." / "아 맞넹 ㅋㅋ" (여기까지)

## 규칙
- 점프는 **억빠맨이 뒤에서 헤엄칠 때만**. 그 전 뗏목(void2/3/4)은 C 눌러도 안 됨.
- 벽 위치: 출발 684px 뒤 첫 벽, 이후 512px 간격 4개(물길 107열). 뗏목 속도 171px/s, 점프 1.0s 에 171px 전진.

## 끝난 뒤 상태
- `void8_intro`(탑승 컷신), `void8_arrived`, `void8_done`. 뗏목은 오른쪽 끝(`raft_raft8=1`), 억빠맨 동료 복귀. 오른쪽 출구 없음(다음 브리핑 대기).
