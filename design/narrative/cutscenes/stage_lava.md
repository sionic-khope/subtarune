- **youngcle13 용광로 복도**: 무대 홀 오른쪽 벽에서 들어와 오른쪽 → 세로 통로 위로 → 오른쪽 → 입구(오른쪽 끝). 배경 `youngcle_furnace`(엄청대박인배 파이프 + 용광로·용암 기운, gpt-image-2 생성), 바닥/벽 `youngcle_iron_blue`(차콜 철 + 파란 기운, 기존 철 타일 재색), 브금 **Pandora Palace**(사용자 지정 q-5cXVcCOUs).
- **youngcle14 용암 수로**(2026-09-16 정정: “한 줄만”, “바로 오른쪽”): 입구에서 오른쪽으로 걸으면 부두 끝에 뗏목. 수로는 **한 줄(3칸 96px)** 이고 오른쪽으로만 간다. 물 대신 용암(L). 함정은 색·크기로 구분하고 부두 안내판이 알려준다.

| 순서 | 장애물 | 넘는 법 |
| --- | --- | --- |
| 1 | 하늘색 낮은 빔(펄스) | C 한 번(꺼졌을 땐 그냥) |
| 2 | 높은 굳은 돌(붉은 균열) | 공중에서 C 한 번 더(2단) |
| 3 | 붉은 높은 빔(펄스) | 2단(꺼졌을 땐 그냥) |
| 4 | 낮은 돌 | C 한 번 |
| 5 | 하늘색 낮은 빔(좌우로 흔들림) | C 한 번(타이밍) |

빔·높은 돌에 닿으면 마지막 체크포인트로 쓸려 내려간 뒤 자동 재출발(청록숲 이단폭포 규칙), 낮은 돌은 쿵 하고 멈춤(C 로 다시). 2단 점프는 컷신이 `double_jump` 를 준다.
