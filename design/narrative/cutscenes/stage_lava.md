## 경로 (사용자 원문 “오른쪽 갔다가 오른쪽 쭉 갔다 윗길 갔다 오른쪽 갔다 입구 통과 후 오른쪽 쭉 갔다 용암 뗏목 마주친 느낌”)
- **youngcle13 용광로 복도**: 무대 홀 오른쪽 벽에서 들어와 오른쪽 → 세로 통로 위로 → 오른쪽 → 입구(오른쪽 끝). 배경 `youngcle_furnace`(엄청대박인배 파이프 + 용광로·용암 기운, gpt-image-2 생성), 바닥/벽 `youngcle_iron_blue`(차콜 철 + 파란 기운, 기존 철 타일 재색), 브금 **Pandora Palace**(사용자 지정 q-5cXVcCOUs).
- **youngcle14 용암 수로**(2026-09-16 정정 반영): 입구에서 오른쪽으로 걸으면 부두 끝에 뗏목. 수로는 **한 줄(3칸 96px)**. 구간 ① 오른쪽 → 착지 → 구간 ② 착지 오른쪽 위의 **좁은 세로 수로로 위로**(사용자: “위로 가는 거 없애버린 거야?” — 뺐던 걸 되돌림) → 위 착지 끝의 **보이는 잠긴 철문**(다음 브리핑). 물 대신 용암(L), 위아래 띠는 어두운 벽 타일(길처럼 안 보이게).
- **장애물 디자인 규칙**(사용자: “색이 다르다고 2단 점프로 인식하겠나 — 디자인을 바꿔야지”): **한 덩어리/한 층 = C 한 번, 같은 것을 두 개 쌓은 것 = 공중에서 C 한 번 더.** 낮은 돌 = 검은 덩어리 하나, 높은 돌 = 덩어리 둘을 쌓고 위 덩어리가 벌겋게 달아오름. 낮은 빔 = 발전기 한 쌍·빔 한 줄(하늘색), 높은 빔 = 같은 유닛을 위로 한 층 더 쌓은 2층 게이트(붉은). 글자 힌트·화살표 표시·정지 대사는 쓰지 않는다(사용자 거부).

| 구간 | 순서 | 넘는 법 |
| --- | --- | --- |
| ① 오른쪽 | 낮은 빔(펄스) → 두 단 돌 → 2층 빔(펄스) → 낮은 돌 → 낮은 빔(좌우로 흔들림) | 한 번 / 2단 / 2단(꺼졌을 땐 그냥) / 한 번 / 한 번(타이밍) |
| ② 위 | 낮은 돌 → 2층 빔(펄스) | 한 번 / 2단 |

빔·두 단 돌에 닿으면 마지막 체크포인트로 쓸려 내려간 뒤 자동 재출발(청록숲 이단폭포 규칙), 낮은 돌은 쿵 하고 멈춤(C 로 다시). 2단 점프는 첫 뗏목 컷신이 `double_jump` 를 준다. 두 번째 뗏목은 컷신 없이 뗏목 자체의 걸어 타기(`walkOn` 즉석 스크립트: 형섭이 걸어 올라타고 동료가 걸어가 뛰어듦)로 출발한다.
