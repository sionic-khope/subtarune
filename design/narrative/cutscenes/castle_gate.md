# 두 봉인 뒤 중앙 대문 (BUILD318)

왼쪽 구체가 켜진 뒤 아래로 내려오고 양쪽 봉인이 모두 활성화되어 있으면 거석 다리에서 영클의 `다 됐노?`, 경섭의 `이제 빨리 다시 가운데 맵으로 가볼까`, 영클의 `ㅇㅋ요`를 읽는다. 미완료 구체에서 단순 퇴실하면 이 사건은 시작하지 않는다. 기존 구체곡은 바깥 귀환 때 끈다.

검정 페이드 아래에서 경섭·억빠맨을 다시 파티에 합류시키고 중앙 로비로 이동한다. 로비의 실제 `meta.gate` 앵커에 주인공 일행과 영클·쥰희·비데·마리오·뚜울라·파크가디언을 두며, 아래에서 함께 걸어 올라온다. 인형탈 파크와 기존 각 배우의 크기·시트를 유지한다. 영클 대사 초상은 `youngcle_tv_smirk`다.

## 비트

| 사건 | 시간·시선·카메라 | 남는 상태 |
| --- | --- | --- |
| 문 앞 집결 | 카메라2.1초 이동, 전원 북향 보행, 도착0.7초 후 대사 | 두 봉인이 켜진 닫힌 문 |
| 쥰희 접근 | `열어볼게.` 완독 뒤 문 전체로1.6초 팬 | 주인공 일행은 뒤에서 대기 |
| 문 열림 | 철컥·낮은 진동, 문짝1.7초 개방, 보라 빛 | 실제 개방 완료 순간 `castle_gate_open` |
| 기겁·후퇴 | 느낌표/종소리 후 빠르게 뒷걸음,1.2초 대화 구도 복귀 | 열린 문 유지 |
| 동료 선행 | `편집노조들` 중 `노`만 모자이크, 여섯 동료가0.38초 간격으로 문턱 접근·가림 속 통과 | 세 주인공만 남음 |
| 마지막 농담 | 원문6줄 뒤 카메라·줌·세 사람 추종 복원 | `castle_gate_reunion_done` 저장 |
| 직접 진입 | 열린 문에 새 C, 검정 페이드, 어둠의 길 | 맵 전체는 검정, 길 렌더는 전용 모듈 |
| 어둠 속 대화 | 화면 준비1.5초 후 지정곡1.2초 페이드인, 원문4줄 | `castle_dark_path_seen`, 이후 자유 이동 |

대사 원본은 `src/data/cutscenes/castle_gate.js`이며 요청하지 않은 다음 이야기는 추가하지 않는다. 어둠의 길 끝은 다음 빈 도착 맵으로만 이어진다.

## 복구

개방 도중 또는 동료 입장 도중 중단하면 임시 문짝/통과 오프셋·사운드·Promise를 정리한다. 이번 사건이 아직 완료되지 않았다면 이번에 세운 개방 플래그와 타일을 되돌린다. 기존에 완료된 열린 문은 닫지 않는다. 정상 종료 후 재입장하면 열린 문과 세 사람 파티를 복원하고 동료 입장을 반복하지 않는다. 양쪽 봉인·문 개방·재회 완료는 서로 다른 플래그다.
