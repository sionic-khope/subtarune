# 검은 미로 추격·회복 방 (BUILD319)

Canon: Established — 사용자 지정 사건·원문 대사. 구현의 최종 시각/조작 QA와 배포 상태는 [STATE](../../../docs/STATE.md)에서 별도로 기록한다. 추격자의 별도 이름·정체·문 너머 이야기는 이번 범위에서 정하지 않는다.

## 진입과 원문

첫 검은 길의 위→오른쪽→위 출구에서 `gajaeman_castle_dark_arrival`로 이어진다. 파티3명과 파동 탐색 규칙을 유지한다. 처음 입장했을 때만 아래5줄을 순서대로 읽는다.

1. 억빠맨: 형들,,
2. 경섭: 왜 빠맨아?
3. 억빠맨: 아까부터느낀건데,,,
4. 억빠맨: 뒤에서 뭔가가 따라오는 기분이..
5. 억빠맨: 오 씨발 도망가요 빨리

4번째 줄 뒤 `baron_intro`·`baron_roar`, 전원 아래 시선과 느낌표, 줌0.6으로 아래를 비춘다. 추격자는2.2초 동안 아래에서120px 올라와 멈추며,5번째 대사까지 먼저 다가오지 않는다. 대사를 확인하면 플레이어 카메라·줌1로 복귀하고 직접 도망간다.

## 이동·접촉·출구

96px 폭 본길은 위→오른쪽→아래→오른쪽→위→오른쪽→위로 굽는다. 배경과 바닥은 완전 검정이며 실제 이동에서만 흰색→보라→분홍 파동이 길의 충돌 타일 영역을 드러낸다. 최신 파동 규격은 [대문·검은 길 콘티](castle_gate.md)를 공유한다.

검은 구형 몸체·보라 코어의 [전용 추격자 그림](../../../assets/source/castle319/pursuer/README.md)은192px·중심 피벗으로 표시한다. 추격속도35px/s, 처음 간격약300px이며 벽과 숨은 길을 무시하고 플레이어를 향해 온다. 오라는 바닥을 밝히지 않고 중심 몸체 반경40px만 접촉 판정한다. 메뉴·대화·전환 중에는 추격을 멈춘다.

접촉하면0.3초 암전→파티를 이 미로 입구로 복원→0.4초 밝힘→재시도다. 체력·아이템을 깎거나 게임오버/새 대사를 출력하지 않는다. 북쪽 출구로 빠져나가면 추격자를 정리하고 `gajaeman_castle_dark_refuge`로 연결한다.

회복 방은 기존 보라 석재·성 내부 깊이 배경에 약한 어둠을 남긴다. 오른쪽 마나의 샘은 기존 `maillard_spring` 상호작용을 재사용하며 실제 회복한다. 위에는 큰 닫힌 문만 있고 아직 다음 사건이나 목적지는 없다. 진입 때 `castle_dark_path`를 낮은 음량0.2로 복귀시킨다.

## 저장·중단과 검증 경계

최초 대사 완료는 `castle_dark_chase_seen`, 회복 방 도착은 `castle_dark_chase_done`으로 저장한다. seen 이어하기는 원문을 반복하지 않고 복원된 플레이어 뒤에 새 간격을 둔다. 접촉 재시도는 seen을 지우지 않는다. 맵 변경·타이틀은 추격체/카메라 잠금/소유한 전환과 긴박곡을 정리한다. 대사 원본은 `src/data/cutscenes/castle_dark_chase.js`, 움직임·접촉은 `src/scenes/castle-dark-chase.js`가 소유한다.

QA 지점: `castle_dark_chase_intro`, `castle_dark_chase`, `castle_dark_refuge`. 자연 진입→5줄→추격→길 모서리→접촉 재시도→북쪽 탈출→샘 회복·닫힌 문, 그리고 대사/추격 중 타이틀 복귀·이어하기를 각각 확인한다. 새 자산 생성/단위검사 통과와 실제 화면·입력 검증을 같은 완료 근거로 취급하지 않는다.
