# 토리이 굽이 길 — 세 토리이 달리기와 장애물 (BUILD236, 2026-09-19)

## 사용자 브리핑 (원문)

> 하고 다음맵 토리이 활용한 오른쪽 그리고 밑길, 다시 왼쪽 토리이 밑길 다시 오른쪽 토리이, 이렇게 활용하는거 만들어주고 중간중간 달리면서 나뭇잎같은게 떨어지거나 날아오거나 나뭇가지가 따라오는데 공격으로하면 효과음과 함께 쳐낼수있고 만약 못쳐내면 피가 10깎이는거 만들어주고 일단 그맵에 들어서면 다시 청소부가 청소부: 껄껄 이번에도 한번 잘 해보게 그럼 이따보게 하고 사라지고 맵끝으로 다시 가는것도 만들어저
>
> 공격ㄱ 쳐낼때 효광므 델타룬에서 쓰이는거 잘 쓰고

## 구현

| 원문 | 구현 | 값 |
|---|---|---|
| 오른쪽 → 밑길 → 왼쪽 토리이 → 밑길 → 오른쪽 토리이 | `tools/maps/jjajang_run2.py` 120×28: A 길(8~9행) 오른쪽으로 → 112~113열 밑길 → B 길(16~17행) 왼쪽으로 → 6~7열 밑길 → C 길(24~25행) 오른쪽으로 → 오른쪽 끝(다음 맵 대기). 파란 토리이 a(10열)·b(104열)·c(10열), 각 토리이를 지난 자리의 트리거(a·c 오른쪽 볼 때, b 왼쪽 볼 때만) → `meta.runs.<id>` 설정으로 러너 | 파란 토리이 길 오른쪽 끝 새 문 ↔ 왼쪽 입구 |
| 왼쪽 달리기 | 러너 `dir −1`: x 가 줄고, 시트는 앵커 기준 좌우 반전, 베기 호도 반대, 카메라는 캐릭터를 화면 오른쪽 22%(78% 자리)에, 바람·바닥 줄기·물보라도 반대 방향. 끝 자리(endX)는 카메라 클램프 안 | `runner-core.js dir`, `runner.js drawFrame mirror` |
| 나뭇잎 떨어짐 / 날아옴 / 나뭇가지 | 장애물 4종(`OBSTACLES`): `leaf`·`leaf2` = 앞 220~400px 위 120~170 높이에서 흔들리며 떨어짐, `needles` = 앞 460~520px 에서 몸 높이로 250~300px/s 날아옴, `branch` = 앞 470~540px 에서 190~230px/s 로 큰 것. 0.9~1.5초마다 순서대로(seed 로 결정적). 그림은 gpt-image 4종(`assets/source/run-obstacles-v1` → `assets/props/run_*.png`) | 끝 앞 500px 부터는 안 나온다 |
| 공격으로 쳐냄 + 효과음(델타룬) | 베기(땅 C: 앞 8~62px × 높이 0~58, 공중 C: 앞 −6~54px × 높이 airY−24~+62) 판정 창(공격 4%~80%)에 든 장애물은 앞·위로 튕겨 돌며 사라짐 + 흰 섬광 + 델타룬 `snd_hit`(새 `deflect`) | `deflectCount` |
| 못 쳐내면 피 10 | 몸 상자(±10 × 높이 44)에 닿으면 HP −10(1 아래로는 안 내려감), 붉은 섬광·흔들림(기존 `hurtPlayer`), 델타룬 `snd_damage`(새 `hurt_dr`), 무적 0.9초 | `hurtCount` |
| 들어서면 청소부: 껄껄 이번에도 한번 잘 해보게 그럼 이따보게 하고 사라짐 | 입구 트리거(1~2열, 한 번) → `jjajang_run2_enter`: 마주 보고 한마디, “껄껄” 뒤 웃음, `wing` 과 함께 확 밀리며 사라짐. A·B 달리기 끝엔 청소부가 사라진 채(`keepFollowersHidden`) | |
