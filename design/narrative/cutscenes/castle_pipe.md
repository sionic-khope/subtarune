# 중앙 봉인문으로 토관 귀환

사용자2026-09-24 브리핑. 기존 컷신/맵 스킬의 탑승 가림·전원 하차·지속 상태 기준을 적용한다.

| 비트 | 큐·시간 | 배우·카메라 | 지속/종료 상태 |
| --- | --- | --- | --- |
| 퇴실 | 구체 활성화 뒤 밖의 페이드 완료→1.5초 | 요플래 혼자, 뒤에서 토관0.9초 상승 | 오른쪽 봉인 유지 |
| 마리오 | 토관 완전 상승→0.55초 솟음→0.6초 점프→0.8초 정지 | 입구에서 옆으로 착지, mario_pipe/mario_jump→나레이션 “토관을 타라는 것 같다.” | 착지 뒤 solid, 대사 확인 후 ready 저장·조작 복귀 |
| 탑승 | 토관 C | 두 사람 접근·동시 점프0.7초→0.65초 축소/가림→검정0.65초 | ready 유지, 중간 완료 저장 금지 |
| 도착 | 로비0.75초 공개 | 세 NPC 대기, 토관 상승→둘 하차→토관 지면 침강 | 로비 무음, 임시 토관 제거 |
| 봉인 확인 | 경섭의 불 대사 확인 | 오른쪽 봉인1.4초 팬/1초 정지→1.3초 복귀 | 오른쪽만 켜짐 |
| 퇴장 | 마지막 대사 확인→마리오 점프 | 비데/마리오 아래→왼쪽→실제 문 통과, 카메라 추적 | 둘 제거, 파티3/조작·카메라 복귀 |

대사 원문은 `src/data/cutscenes/castle_pipe.js`에 저장한다. 말풍선 느낌표는 억빠맨에게 도착/“아” 전에 한 번씩이다. 대사 타이핑·C 진행·전용 목소리/초상화는 공통 TextBox를 사용한다. 추가 선택지/보상/회복은 없다. 왼쪽 방은 후속 BUILD315의 [후회의 방](../../gdd/castle-regret.md)으로 연결된다.

`castle_right_seal_active`는 기존 구체 완료 조건, `castle_pipe_ready`는 등장 완료의 side flag, `castle_pipe_returned`는 대화·퇴장·재합류 완료 단계다. 미활성 퇴실은 원래 길이고 토관을 만들지 않는다. Q와 이어하기에서 ready 토관과 마리오의 충돌을 복원하고 나레이션을 재생하지 않는다. 등장 전 숨겨진 마리오는 비충돌이다. completed에서는 세 사람만 복구한다. 중단 때 소유 애니메이션·축소·가림 참조를 정리한다.

검증: 신규 castle-pipe 실제 입력 시나리오, 기존 castle-orb 회귀, 종료 후 보행/왼쪽 길/저장 복원,375/768/1280 화면. 최신 결과는 `.omc/evidence/pipe313/ledger.md`에 기록하며 이 콘티 자체는 완료 증거가 아니다.
