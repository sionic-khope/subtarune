# BUILD306 결전 출항

정사 수준: Established. 사용자가 확정한 새 결전 전날~성 입구 구간이며, 기존 구조 후 라운지 준비의 바로 다음이다. 용준의 생사는 영클의 추측 대사일 뿐 확정 사망으로 기록하지 않는다. 요플래의 귀환 가능성은 이번 장면에서 답을 정하지 않는다.

## 진입과 지속 상태

구조 후 라운지 입장 대사가 끝나면 `ship_lounge` 음악으로 복귀한다. 영클의 “준비됨?” 선택지는 0.6초 후 나타난다. 아니요는 배치·음악·진행도를 바꾸지 않고 종료한다. 네만 진행한다. 순서 플래그는 `ship_invasion_started`, `ship_rally_done`, `ship_deck_bond_done`, `ship_invasion_arrived`다. 완료 뒤 다시 실행하지 않으며 회복 시 완료한 집회/갑판 대화를 건너뛴다.

## 원문·기술 계약

- 사용자 대사는 `src/data/cutscenes/ship_invasion.js`에 그대로 보존한다. 모자이크는 `보지임신?`의 `보지`, `편집노조`의 `노`만 기존 `mosaic` 필드로 처리한다. 기호 치환 없음.
- 원문 `...` 반응은 세 점이다. 당황한 `...?`, 말끝 `..`와 의성어는 원문대로 둔다.
- 자동 중단은 화면에 공개된 현재 페이지 토큰을 감지한다. 해당 줄의 `cut` 입력 잠금으로 C/X 즉시표시를 막고, 부모 스크립트가 바뀌면 관찰기를 제거한다.
- 오션 `scene.done`은 실제 낙하 접촉/순간이동 완료 기준이다. 중복 타이머로 충돌 이전에 대사를 넘기지 않는다. 장면 폐기·스크립트 교체 시 대기는 종료된다.
- 새 맵의 숨은 앵커와 기존 문/사다리를 기준으로 배치한다. 주인공의 저장된 소지품·HP·돈은 변경하지 않는다. 이후 보스전·다음맵은 아직 만들지 않는다.

## 확인 범위

단위 검사는 선택지 부작용·정확한 글자 중단·취소·오션 대기·음악 복귀·모자이크/대사 순서를 다룬다. 통합 검수는 실제 C 선택→집회→갑판→항해→충돌→기상→조작 복귀, 재입장/타이틀 중단, 화면 가장자리·대화창 가림·음향 큐를 root의 재사용 브라우저 러너로 확인한다. 문서 작성만으로 통합 검수를 통과했다고 간주하지 않는다.
