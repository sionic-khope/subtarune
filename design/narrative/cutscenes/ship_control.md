## 구현 메모 (`src/data/cutscenes/ship_control.js`, 맵 `tools/maps/youngcle20.py`)
- 기준점: 바닥 강철 로고(영클 얼굴 양각, 480·300). 카메라 “가운데” = 로고. 쥰희(486,216)·용준(436,272)은 로고 위쪽에서 앞(위)을 본다.
- 대포: 왼쪽 벽 속 소품 `ship_cannon` 이 `slide`(scrape) 로 나오고 `boom` 연기 띠(cannon_smoke) + `boom` 효과음. 포탄은 `spawn` 소품(검은 원 28px) → `slide` 로 날아가 맞는 순간 `hop`(사람)+`slide`(포탄)을 병렬로 벽까지, 카메라는 맞은 사람을 따라간다. 벽에서 `shake`+`impact`+`tremble`, 포탄 `remove`, “꾸엑” 뒤 `pose lying`. 용준 포탄은 대포 없이 화면 왼쪽 밖(x200)에서 바로.
- 영클: `youngcle_hover`(비행 장치). 첫 등장은 위에서 일행 앞(470,236)으로 내려오고 일행은 40px 뒷걸음. 상승은 `move px y-140` + rocket. 하강은 (556,300)까지 세 번 끊어 내려오며(훅훅훅) 매번 `ember`+`whoosh`.
- 철창: 광장 밧줄 철창 그림 재사용(`lava_cage`), 412px 위에서 `slide` 2.6초(chain_extend, 흔들림 oscillate) → 착지 thud/진동 → 문 열린 그림(`lava_cage_open`, 가운데 살 둘 제거)으로 교체(locker) → 오방순·나람(거대) 이 아래로 나와 ㄱ자로 걸어 영클 위(556,236)·아래(556,364)에 서서 왼쪽을 본다.
- 대사 원문 그대로. 편집노조는 `편집▩조`(노 모자이크), 악당은 `{c=red}`. 영클 초상은 TV 표정 그림(smirk 기본, ㅋㅋ/훗훗훗 laugh, 째려봄 glare, 나와라/즐 taunt).
- 전투 시작 연출은 표준 조우 진입 그림(battle_start·브금 끔·진동·소용돌이·줌·검게)까지. 전투는 다음 명령 — 지금은 화면이 돌아오고 대치 상태(`ship_intro_done`)로 남는다. 재입장 `after` 라벨이 같은 상태를 복원.
- 내가 고른 것: 브금 `storage_show`(영클 테마), 대포 소리 scrape/boom/cannon_puff/impact, 엔진 ember/whoosh, 버튼 click. 바꾸려면 말씀.
- 정정(2026-09-17 사용자 “용준이 대포 쏠 때도 효과음 나야지”): 용준 쪽 포탄은 대포 그림 없이 가운데서 날아오지만 발사음(`cannon_guard_fire`·`boom`)은 쥰희 때와 같이 난다.
