# 가재맨 성 출현 계약

Canon level: Established

라운지 보라색 문 앞 실제 근접 진입으로 한 번만 시작한다. 구현 원본은
`src/data/cutscenes/ship_castle.js`, 연출 비트와 치수는 `src/data/ship-castle.js`다.

## 고정 순서

1. 일행이 문을 올려다보고 라운지 BGM이 꺼진다. 영클·쥰희·억빠맨의 원문 6줄 뒤
   요플래가 뒤를 보고 보라색 코드를 2초간 들어 올린다.
2. 요플래가 위를 보고 문으로 계속 천천히 걷는다. 길을 막던 세 사람은 요플래를
   보며 물러나 통로를 비운다.
3. 문 나레이션 2줄 뒤 2초, 가재맨이 화면 왼쪽 밖에서 검은 연기와 함께 돌진해
   요플래를 잡고 오른쪽 창문 밖으로 데려간다. 나머지 다섯 명은 느낌표와 함께
   오른쪽을 본다.
4. 지정 전체곡 `TBVteb9Z6ps`를 시작한다. 연결된 마이야르호·영클 함선 바다,
   연속 상승 하늘, 코드 줄다리기, 반대색 오라, 보라 소용돌이 폭발 순서다.
5. 가재맨은 코드를 쥐고 요플래만 날아간다. 같은 원근에서 영클 함선 폭의 6배
   이상인 보라·검정 성 전체를 먼저 보여 준 뒤 원문 3줄을 말한다.
6. 요플래가 회전하며 바다에 떨어진다. 성의 보라 구체 광선이 연결 함선을
   빗나가고, 원문 2줄 뒤 반복 광선을 피해 후퇴한다.
7. 짧은 후퇴 정지 비트 뒤 `ship_castle_cord_stolen`과 `ship_castle_done`을 남기고 보라색 코드는 실제
   인벤토리와 플래그 기반 QA 복원 양쪽에서 제거한다. 여기서 구조·재회·전투·문
   개방을 만들지 않는다. 최신 후속 수중 요청은 별도 `ship_sinking` 스크립트가
   이어받는다.

## 저장·중단

- 컷신 중 타이틀/Q 중단은 임시 씬·카메라·오디오를 정리한다.
- 완료 플래그 전에는 저장하지 않으므로 중단 저장은 장면을 완료로 오인하지 않는다.
- 완료 뒤 저장/QA 복원에서 코드를 다시 지급하지 않는다.
