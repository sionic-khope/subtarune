# 마이야르호 메인 라운지 NPC

Canon level: Established — 2026-09-13 사용자 대사와 인물 배치 요청.

1536×640 메인 라운지(`maillard_lounge`)의 상점·마나샘·동상과 같은 맵에 네 NPC가 있다. 야꿀벌(250,400)과 마뱀이(570,416)는 서로 떨어진 배회 범위로 움직인다. 야꿀벌은 지정된 소개 한 줄만 말한다. 마뱀이는 첫 대화 7줄이 끝나야 `maillard_mabaem_seen`을 저장하고 이후 첫 인사만 반복한다. 두 NPC는 C를 누르면 즉시 대화하며 플레이어·동료·NPC 좌표를 재배치하지 않는다. 기존 NPC의 플레이어 쪽 바라보기만 유지한다.

예림(780,368)이 왼쪽, 박원숭(900,368)이 오른쪽이다. 어느 쪽을 C로 조사해도 `maillard_yerim_pair`가 시작된다. 이 이벤트만 파티를 예림 아래로 이동시켜 경섭·형섭·억빠맨이 x772/836/900, y440에서 위를 본다. 모든 이동은 예림 상대 좌표다. 카메라는 대화 전에 왼쪽 위(640,240)로 이동해 두 NPC와 파티를 담고 비행 중에도 고정한다.

비트는 인사 → 옆 인물 질문 → 박원숭의 짧은 점프와 허리 옆 질주 → 킁킁 → 예림 반응과 발차기 그림 → 박원숭이 회전하며 화면 오른쪽 밖으로 퇴장 → 후속 대화다. 비행은 vx700, vup400, gravity600, spin30으로1.3초이며 몸 전체가 화면을 벗어난 뒤 제거한다. 착지·복귀는 없다. 기존 jump·thud·whoosh 효과음을 사용한다. “씨밯”, “당신요” 등 지정11줄은 유지한다.

예림은 전신 일러스트 정지 그림이며 발차기 때만 같은 발 기준점[160,300]의 별도 그림으로 바뀐다. 두 그림 모두 `stillScale`0.29에서0.348로20% 확대한다. 박원숭은 기존64px 셀4×4 시트와 개체 배율1.3을 유지한다. 비행은 기존 `fling`의 제거 동작을 사용하고 예림은 비행 종료 후 정지 그림으로 돌아온다.

마지막 대사 이후 `maillard_yerim_pair_seen`을 저장하며 카메라는 플레이어로 돌아간다. 박원숭은 완료 플래그의 `unless` 조건으로 재진입·이어하기에도 나타나지 않는다. 예림 재대화는 첫 인사만 반복한다. 기존 저장 플래그를 초기화하지 않으며 보상·파티 구성·BGM은 유지한다. 완료 저장은 기존 `runScript` 종료 저장을 사용한다.

나무문은 선장실로 가는 길의 입구다. 기존 `maillard_saloon` ID·연결·736×448 방 구조는 유지하며 표시 이름과 Q 이름만 “선장실로 가는 길”로 바꾼다. 이 맵에는 NPC가 없으며 별도의 선장실 맵을 만들지 않는다.

검증 범위: 배회 범위·출입구 경계, 즉시 대화와 좌표 보존, 대사 완료/반복, 화면 밖 비행·제거와 예림/카메라 복원 단위 검사. 실제 그림·C 접근·비행 전후·재진입 화면은 해당 구간 플레이테스트에서 확인한다.
