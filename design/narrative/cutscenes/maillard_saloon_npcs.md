# 안쪽 라운지 NPC

Canon level: Established — 2026-09-13 사용자 대사와 인물 배치 요청.

736×448 안쪽 라운지의 왼쪽에는 야꿀벌과 마뱀이가 서로 떨어진 72×72 배회 범위로 움직인다. 아래 출입구와 입장 동료 자리는 비워 둔다. 야꿀벌은 지정된 소개 한 줄만 말한다. 마뱀이는 첫 대화 7줄이 끝나야 `maillard_mabaem_seen`을 저장하고 이후 첫 인사만 반복한다. 작은 NPC를 파티가 가리는 문제가 있어 두 대화는 공통 `roamerTalkStage`로 파티를 화자의 오른쪽 아래에 64px 간격으로 짧게 걸어 배치하고 서로 바라보게 한다. 배회 반경 끝에서도 벽·대화창·화자를 침범하지 않으며 NPC 자신의 위치는 옮기지 않는다.

오른쪽은 예림이 왼쪽, 박원숭이 오른쪽이다. 어느 쪽을 C로 조사해도 `maillard_yerim_pair`가 시작된다. 파티는 예림 아래의 가운데로 걸어와 경섭·형섭·억빠맨 순으로 64px 간격, 위를 보는 상태로 선다. 모든 이동은 예림 상대 좌표이며 기존 `freeSpot`으로 바닥을 확인한다.

비트는 인사 → 옆 인물 질문 → 박원숭의 짧은 점프와 허리 옆 질주 → 킁킁 → 예림 반응과 발차기 그림 → 박원숭 회전 비행 → 오른쪽 안전한 착지 → 후속 대화다. 기존 jump·thud·whoosh 효과음을 사용한다. “씨밯”, “당신요”는 사용자 원문 그대로다. 새 대사는 추가하지 않는다.

예림은 방향별 이동 시트가 아닌 전신 일러스트 정지 그림이며 발차기 때만 같은 크기의 별도 그림으로 바뀐다. 박원숭은 64px 셀의 4×4 시트에 개체 배율1.3을 적용해 실제 몸 높이 약54px로 예림 허리까지 닿는다. 비행은 기존 `fling`을 사용하고 착지할 때 비행 오프셋·회전을 정리해 살아 있는 NPC로 남긴다.

마지막 대사 이후 `maillard_yerim_pair_seen`을 저장하며 카메라는 플레이어로 돌아간다. 재진입에는 플래그별 NPC 변형이 착지 위치를 복원한다. 재대화는 예림의 첫 인사만 반복하며 개그를 재생하지 않는다. 보상·파티 구성·BGM·Q 지점은 변경하지 않는다. 완료 저장은 기존 `runScript` 종료 저장을 사용한다.

검증 범위: 배회 범위·출입구 경계, 기존 러너로 대사 완료/반복·비행/착지·정지 그림/카메라 복원 단위 검사. 실제 그림·음성 및 C 접근·추종·재진입 화면은 통합 플레이테스트에서 확인한다.
