# 거석 회랑 협동 밀기 (BUILD316)

Canon: Established. 사용자 지정 후회의 방 이후 사건이며, 중앙 문을 여는 이후 이야기는 포함하지 않는다.

## 소유와 재진입

`castle_boulder_intro`가 대사·카메라·진행을 소유하고 `CastleBoulderScene`이 돌/괴물/레이저/진공파/파편만 소유한다. 타이밍 컨트롤러는 `castle-boulder-push.js`이며 기본 입력 추상화 `confirm`을 사용한다. 씬 종료·Q·타이틀·맵 변경에서는 두 컨트롤러를 정리하고 완료 플래그를 만들지 않는다.

중단 시 미니게임 단계는 저장하지 않고 전체 대치에서 다시 시작한다. 완료 세이브는 `castle_boulder_done`, `party:[]`, 벽에 박힌 바위, 여덟 대기 배우를 복원한다. 왼쪽 구체 완료는 별도 `castle_left_seal_active`다. `party_hidden` 전역 플래그는 사용하지 않는다.

임시 원/사각형으로 최종 자산을 대신하지 않는다. 새 생성 자산의 셀/피벗/네 포즈는 `assets/source/boulder316/nunusub/` 기록을 따른다. 바위256셀의 중심128,128과 벽 자산384×320의 바위 중심144,176을 맞춰, 월드 최종중심3344,628→벽그림원점3200,452로 이어진다. 충돌하는 순간까지 돌은 그려지고 그 직후 같은 크기의 박힌 돌로 전환한다.
