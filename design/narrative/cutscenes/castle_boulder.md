# 거석 회랑 협동 밀기 (BUILD316)

Canon: Established. 사용자 지정 후회의 방 이후 사건이며, 중앙 문을 여는 이후 이야기는 포함하지 않는다.

## BUILD319 최신 교정

아래317의 무음 레이저·미니게임 긴박곡·10단계 고정 카메라 설명은 이 절이 대체한다. 영클·쥰희 초점 구도에 도착하면 `baron_intro`와 실제 발사 시점의 `laser_zap`0.28을 사용한다. 영클이 레이저를 설명하는 초점에서도 소리를 내고, 다른 곳을 보는 동안과 밀기 중의 반복 발사는 무음이다. 구경하는 일행은 쥰희/돌의 왼쪽 뒤에서 간격을 두고 서며 “다들 붙으시죠” 뒤에만 한 줄로 붙는다. 자산·배율·성공음·새 C 판정은 유지한다.

“밀어!!!!!!”부터 `castle_battle`(From Now On)로 바뀐다. 10단계 성공 뒤 판정/게이지를 멈추고1.4초 동안 오른쪽 누누 쪽으로 팬한다. 그 구도에서 돌·괴물과 일행의100px 전진→쿠구궁·포효를 보여주고 “거의다 온거같아 마지막 스퍼트다 밀어!!!!!”를 읽는다. 다시1.4초 팬으로 밀기 대형을 잡은 뒤에만 연타를 받는다. 카메라 전환·대사 중 취소해도 이전 Promise가 입력이나 음악을 뒤늦게 복원하지 않는다.

## BUILD317 최신 교정

아래 초기 비트의 상충하는 크기·음악·게이지 전환은 이 절로 대체한다. 처음 오른쪽 팬은 영클·쥰희와 거대한 돌만 보여 주며 누누는 물리적으로 오른쪽 화면 밖에 둔다. 누누 소개 후 오른쪽 팬에서 몸이 화면 대부분을 차지한다. 거석은 표시1.5배, 누누는1.3배이며 마지막 박힌 돌도 같은 배율이다. 파크 인형탈2.22·뚜울라1.79를 기존 라운지에서 재사용한다. 끝은 상하 다리 벽에 연결된 두꺼운 석벽이고 북쪽 문은 확대된 돌을 피한 안전 위치다.

영클 외8명은 쥰희 뒤 한 줄로 붙는다. 영클은 더 위에서 레이저를 계속 쏘지만 발사음은 없다. 쥰희: “타이밍에 맞춰서 c를 눌러, 합 맞춰서 미는거야!”→“밀어!!!!!!” 시작에 `baron_intro` 재생→약2초 여유→보라색 성공 구역 게이지0.7초 페이드인→새 C 판정이다. 성공음 `great_shine`은 유지한다.

10단계 완료는 즉시 연타가 아니다. 합동 전진·쿠구궁→누누 포효→쥰희: “거의다 온거같아 마지막 스퍼트다 밀어!!!!!”→확인 뒤 `연타하라!`다. 이 사이 게이지와 판정은 멈추며 중단/타이틀 이동 뒤 오래된 Promise가 기믹을 복원하지 않는다. 이후 기합·굴러감·벽 충돌·동료 대기·단독 구체 동선은 유지한다.

후회의 방2 북쪽에서 입장한다. 기존 보라 석재와 성 내부 깊이 배경을 잇는 ㄱ자 다리다. 미니게임 이전에는 파티 셋, 비데, 마리오가 걷고, 완료 후에는 요플래만 북쪽 봉인의 방으로 간다.

## 소유와 재진입

`castle_boulder_intro`가 대사·카메라·진행을 소유하고 `CastleBoulderScene`이 돌/괴물/레이저/진공파/파편만 소유한다. 타이밍 컨트롤러는 `castle-boulder-push.js`이며 기본 입력 추상화 `confirm`을 사용한다. 씬 종료·Q·타이틀·맵 변경에서는 두 컨트롤러를 정리하고 완료 플래그를 만들지 않는다.

중단 시 미니게임 단계는 저장하지 않고 전체 대치에서 다시 시작한다. 완료 세이브는 `castle_boulder_done`, `party:[]`, 벽에 박힌 바위, 여덟 대기 배우를 복원한다. 왼쪽 구체 완료는 별도 `castle_left_seal_active`다. `party_hidden` 전역 플래그는 사용하지 않는다.

임시 원/사각형으로 최종 자산을 대신하지 않는다. 새 생성 자산의 셀/피벗/네 포즈는 `assets/source/boulder316/nunusub/` 기록을 따른다. 바위256셀의 중심128,128과 벽 자산384×320의 바위 중심144,176을 맞춰, 월드 최종중심3344,628→벽그림원점3200,452로 이어진다. 충돌하는 순간까지 돌은 그려지고 그 직후 같은 크기의 박힌 돌로 전환한다.
