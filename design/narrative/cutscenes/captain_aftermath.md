# 만카츠키 승리 이후 — 쥰희 회복과 요플래의 과거

Canon: Established. 2026-09-13 사용자 지정 대사·연출. 원문과 실행 순서는 `src/data/cutscenes/captain_aftermath.js`가 기준이다.

## 시작과 보상

기존 만카츠키 전투의 승리 화면에서 500원을 한 번 지급한다. 전투가 종료되고 승리 플래그 `captain_mankatsuki_defeated`가 선 다음 후속 스크립트를 시작한다. 컷신에서 돈이나 HP를 직접 변경하지 않는다.

선장실 진입 시 승리했지만 `captain_aftermath_done`이 없으면 같은 후속 장면을 재개한다. 이 조건은 이전 빌드의 승리 저장에도 적용되며 승리 보상이나 전투를 다시 실행하지 않는다. 후속 장면의 진행 위치는 저장하지 않으므로 미완료 장면은 첫 대사부터 다시 시작한다.

## 연출 비트

1. 검정 페이드 뒤 같은 선장실 중앙에서 대치한다. 만카츠키 쥰희는 카펫 위쪽 기준, 빠맨·요플래·경섭은 그 아래 64px 간격이다. 보라 목재 음영과 오라는 유지한다.
2. 만카츠키의 신음 뒤 오라와 음영이 3초에 걸쳐 흩어진다. 기존 분홍 쥰희 스프라이트와 보통 크기로 돌아온다.
3. 회복 대화 후 빠맨·경섭·쥰희가 요플래를 바라본다. 요플래가 자신의 정체와 김형섭을 되찾아야 한다는 목적을 말한다.
4. BUILD133 사용자 요청: 선장실이2.6초 동안 천천히 어두워지고 검정에서1.2초 쉰 뒤 지정 `captain_memories`를0초부터 재생한다. 음악 볼륨은2.5초, 첫 삽화는2.8초에 걸쳐 나타난다. `origin` 2줄 → `split` 2줄 → `demon` 4줄 → `hack` 3줄. 검은 배경의 상단 그림과 하단 실시간 나레이션으로, 같은 그림에서는 대사만 바뀌고 그림이 바뀔 때만1.4초 페이드아웃→2초 페이드인한다. 음악은 네 장 동안 한 번만 시작해 연속 재생한다. 그림 전환 중 확인·취소와 타이핑은 잠그되 일반 대화 속도는 유지한다.

6. 지정 후속 대사 → 노란 흔들림 강조 “그리고 족치는거다!” → 기존 쥰희 웃음 동작·음원 → 마지막 빠맨 대사 후 자유 조작.

## 완료 상태

마지막 대사를 확인해야 `captain_aftermath_done`이 선다. 같은 배우를 `captain_junhee_restored`로 유지하고 재방문 시에도 보통 분홍 쥰희를 복원한다. 재상호작용은 추가 대사 없이 종료한다. 새 전투·전함 이동·동료 합류·추가 보상은 없다. 선장실의 후속 음악은 지정되지 않아 무음이다.

QA `captain_aftermath`는 승리 직후 장면 하나만 추가한다. 두 상점 강화와 승리 500원은 기존 `stateFromFlags`를 통해 유도한다. 자동 검증은 배우 지속성, 컷신 실제 실행, 음악 순서, 파티 간격, 중복 재생·지급 방지를 검사한다. 최종 이미지·화면과 실전 승리/저장 재개는 별도 브라우저 검증 대상이다.
