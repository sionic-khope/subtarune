## 흐름
1. **조건·트리거**: 최미스 구출 뒤(`choimis_rescued`) 엄청대박인배 라운지. 상점(왼쪽 아래) 건너편 분수 = 상점과 같은 높이 오른쪽의 **홀로 탁자**(`lounge_holo`, 물줄기처럼 솟는 그림). BUILD468 은 작은 파란 마나샘(`ship_lounge_spring`)으로 잘못 읽었다(사용자 2026-10-15 “이 분수를 말한게 아니라 여기 아래에 분수”). 버튼 자리(`ship_lounge_fountain_button`, 표시 없는 sign x572 y906 48×44)는 탁자 그림 윗변부터 충돌 윗부분까지 — 뒤편(위)에서 아래를 보면 어디서든 C 가 닿고, 아래·옆에서는 닿지 않는다. 뒤편 스폰 `fountain_back`(584,888, 아래 보기 — QA·돌아오는 자리). 이기면 버튼이 사라진다(`unless: janitor_hidden_won`), 마나샘 회복은 그대로.
2. **라운지**(`ship_fountain_button`): 억빠맨 “응? 왜요 형?” → 경섭 “여기에 버튼이 있어” → “버튼을 눌러볼까?” 예/아니요 → 예: 딸깍 + 1.4초 정적 → 억빠맨 “...” → 경섭 “허허 뭐지” → 억빠맨 “아무 반응도 없는데요.” → 경섭·요플래 발밑 구멍(`assets/props/floor_pit.png`, tools/art/floor_pit_set.py) + 모두 ‘!’ → 둘이 구멍으로 빨려 내려감 → 억빠맨 “어 어 형들!!” → 페이드 → 일행 = 경섭만.
3. **지하실**(`ship_basement`, 엄청대박인배 철벽·바닥·배관, 가구 없이 어둡게, 들어올 땐 브금 없음, 들어오면 `ship_basement_janitor`): 둘이 떨어져 넘어짐 → 경섭이 천천히 일어남 → 대사 → 요플래 일어남 → ???(청소부 목소리) “도움이필요한가?” → 둘 ‘!’·오른쪽 → 경섭 “아니 저건...!” → 카메라가 오른쪽, 허약 청소부(`janitor` 걷기 시트)가 **방 안**(x 656)에서 걸어옴 + 첫 등장 곡 → 껄껄 → 대사(원문) → 상승해 사라짐, 카메라 요플래 → 경섭 “...” → “어디가셨..”(‘셨’에서 `cut`) → 곡이 끊기고 강한 청소부(`janitor_hero`)가 내려찍기 + 둘 ‘!’·좌우로 간신히 → 착지 충격 → 껄껄 → 대사 → 대치 → 껄껄 → 깃발 공격 → 전투.
   - **허약 청소부 등장 곡**(사용자 2026-10-15 “청소부 첫 등장했을때 브금도”): 토리이 길 첫 등장(`jjajang_torii.js`)과 같은 `wise_words`. `{show}` 와 함께 걷기·카메라와 동시에 `fadeIn 1.2`(무음에서 켜는 곡, cue-lead-in 회고). 지하실에 들어올 때·라운지 버튼 ‘예’ 때 미리 받는다. 강한 청소부가 내려찍는 순간(“어디가셨..” 끊김과 같은 박자) 0.15초에 끊고, 그 뒤는 무음으로 전투 브금(`janitor_hidden`)까지.
   - **걷는 거리 절반**(사용자 “벽에서 나오는느낌인데 걷는시간 반절로”): 멈추는 자리(요플래 오른쪽 88px = x 412)까지 오른쪽 벽 앞 x 900 에서 488px → 시작 x 656 에서 244px, 걸음 46 그대로라 약 5.3초 → 2.7초. 시작 자리는 카메라 밖이라 카메라가 오른쪽으로 가는 동안 화면 오른쪽 가장자리로 걸어 들어온다.
   - **상승·낙하 = 드럼통 악마전 청소부**(사용자 “올라갔다 내려가는것도 이미 드럼통의 악마에서 오오라랑 연출과함께”, `drum_devil.md` 상승·착지 행): 사라짐 = 상승 0.52초(`DRUM_DEVIL_RESCUE.rise`, 가속, 높이 440 — 맨 아래 잔상까지 화면 위로) + `spearappear` 0.7. 내려찍기 = 낙하 0.34초(`dive`, 높이 360) + `wing` 0.9 → 착지 `impact` 0.9·흔들림 0.45초 세기 7·먼지 12알(필드 입자)·주황 충격파 고리(필드 ripple ring, 반지름 20→90). 오오라 = 몸의 붉은 실루엣 잔상 셋(`janitorRedAfterimage`, 거리 34·70·112, 투명도 0.24·0.17·0.10)을 지나온 쪽에 — 컷신 노드 `trail`(rise·drop·move), 잔상은 지나온 거리까지만 퍼진다.
   - **대치·공격**(사용자 “너희를 계엄해주겠다 하고 상단으로 올라가서 다시 왼쪽 바라보게 주인공들이랑 대치대게 움직인다음에 껄껄 웃고 공격모션 효과음과 함께 공격하고 그 뒤로 배틀”): 마지막 대사 뒤 강한 청소부가 요플래 오른쪽 위(오른쪽 72·위 64px)로 드럼통 악마전 순간이동처럼 빠르게(`dash`, `spearappear` 0.7, 붉은 잔상) → 0.3초 → 왼쪽을 봄(정지 그림 `stillFaces:'right'` 를 발 기준 반전) → 요플래·경섭이 오른쪽(청소부)을 봄 → 0.6초 → 껄껄(웃음 그림 반전 + `laugh_janitor`) → 깃발 공격 동작(`CHARACTER_MOTIONS.janitor_hero.attack` = 드럼통 악마전 지원 공격 시트 6칸·칸 시간 그대로, 몸 크기는 서기 그림과 같게) 내려치기 칸(0.68초)에 `rudebuster_swing` 0.8 → 동작이 끝나면 `battleEntry`. 대치 동안 새 대사 없음.
4. **전투**(`janitor_hidden`, HP 100, 피해 15, 돈 0, 보스): 드럼통 악마전 청소부 영웅 대기 시트를 `flipX`(엔진, 발 x 축 반전)로 왼쪽을 보게. 배경 `janitor_basement`(철 방 + 붉은 경광등, BUILD469 “너무 자주 깜빡이는듯 천천히” → 4초 주기·부드러운 곡선). 브금 `janitor_hidden` = Hammer of Justice(사용자 지정 tBdLO8u-0L8). 일행 요플래·경섭 둘.
