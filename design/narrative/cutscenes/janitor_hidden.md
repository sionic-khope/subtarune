# 청소부 히든 보스 (BUILD468, 사용자 브리핑 2026-10-15)

## 흐름
1. **조건·트리거**: 최미스 구출 뒤(`choimis_rescued`) 엄청대박인배 라운지. 상점(왼쪽 아래) 건너편 분수 = 파란 마나샘(`ship_lounge_spring`)으로 해석. 그 뒤편(위)에 버튼 자리(`ship_lounge_fountain_button`, 표시 없는 sign) — 위에서 아래를 보고 C. 이기면 사라진다(`unless: janitor_hidden_won`), 마나샘 회복은 그대로.
2. **라운지**(`ship_fountain_button`): 억빠맨 “응? 왜요 형?” → 경섭 “여기에 버튼이 있어” → “버튼을 눌러볼까?” 예/아니요 → 예: 딸깍 + 1.4초 정적 → 억빠맨 “...” → 경섭 “허허 뭐지” → 억빠맨 “아무 반응도 없는데요.” → 경섭·요플래 발밑 구멍(`assets/props/floor_pit.png`, tools/art/floor_pit_set.py) + 모두 ‘!’ → 둘이 구멍으로 빨려 내려감 → 억빠맨 “어 어 형들!!” → 페이드 → 일행 = 경섭만.
3. **지하실**(`ship_basement`, 엄청대박인배 철벽·바닥·배관, 가구 없이 어둡게, 브금 없음, 들어오면 `ship_basement_janitor`): 둘이 떨어져 넘어짐 → 경섭이 천천히 일어남 → 대사 → 요플래 일어남 → ???(청소부 목소리) “도움이필요한가?” → 둘 ‘!’·오른쪽 → 경섭 “아니 저건...!” → 카메라가 오른쪽, 허약 청소부(`janitor` 걷기 시트)가 오른쪽에서 걸어옴 → 껄껄 → 대사(원문) → 휘익(`wing`) 사라짐, 카메라 요플래 → 경섭 “...” → “어디가셨..”(‘셨’에서 `cut`) → 강한 청소부(`janitor_hero`) 위에서 내려찍기(쾅·진동) + 둘 ‘!’·좌우로 간신히 → 껄껄 → 대사 → 전투.
4. **전투**(`janitor_hidden`, HP 100, 피해 15, 돈 0, 보스): 드럼통 악마전 청소부 영웅 대기 시트를 `flipX`(엔진, 발 x 축 반전)로 왼쪽을 보게. 배경 `janitor_basement`(철 방 + 붉은 경광등이 1.1초 주기로 차올랐다 빠짐). 브금 `janitor_hidden` = Hammer of Justice(사용자 지정 tBdLO8u-0L8). 일행 요플래·경섭 둘.
5. **승리 뒤**: 지하실, 요플래·경섭 오른쪽에 청소부 → 껄껄 → 대사 → 둘이 다가감 → “멸공의 깃발이 무기에 감긴다. 요플래와 경섭의 공격력이 증가했다.” = **팀 공격력 +1**(공격력은 팀 공통 값이라 둘만 따로 올릴 수 없음, `janitor_flag_wrapped`, QA 상태 `attackPlus`) → … → “잘 컸구나.” → 경섭 ‘!’ → 휘익·흰 화면 → 분수 뒤(`fountain_back`) → 억빠맨 ‘!’ 두세 칸 위에서 달려옴 → 대사 → 다시 합류(`janitor_reunion_done`).

## 플래그
`janitor_hidden_won`(전투) · `janitor_flag_wrapped`(공격력 +1) · `janitor_reunion_done`(억빠맨 재합류). 지하실에서 껐다 켜도 들어오면 이어서(전투 전이면 처음부터, 이겼으면 승리 뒤 연출부터). QA `janitor_hidden`(Shift+Q 맨 아래, 분수 뒤).
