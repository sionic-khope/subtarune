# 낙석 맵 꼬리 길 이벤트 (void5 / void6 / void7)

**트리거**: 각 맵 마지막 레인 뒤 낙석 없는 길의 소품에 C. **등장**: 억빠맨(동료). 동료 없이 오면 나레이션만.
사용자 브리핑 2026-09-10: "낙석 외에 맵에 상호작용할 수 있는 표지판이나 뭔가 … 이런류의 이벤트 두세개".

## void5 꽃 (사용자 텍스트 그대로)
나레이션 "꽃들이다" → 억빠맨 "네 왜요?" → [냄새를 맡게 시킨다 / 그냥 간다]
- 냄새: 억빠맨 "아 넵." → (꽃들로 들어가서) "킁킁" → "...." → "냄새 존나 구려요 씨발 아" → 나레이션 "ㅋㅋ 갈길 가야겠다." (`flowers_sniffed`)
- 그냥 간다: 나레이션 "갈길 가야겠다."
- 두 번째: 나레이션 "꽃들이다" → 억빠맨 "저 이제 안 맡을 거예요"

## void6 표지판 (내가 씀)
나레이션 "표지판이다." / "\"낙석 주의\"" → 억빠맨 "... 지금 알려주면 어떡해요" → 나레이션 "맞는 말이다."

## void7 떨어진 바위 (내가 씀)
나레이션 "떨어진 바위다." → 억빠맨 "제가 한번 차볼게요" → [말린다 / 내버려 둔다]
- 말린다: "아 넵." → 나레이션 "현명했다."
- 내버려 둔다: (바위 옆으로) "얍!" → 흔들림(소리 없음) → "아 ㅅㅂ 발" → 나레이션 "ㅂㅅ같다." → "..." → 나레이션 "갈길 가야겠다." (`boulder_kicked`)
- 두 번째: "다신 안 차요"
