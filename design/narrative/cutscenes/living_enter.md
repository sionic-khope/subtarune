# 컷신: living_enter (거실 첫 진입)

**트리거**: `assets/maps/living.json` `enter:{script:'living_enter', flag:'living_entered'}` — 복도 오른쪽 끝 출입구로 들어와 페이드 인 직후 1회
**장소**: `living`(거실/부엌, 살짝 어두움)   **등장**: 형섭(나레이션 스타일)

3. "* 안계시나보다 코드를 찾아봐야겠네"

## 거실 상호작용 (`src/data/scripts.js`)
- **밥상** `living_table`: "에그타르트가 있다." → "먹을까?" 예/아니오 → 예: 타르트 소품 제거 + `tart_eaten` + "살짝 눅눅하고 차갑지만 맛은 있었다." / 이후: "빈 접시만 남았다."
- **냉장고** `living_fridge`: "음 냉장고에 뭐 없나.." → "후추? 이건 왜 있지 ㅅㅂ" → "아 진짜 씨발 왠지 어제 사골곰탕 먹는데 아프더라 아오" → (나레이션) "기분이 안좋아졌다." (`fridge_checked`)
- **티비** `living_tv`: "빈 코드를 뒤져봐야겠다." — 다음 이벤트 브리핑 대기

## 끝난 뒤 상태
- `flags.living_entered`, 플레이어는 왼쪽 출입구 앞(`from_hall`)에 그대로. 재진입 시 컷신 없음.
