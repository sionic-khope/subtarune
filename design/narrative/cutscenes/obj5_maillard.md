# 마이야르호 등장

Canon: Established. 2026-09-12 사용자 브리핑의 14개 대사를 그대로 사용한다.

바다 슈팅 승리 뒤 기존 `seaChase` 대기자가 끝나면 `MaillardArrival`이 화면만 맡고, `obj5_maillard`가 기존 대화 러너로 진행한다. 총과 적 공격은 사라지고 바닷물과 뗏목의 움직임은 계속된다. 별도 전투 UI나 진행 숫자를 추가하지 않는다.

1. 무음 속 흔들리는 바론과 두 사람의 반응. 강한 포효·진동 때 추격곡 `baron_intro` 재개.
2. 빠맨 반응 뒤 음악 즉시 정지. 화면 밖 쥰희의 “이몸 등장”은 초상화 없이 실제 쥰희 목소리만 사용.
3. 3.2초 동안 그림자가 커지고, 반응 대사 뒤 0.9초 가속 낙하. 화면보다 넓은 거대 선체가 떨어진 뒤 흰 섬광·진동·실제 물 충돌 소리.
4. 2.3초 줌아웃으로 먼저 무대사 화면 440×310 안에서 거대한 배 전체를 보여준다. 선단의 작은 분홍 쥰희가 두 번 점프한 뒤 0.45초 동안 대화창 위 440×210 예산으로 부드럽게 구도를 옮긴다. 옆의 작은 원래 뗏목이 상대적 크기를 보여준다. 바론은 죽었으므로 축소 화면에서 사라진다. 왼쪽 선수 방향으로 항해하고 오른쪽으로 흐르는 수면·선미 항적과 조금 잠긴 선체를 표시한다.
5. 지정곡 `maillard_reveal` 시작. 그것은 노란색. 세로 스포트라이트·박수, 기존 `junhee-laugh` 프레임과 `laugh_junhee` 소리.
6. 방송플랫폼 섬 설명 뒤 세 구역의 단일 섬 이미지를 화면 가운데 표시. 말이 다 출력된 후 빠맨의 진동 대사와 음악 정지.
7. "... 어" 뒤 물이 끌려 올라가는 소리와0.35초 흰 페이드, 완전한 흰 화면1.6초를 유지한다. `obj5_maillard_done`을 세우고 `maillard_deck/arrival`로 이동한 뒤 기존 러너 종료 콜백에서 선실의 `maillard_hold` 도착 연출을 시작한다. 바깥 배경 없이 목조 배 안에서 `wind`와 후속 원문 대사로 이어진다.

미완료 클리어 세이브는 연출을 처음부터 재생한다. 완료 세이브는 갑판에 남으며 반복하지 않는다. 타이틀/리셋/맵 전환은 연출의 비동기 그림 로드를 취소하고 임시 장면을 정리한다. 기존 총·파티·승리 플래그를 지우지 않는다.

검증: `tests/unit/maillard-arrival.test.mjs`, `tests/playtest/maillard.mjs`. 브라우저 테스트는 승리 상태만 fixture로 준비하고 이후 실제 C/X 키로 대사·전환·갑판 이동·이어하기를 확인한다. 400발 전투를 반복하지 않는다.
