# BUILD311 · 오른쪽 봉인의 구체

## Overview

말자하섭 돌파 후 북쪽 닫힌 문을 C로 열면 한 화면 크기의 검은 구체 방으로 들어간다. 중앙 보라 구체와 상호작용하면 실제 로비 대문의 오른쪽 봉인이 켜지는 장면을 보여 준 뒤 원래 방으로 시점을 돌려준다. 왼쪽 봉인과 대문 전체 개방은 이번 범위가 아니다.

## Player Fantasy

어두운 방의 유일한 강한 빛에 다가가 정체불명의 힘을 건드리고, 멀리 있는 대문과 연결되어 있다는 사실을 화면으로 확인한다.

## Detailed Rules

- 검정 허공 위 기존 성의 검은 석재 바닥만 배치한다.15×12타일 맵의 카메라는[0,12]에 고정하고 이동 가능한 방·구체·귀환 통로가480×360 안에 들어온다.
- 구체는 중앙[240,130]의128px 소품이다. 보라 광원과 오라가 움직이며 접근한 요플래의 실루엣 그림자가 빛 반대편 바닥에 늘어진다.
- C 조사 원문은 나레이션 음색으로 `...`, `알수없는 힘으로 가득한 구체다.`, `나는 그것에 손을 가져다댔다.` 순서다.
- 접촉음·상승음·빛의 맥동 후 암전한다. 로비 대문으로 시점이 이동하고 오른쪽 검은 구체가 지직거리다가 보라색으로 점등한다. 왼쪽은 검정 그대로다.
- 로비 장면은 읽기 전용 렌더다. 실제 맵·좌표·파티·인벤토리를 변경하지 않으며 로비 첫 진입 이벤트를 재실행하지 않는다.
- 보라 점등 시 `castle_right_seal_active`를 적용하고 원래 구체 방 복귀 완료 후 저장한다. BGM 재생 시계와 혼자인 요플래를 유지한다. 재조사는 짧은 상태 문장만 표시한다.
- 지정 `byUCuhB8r5Q` 전체 음원(The distance between two)을 `castle_orb`로 재생한다. 방에서 나가면 기존 `castle_right`로 돌아간다.

## Formulas

광원 중심 L=[240,130], 플레이어 발 중심 P의 벡터 P−L이 그림자의 연장 방향이다. 거리가 가까울수록 그림자의 길이와 대비가 커진다. 예를 들어 광원 아래의 요플래는 아래쪽으로, 오른쪽의 요플래는 오른쪽으로 그림자를 드리운다. 실제 길이·거리 범위·알파와 연출 시간은 `CASTLE_ORB` 및 장면 렌더 함수가 원본이며 QA에서 가까운/먼 위치와 좌우 위치를 비교한다.

거리 d(px)에 대해 근접도 n=clamp(1−d/240,0,1), 그림자 길이=30+92n(px), 알파=0.28+0.58n이다. d=120이면 n=0.5, 길이76px/알파0.57이다. 적용 길이30~122px, 알파0.28~0.86이며240px 밖에서는 그리지 않는다. 연출 기본 시간은 접촉1.05→암전0.7→공개0.7→카메라1.3→지직0.9→점등0.85→유지1.25→암전0.7→복귀0.8초다.

## Edge Cases

원래 방으로 복귀하기 전 타이틀/맵 변경으로 취소하면 이번 장면이 적용한 점등 플래그를 되돌린다. 기존 완료 상태는 지우지 않는다. 취소는 임시 커튼·카메라 그림·소리 핸들을 정리하고 뒤늦은 준비 작업이 장면을 재개하지 않는다. 완료 저장/이어하기는 실제 구체 방 위치와 점등을 복원하며 로비로 순간이동하지 않는다. 로비 재방문에도 오른쪽 점등은 유지하고 잠긴 문 반응은 현재 봉인 상태에 맞춘다.

## Dependencies

`tools/maps/gajaeman_orb.py`가 방과 충돌을, `castle_orb.js` 컷신이 대사와 출입 음악을, `src/scenes/castle-orb.js`가 조명/그림자/읽기 전용 로비 장면과 임시 자원의 수명을 소유한다. `src/main.js`는 갱신·렌더·취소 훅만 연결한다. 이전 구간은 [말자하 runner 기획](malzahar-runner.md), 전체 최신 계약은 [DESIGN](../../DESIGN.md)을 따른다.

## Tuning Knobs

구체와 플레이어가 겹치지 않는 접촉 거리, 오라의 외곽 범위, 근접 그림자의 길이/대비, 페이드와 점등 대기 시간을 조정할 수 있다. 방의 전체 가시성·원문3줄·지정곡·오른쪽만 점등·원래 위치 복귀는 조정 대상이 아니다. 광원 밝기는 얼굴·바닥·상호작용 표시를 지우지 않는 범위로 유지한다.

## Acceptance Criteria

실제 북쪽 문 C→방 진입→방향키 접근→C3줄→접촉/대문 이동/오른쪽 점등→원위치 복귀를 통과한다. 중간 화면, 근접/좌우 그림자,375/768/1280px 구도와 음악 재생 시계를 확인한다. 재조사/왕복/저장/이어하기/점등 전후 취소/로비 점등 재방문에서 상태가 보존되고 왼쪽 봉인과 문은 열리지 않는다. 검증 결과와 배포 상태는 STATE와 증거 장부에 별도로 기록한다.
