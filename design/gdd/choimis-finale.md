# BUILD300 · 최미스 파이널 어택

BUILD303 최신 전환·두 타격의 구분은 [렌더링 계약](../../DESIGN.md#최미스-후속-교정-build303)을 따른다. 기존4줄 뒤 지정 Flowery 원본 “마지막 모두의 힘을 합쳐.”를 끝까지 듣고, 흰 전환/전체 하늘 공개 뒤 “마지막 피날래 GAP 모드!!!”를 확인해야60초가 시작된다. 공세 종료 폭발의 릴리즈샷과, 이후4초 충전 관통 빔의 명중음을 구분한다. 빔은 뒤 화면 밖까지 뻗은 뒤1.4초 가늘어짐·0.75초 흰 전환을 거친다.

## Overview

막타를 HP1에서 보류하고, 현재 행동이 끝난 뒤 밤하늘 전체에서60초 최종전을 치른다. 생존하면4초 자동 충전 하트빔으로 변신을 해제하고 냄트기 구조 이야기로 연결한다.

## Player Fantasy

최미스가 마지막 힘을 모두 쏟는 난전과, 충분히 힘을 모은 큰 일격으로 결착내는 감각. 검은 회피창으로 하늘을 가리지 않는다.

## Detailed Rules

- 일반 막타는 현재 공격 연출까지, 핑크 사격·먹방 막타는 현재 적 패턴 전체까지 마친다. 대기 중 추가 피해는 사망을 만들지 않는다.
- 지정 네 줄 대사→손 올리기→190장 꽃 모임→60초 혼합 공격. 상하 이동과 기존C 사격/충전을 재사용한다.
- 최종전은 명중 수로 일찍 종료하지 않는다.15초마다 공격 밀도가 커지며 이동 가능한 회피 통로를 유지한다.
- 종료 후 음악 정지와 지정 세 줄 대사. 자동 충전은0부터4초, 입력 없이 큰 빔 발사→강한 명중/흰 섬광→검은 연기 확산→기본 모습→추락 순서다.
- 승리·구조·라운지 귀환은 별도 단계다. 구조 완료 후 `choimis_rescued`를 저장하며 이전 스토리 라운지와 상점은 유지한다.

## Formulas

- 막타 보류 체력: `HP = max(1, HP - damage)`; 최초 치명타에서만 finalePending을 켠다.
- 자동 충전 진행: `p = clamp(elapsed / 4, 0, 1)`.4초 이후에는 더 강해지는 추가 충전이 없다.
- 공격 단계: `stage = min(3, floor(elapsed / 15))`; 종료는 `elapsed >= 60`.
- 구조 후 상품은각10원. 강화 바세린은 전원 최대HP+20, 강화 씨알리스는 팀 공격력+1이며 각1회다. 반복 회복품은 핫도그 한 명150/기름떡볶이 전원100이며 회복은 최대HP를 넘지 않는다.

## Edge Cases

연속 막타 중복 발동, 적 패턴 중 치명타, 패배/재도전, 타이틀 취소, 맵 이동 취소, 저장 후 재입장을 검사한다. 이전 빌드에서 승리한 세이브는 재전투 없이 절벽 진입에서 구조로 이어진다. 전투 승리만으로 구조 완료를 미리 저장하지 않는다.

## Dependencies

Battle 행동/적턴 경계, 기존 핑크 사격, Choimis 밤하늘 배경·시트·효과음, 컷신DSL, 스토리/맵/상점. 후속 대사는 `design/narrative/cutscenes/choimis_rescue.md`, 상태 소유는 `docs/architecture/choimis300-finale-rescue.md`를 따른다.

## Tuning Knobs

`src/data/choimis-finale.js`의 장면 시간·꽃 수·충전음과 `src/data/choimis-final-assault.js`의60초·15초 단계·예고·속도·통로 폭이 단일 수치 기준이다.4초/60초는 사용자 확정값이므로 임의 단축하지 않는다.

## Acceptance Criteria

실제 입력으로60초 생존, 충전0부터약4초와 무입력 발사, 기본 모습 추락 후에만 승리, 지정 구조 대사와3명 포획, 라운지 브리핑과 조작 복귀를 확인한다. 새 NPC대사·저장·귀환 후 뒤통로 잠금·과거 시점 통로 보존·내부 상점 구매/사용/취소·지연된 준비 선택지를 검사한다. 자동 생존은 인간 난도 승인과 구분하고 프레임 캡처를 독립적으로 눈으로 검수한다.
