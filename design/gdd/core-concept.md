# SUBTARUNE — Core Concept

**장르**: 탑다운 도트 스토리 어드벤처 (델타룬/언더테일 느낌)
**핵심 경험**: **스토리를 보는 게임**. 레벨업·노가다 없음. 걸어다니며 말 걸고, 중간중간 **미니게임**과 **스토리 상호작용(선택지)**이 맛을 낸다.
**이동 규칙**: 쯔꾸르(RPG Maker)처럼 **정해진 길만** 걸을 수 있다 — 넓은 오픈 필드가 아니라 통로·방 단위로 동선을 설계한다.
**플랫폼**: 웹 (데스크톱 브라우저) → 이후 itch.io / Electron

## 디자인 필러 (모든 결정의 기준)
1. **스토리 우선** — 시스템은 연출을 위해 존재. 숫자 성장(레벨/스탯/경험치) 없음.
2. **리듬 있는 대사** — 글자별 블립, 캐릭터별 음색, 속도·흔들림 태그가 연기다.
3. **정해진 길** — 맵은 통로형. 막힌 곳엔 이유(팻말/대사)가 있다. 길 잃을 수 없다.
4. **가끔 미니게임** — 스토리 비트를 강조하는 짧은 게임(리듬/회피/타이밍). 실패해도 진행은 됨, 대사만 달라짐.
5. **상호작용의 맛** — 아무 오브젝트나 눌러도 한마디는 나온다. 선택지는 플래그로 이후 대사에 남는다.

## 핵심 시스템 (구현됨)
- **타이틀**: 검은 화면 + 블록 로고 `subtArune`(A 안에 빨간 하트) 페이드인, `C 를 눌러 시작` 깜빡임 → 플래시 → 페이드 → 필드
- **컷신 DSL**: 나레이션(검은 화면)·이동·방향·카메라·페이드·흔들림·스폰·맵교체·parallel — 데이터로 작성 (`/cutscene` 스킬)
- **오프닝**: "20XX년, 평화로운 우이동 한 반지하에서..." → 반지하 방 → 고양이 등장 이벤트
- **오버월드**: 타일맵(문자열), AABB 충돌, y-정렬 렌더, 카메라 lerp+클램프, 맵 전환 페이드
- **엔티티**: player / npc(배회) / sign / chest(플래그) / door(워프) / trigger(1회 컷신)
- **대사창**: 타자기, 글자별 화자 음색 블립(0.1s), 태그 `{s} {w} {c} {shake} {wave} {n}`, 3줄 페이지, 초상화, 이름표, 선택지(하트 커서, X=취소 옵션), 라벨/goto/if/set/action
- **메뉴**: 아이템, 설정(대사 속도 3단, 사운드 on/off)
- **사운드**: 전부 WebAudio 합성. 화자별 VOICES 프리셋

## 아트 규격 (교체용)
- 캐릭터: `assets/sprites/<이름>.png` 64x64 시트 = 4열(idle, stepA, idle, stepB) × 4행(down, up, left, right), 16x16
- 타일: `assets/tiles/<타일이름>.png` 16x16 (이름은 `src/world/tiles.js` `name`)
- 초상화: `assets/portraits/<이름>.png` 48x48
- 파일명은 소문자+언더스코어
