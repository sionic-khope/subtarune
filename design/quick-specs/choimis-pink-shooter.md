# 최미스 핑크 슈터 오프닝 브리프

## Overview

최미스 전투의 두 인트로 대사 직후, 첫 행동 메뉴 전에 한 번만 실행되는 세로 이동 슈터다. 기존 전장·상단 가사·하단 패널/HP는 유지한다.

## Player Fantasy

차오른 핑크 물에 물든 하트가 오른쪽을 향해 날며, 어둠의 짜장면 그릇과 면발을 핑크 탄으로 밀어낸다.

## Detailed Rules

- 보드 열림 0.5초 → 핑크 물 채움 1.4초 → 배수·분홍 변신 2.4초 → 가로 보드 전환/좌측 이동 0.7초 → 실제 전투 20초 순서다.
- 하트는 채움까지 중앙의 일반 빨간 하트다. 배수부터 분홍색이며 단일 뾰족 끝이 오른쪽을 향한다.
- 전환 중 보드 안에 `↑↓ 이동 · C 발사`를 표시한다. 전투에서는 좌우 입력을 무시하고, 하트는 왼쪽 x에 머문다.
- 오른쪽 경고 표식 뒤 `assets/props/dark_jjajang.png` 그릇과 면발이 왼쪽으로 온다. C의 분홍 탄은 이를 파괴한다.
- 피격은 적의 표준 피해와 0.75초 무적을 사용한다. 빠른 탄과 면발은 이동 구간 전체의 연속 충돌로 판정한다.
- 발사/파괴 소리는 Baron sea chase와 같은 `cannon_puff`(0.4, 1.45) / `pop`(0.384, 0.8)이다. 피격음은 `hurtParty`의 표준 `hurt` 경로다.

## Formulas

- `heartY += (down - up) × 126 × dt`, 보드 위·아래 13px 안으로 제한한다.
- `shotX += 410 × dt`, `noodleX -= 118 × dt`, 발사 간격은 0.18초다.
- 두 이동 원의 상대 선분에서 가장 가까운 점과 반지름 합을 비교해 프레임 건너뜀 충돌을 막는다.

## Edge Cases

- 큰 `dt`에서도 전투 시간은 20초로 고정한다.
- 파티 전멸·재시도·강제 종료로 `dispose()`가 불리면 보드/하트 위치와 무적시간을 복원하고 탄·면·효과를 비운다.
- 이미지가 아직 없거나 로드 실패하면 같은 판정 크기의 픽셀 그릇 폴백을 그린다.

## Dependencies

- 공개 모드 API: `createChoimisPinkShooter(battle, { enemy })`.
- 통합부는 `choimis_pink_shooter` 등록과 전투별 opening-mode 1회/재시도 초기화를 소유한다.
- 인트로 대사 `형들 꼭 그렇게 저를 막으셔야겠다면` / `여러분들의 마음을 핑크로 물들여보세요.`는 전투 코어 인트로가 소유하며 이 모드는 추가 대사를 만들지 않는다.

## Tuning Knobs

`CHOIMIS_PINK_SHOOTER`의 단계 시간, 이동/탄 속도, 발사/스폰 간격, 예고시간, 무적시간만 조정한다. 실제 전투 20초와 지정 사운드 옵션은 고정 계약이다.

## Acceptance Criteria

- 단계·변신·오른쪽 하트 기하·20초 예산이 자동 검사된다.
- 위/아래/C 쿨다운, 명중/빗나감/피격, 예고와 기존 그릇 렌더가 자동 검사된다.
- 종료 뒤 보드·하트·투사체가 남지 않는다.
- 실제 화면에서 전장, 상단 가사, 하단 패널/HP가 가려지지 않는다.
