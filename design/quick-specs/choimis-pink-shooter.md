# 최미스 핑크 슈터 오프닝 브리프

## Overview

최미스 전투의 두 인트로 대사 직후, 첫 행동 메뉴 전에 한 번만 실행되는 세로 이동 슈터다. 기존 전장·상단 가사·하단 패널/HP는 유지한다.

## Player Fantasy

차오른 핑크 물에 물든 하트가 오른쪽을 향해 날며, 어둠의 짜장면 그릇과 면발을 핑크 탄으로 밀어낸다.

## Detailed Rules

- 보드 열림 0.5초 → 핑크 물 채움 1.8초 → 배수·분홍 변신 2.4초 → 가로 보드 전환/좌측 이동 0.7초 → 실제 전투 15초 순서다.
- 하트는 채움까지 중앙의 일반 빨간 하트다. 배수부터 분홍색이며 단일 뾰족 끝이 오른쪽을 향한다.
- 전환과 사격 중 하단의 빈 검은 패널에 `↑↓ 이동 · C 탭 발사 / 길게 눌러 충전`을 유지한다. 좌우 입력을 무시하고, 하트는 왼쪽 x에 머문다.
- C 탭은 한 발,0.6초 홀드하면 세 갈래 오라가 하트로 모여 고정 최대치가 되고 놓을 때 차징탄 한 발을 발사한다. 더 오래 누른 시간은 위력에 영향을 주지 않는다. 진입부터 잡고 있던 C는 한 번 놓아야 새 입력으로 인정한다.
- 채움 시작 `great_shine`과 차징 시작 `yellowheart_charge`를 한 번씩 재생한다. 첫 하트 변색 전용 `color_heart`는 재생하지 않는다. 놓기·종료 때 충전 음성 핸들을 정리한다.
- 오른쪽 경고 표식 뒤 `assets/props/dark_jjajang.png` 그릇과 면발이 왼쪽으로 온다. C의 분홍 탄은 이를 파괴한다.
- 피격은 적의 표준 피해와 0.75초 무적을 사용한다. 빠른 탄과 면발은 이동 구간 전체의 연속 충돌로 판정한다.
- 발사는 노란 하트 원본 `yellowheart_shot`/`yellowheart_shot_big`(volume0.9,rate1), 충전은 `yellowheart_charge`(0.3,1), 파괴는 기존 `pop`(0.384,0.8)이다. 피격음은 `hurtParty`의 표준 `hurt` 경로다.
- 일반탄은 첫 명중에서 소모되고 완충탄은 뒤 표적까지 관통한다. 같은 탄은 안정된 표적 ID당 한 번만 명중한다. 첫턴에는 회피창 안 보스나 보스 HP 피해가 없다.

## Formulas

- `heartY += (down - up) × 126 × dt`, 보드 위·아래 13px 안으로 제한한다.
- `shotX += 410 × dt`, `noodleX -= 155 × dt`, 발사 간격은 0.3초다.
- 두 이동 원의 상대 선분에서 가장 가까운 점과 반지름 합을 비교해 프레임 건너뜀 충돌을 막는다.

## Edge Cases

- 큰 `dt`에서도 전투 시간은 15초로 고정한다.
- 파티 전멸·재시도·강제 종료로 `dispose()`가 불리면 보드/하트 위치와 무적시간을 복원하고 탄·면·효과를 비운다.
- 이미지가 아직 없거나 로드 실패하면 같은 판정 크기의 픽셀 그릇 폴백을 그린다.

## Dependencies

- 공개 모드 API: `createChoimisPinkShooter(battle, { enemy })`.
- 통합부는 `choimis_pink_shooter` 등록과 전투별 opening-mode 1회/재시도 초기화를 소유한다.
- 인트로 대사 `형들 꼭 그렇게 저를 막으셔야겠다면` / `여러분들의 마음을 핑크로 물들여보세요.`는 전투 코어 인트로가 소유하며 이 모드는 추가 대사를 만들지 않는다.
- 첫 사격 완료 후 코어가 배우를 복원하고 `choimis-defense-cinematic.js`를 실행한다. “분홍의 힘이 나를 감싼다.”→꽃 집중2.8초/충전음→“최미스의 방어력이 강화되었다.” 이후 공격당1피해가 활성화된다. 재도전하면 미활성으로 초기화한다.
- 후속 `choimis_pink_round`는 같은 C 입력·차징·탄·충돌을 재사용하며 각 라운드는 명중 수와 무관하게18초 동안 진행한다.

## Tuning Knobs

`CHOIMIS_PINK_SHOOTER`의 단계 시간, 이동/탄 속도, 발사/스폰 간격, 예고시간, 무적시간만 조정한다. 실제 전투15초·충전0.6초와 지정 사운드 옵션은 고정 계약이다.

## Acceptance Criteria

- 단계·변신·오른쪽 하트 기하·15초 예산이 자동 검사된다.
- 위/아래/C 쿨다운, 명중/빗나감/피격, 예고와 기존 그릇 렌더가 자동 검사된다.
- 종료 뒤 보드·하트·투사체가 남지 않는다.
- 실제 화면에서 전장, 상단 가사, 하단 패널/HP가 가려지지 않는다.
