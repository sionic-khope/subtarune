# 최미스 전투 패턴 B

## 요청과 확정

이 문서는 최미스 보스의 `랩 → 스읍 미스 → 패션` 세 공격 계약이다. 적 체력 200과 파티 피격 피해 15는 enemy 데이터가 소유한다. 랩 전체 녹음을 새로 만들거나 보이스 클론을 붙이지 않고, 전투 말풍선의 기존 `choimis_flower` 보이스폰트와 이미 승인된 `choimis_seup_miss` 클립만 사용한다.

## 플레이 규칙

| 패턴 ID | 보이는 단서와 행동 | 공간·시간 규칙 | 성공/실패 |
| --- | --- | --- | --- |
| `choimis_rap` | 최미스가 공격 상자 중앙에서 마이크를 들고 흰 2톤 실루엣으로 랩한다. `요 / 최미스 / 래퍼딱지를 / 때 / 이젠 / 앰씨로 / 포에버 / 포에버`가 실제 한글 글자 탄으로 양쪽에서 들어온다. | 중앙 실루엣과 각 가사 레인은 최소 0.45초 점선 예고 뒤 고정된다. 가사는 네 높이를 교차하고 반대 방향으로 번갈아 들어온다. | 글자 외곽 직사각형과 중앙 최미스의 실제 흰 실루엣만 충돌한다. 투명 모서리는 안전하며 가사 사이 높이로 이동한다. |
| `choimis_seup` | 기존 2.7초 `choimis_seup_miss`를 한 번 재생한다. 네 변에서 들숨 획이 위·중앙·아래 고정 곡선을 따라 중앙으로 빨려 들어오고, 후반에는 중앙 손가락총이 세 줄을 쏜다. | 흡입 곡선 0.45초, 손가락총 0.55초 예고다. 예고가 끝난 뒤 하트가 움직여도 곡선과 광선은 따라오지 않는다. | 네 구석을 모두 한 번 이상 지나 영구 구석 안전지대가 없지만, 동시에 상자 전체를 덮지 않아 예고 사이로 이동할 수 있다. |
| `choimis_fashion` | “이거 패션어떰?” 뒤 원본 시트의 표범 정장, 지브라 코트, 체크 아이돌복, 하트별 점프수트가 순서대로 런웨이처럼 교차한다. | 네 의상은 0.55초 레인 예고 뒤 좌우를 번갈아 횡단한다. 각 원본 알파 bbox를 비율 유지한 48×60px 안에 그린다. | 생성된 흰 막대나 외곽선을 덧씌우지 않는다. 실제 불투명 의상 픽셀만 충돌하고 소매·바지 사이와 투명 모서리는 안전하다. DOM 없는 검사에서는 결정적인 전용 기하 폴백을 쓴다. |

## 원문과 오디오

- 랩 말풍선 원문: `요 최미스 래퍼딱지를때이젠앰씨로 포에버 포에버`.
- 스읍 말풍선 원문: `스읍 미스`.
- 패션 말풍선 원문: `이거 패션어떰?`.
- `choimis_seup`만 기존 `assets/audio/sfx/choimis_seup_miss.mp3`를 패턴 시작에 한 번 재생한다. 탄마다 효과음을 재생하지 않는다.
- 랩은 원문을 화면 가사 탄으로 나누지만, 합치면 원문의 공백 제외 문자열과 정확히 같다.

## 자산과 연동

- 패턴 모듈: `src/battle/choimis-patterns-b.js`, export `CHOIMIS_PATTERNS_B`.
- enemy projectile key `mic`: `assets/enemies/choimis-rap.png`, 320×320 RGBA, 160셀 2×2 행우선 프레임. 승인된 body bbox 123px를 공통 enemy scale 0.506과 pivot `[80,152]`로 그려 보이는 몸 높이를 62.238px로 맞춘다. 상자 안에서는 `monoPortrait` 흰 2톤으로 변환하고 같은 62px 충돌 실루엣으로 잘라 쓴다.
- enemy projectile key `fashion`: `assets/props/choimis-fashion.png`, 192×192 RGBA, 96셀 2×2 행우선 프레임. 표범·지브라·체커 아이돌·하트별 점프수트 순서로 쓴다. 이미지마다 프레임 알파 마스크를 한 번 캐시해 렌더 crop과 충돌에 같은 bbox를 사용한다. 자산이 없을 때만 결정적 분홍 의상 도트 폴백을 쓴다.
- 공유 등록은 `src/battle/bullets.js`의 `...CHOIMIS_PATTERNS_B` 한 줄이며 새 전역 Bullet shape가 필요 없다.

## 완료 판정

`tests/unit/choimis-patterns-b.test.mjs`가 registry ID, 원문 가사 순서, CJK 글꼴과 상자 여백, 실제 클립 1회, 최소 0.3초 예고, 예고 후 고정 경로, 네 의상 실루엣, 네 구석 압박과 남는 회피 공간을 검증한다. 실제 전투 검수는 각 패턴의 예고·활성·종료 프레임과 패턴 종료 뒤 꽃망토 복귀를 별도로 캡처한다.
