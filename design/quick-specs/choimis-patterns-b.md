# 최미스 전투 패턴 B

## 요청과 확정

이 문서는 최미스 보스의 `랩 → 스읍 미스 → 패션` 세 공격 계약이다. 적 체력 200과 파티 피격 피해 15는 enemy 데이터가 소유한다. BUILD297의 실제 영상·음성 랩이 이전 보이스폰트 전용 랩 해석을 대체한다.

## 원문과 오디오

- 랩 영상: `https://www.youtube.com/watch?v=LHT3XMBGO_8`의 22–41초. 런타임 파일은 `assets/video/choimis-forever-22-41.mp4`다.
- BUILD299 랩 가사 탄 원문은 enemy config `lyrics`의 `래퍼딱지를때는중이젠앰씨로 예술가의길로!@#!@$!@#@#$포에버포에버`다. 공백은 탄으로 만들지 않고, 나머지 글자는 원문 순서대로 반복한다. 조절 값은 `lyricStart`, `every`, `burstSize`, `burstPause`, `fontSize`, `speed`, `warn`, `micWarn`이다.
- 스읍 말풍선 원문: `스읍 미스`.
- 패션 말풍선 원문: `이거 패션어떰?`.
- 모든 등록 패턴은 공격 전 1인칭 프리앰블을 가진다. 신규 문구는 `내 짜장면 맛 좀 볼래?`, `핑크빛으로 물들어봐`, `짜장면 배틀 한번할까?`이며 기존 지정 문구는 바꾸지 않는다.
- `choimis_seup`만 기존 `assets/audio/sfx/choimis_seup_miss.mp3`를 패턴 시작에 한 번 재생한다. 탄마다 효과음을 재생하지 않는다.
- 랩 영상 오디오는 음소거하지 않으며 기존 BGM을 멈추거나 다시 시작하지 않는다. 게임 사운드 설정, 숨김 탭, 패턴 시계에 동기화한다.

## 자산과 연동

- 패턴 모듈: `src/battle/choimis-patterns-b.js`, export `CHOIMIS_PATTERNS_B`.
- 영상 모듈: `src/battle/choimis-rap-video.js`. 전투 진입 중 최대 3초만 디코드를 기다리고, 실패·재생 거부는 경고 상태로 남긴다. 정상 종료와 패배·재도전·취소·승리에서 요소·소스를 해제한다.
- 영상 소스/인코딩 원본: `assets/source/choimis-rap297/README.md`, `metadata.json`. 출력은 480×270,15fps,H.264 Baseline+A​AC,19.000초,1,043,724바이트다.
- enemy projectile key `mic`: `assets/enemies/choimis-rap.png`, 320×320 RGBA, 160셀 2×2 행우선 프레임. 승인된 body bbox 123px를 공통 enemy scale 0.506과 pivot `[80,152]`로 그려 보이는 몸 높이를 62.238px로 맞춘다. 상자 안에서는 `monoPortrait` 흰 2톤으로 변환하고 같은 62px 충돌 실루엣으로 잘라 쓴다.
- enemy projectile key `fashion`: `assets/props/choimis-fashion.png`, 192×192 RGBA, 96셀 2×2 행우선 프레임. 표범·지브라·체커 아이돌·하트별 점프수트 순서로 쓴다. 이미지마다 프레임 알파 마스크를 한 번 캐시해 렌더 crop과 충돌에 같은 bbox를 사용한다. 자산이 없을 때만 결정적 분홍 의상 도트 폴백을 쓴다.
- 공유 등록은 `src/battle/bullets.js`의 `...CHOIMIS_PATTERNS_B` 한 줄이며 새 전역 Bullet shape가 필요 없다.

## 완료 판정

`tests/unit/choimis-patterns-b.test.mjs`가 registry ID,19초/원문 한 글자 순서/하강 방향,정확한3초 낙하·이전 무해성,큰 프레임 간격에서의 위치·중복 방지,CJK 글꼴과 상자 여백,영상 재생·mute/pause/숨김 탭·정리,실파일 계약,최소0.3초 예고,교대 통로,네 의상 실루엣,네 구석 압박과60Hz 도달 가능 경로를 검증한다. 실제 전투 검수는 영상 움직임·원음+BGM 중첩·예고·활성·종료 프레임과 패턴 종료 뒤 꽃망토 복귀를 별도로 캡처한다.
