# 최미스 후속 핑크 슈팅 라운드 브리프

## Overview

12초 핑크 슈터 오프닝과 별개로 일반 적 턴 순환에 들어가는 세 가지18초 슈팅 라운드다. 명중 수나 장애물 제거 수로 조기 종료하지 않으며 같은 위/아래 이동과 C 탭·홀드 입력을 재사용한다.

## Shared Contract

- 전투 배우가 0.22초 페이드아웃한 뒤 보드가 하단 패널에서 `430×150`으로 열린다. 보드가 도착하기 전에는 표적·위협·하트를 그리지 않는다.
- 하트는 왼쪽 x=64에 고정되고 위/아래만 움직인다. 배경층은 왼쪽으로 흘러 전진 비행감을 만든다. C 탭은 일반탄,0.6초 홀드 후 놓기는 차징탄 한 발이다.
- 하단 패널은 `↑↓ 이동 · C 탭 발사 / 길게 눌러 충전`만 보여 준다. 명중 수·피해 규칙·종료 목표를 설명하지 않는다.
- 상자 안 최미스·다오·배찌는 `whiteSprite`로 흰색 실루엣화한다. 실제 승인 스프라이트가 없으면 캐릭터를 코드 도형으로 대신 그리지 않는다.
- 각 위협은 최소0.4초 고정 예고 뒤 발동하고, 피해는 최미스 표준15를 `hurtParty`에 한 번 전달한다. 천혈의0.55초 예고와 기존 난도는 유지한다. 프레임 건너뜀에는 이동 원의 상대 선분 충돌을 사용한다.
- 최미스는 세 라운드 모두 창 오른쪽 밖에서 들어와 끝에 자리 잡고 공격을 보낸다. 완충탄은 관통하되 표적마다 한 번만 판정한다. 최미스에게 맞은 완충탄은 즉시 공통 `hitEnemy`로1HP, 일반탄은3발당1HP를 깎는다. 장애물 명중은 제외하고 일반탄 잔여 명중은 같은 전투에서만 이어지며 재도전 때 초기화된다.
- 접촉마다 바론 바다 추격전의 `pop`(`volume:0.384, rate:0.8`)을 재사용한다. 실제 HP가 줄었을 때만 움직이는 보스의 왼쪽 위에 작은 연분홍 `-1`이0.55초 뜬다. 일반탄1·2번째 접촉이나 피해 차단은 숫자를 표시하지 않는다. 출처는 `src/scenes/baron-sea-chase.js`의 `hit/tutorial-hit` 처리이며 신규 사운드는 없다.
- 완료·패배·재도전 때 보드,하트,무적시간,최미스 포즈를 복원하고 내부 탄·효과·충전 상태를 비운다.

## Scenarios

### 쵸소우 / 천혈

- `내 추구미는 쵸소우야` 말풍선과 기존 녹음 `choimis_chosouya`1.7초 전체 재생(글자 블립 없음)→쵸소우 복장 변신→`천혈!` 순서 뒤 최미스가 상자 오른쪽에서 4초 주기·상하38px로 움직인다. 실제 클립이 아직 재생 중이면 변신을 기다리고 중단 때 핸들을 정리한다.
- 0.55초 동안 피가 움직이는 최미스 쪽으로 모이고 점선 조준 경로를 고정한 뒤0.38초 혈광선과 뒤따르는 무해한 비산을 그린다. 세 번째 발리마다 위·아래 두 줄을 함께 쏜다.
- 보스가 맞아도 빔·발리·18초 라운드는 멈추지 않는다. 예고와 실제 판정선은 같은 고정 목표를 사용하고 발사 원점은 움직이는 보스에 붙는다.

### 막자할게

- `막자할게` 말풍선 뒤 실제 다오·배찌와 차량이 함께 있는 `daoKart/bazziKart` 에셋이 세 차선을 번갈아 오른쪽에서 진입한다. 서 있는 캐릭터나 코드로 그린 차체를 대신 쓰지 않는다. 표시 폭50px, 원본 종횡비 보존, 흰색 변환을 사용한다.
- 각 카트는0.45초 차선 점선 예고 뒤170px/s로 왼쪽으로 달리고 출발0.65초/0.81초 뒤255px/s 부스터를 쓴다. 이전 카트가 남아 있어도1.2초마다 두 대를 보내며 빈 차선은 중간→위→중간→아래를 반복한다. 차선 간47px 이동에126px/s 하트가 약0.373초 걸리며 실제18초 회피 시뮬레이션으로 통로를 검사한다.
- 기존 `kart_booster`는 출발/부스트 때만 짧게0.28초 재생한다(음량0.18/0.24). 파괴에는 바론 명중음 `pop`을 쓴다. 원본은 `assets/source/kartrider-v1/README.md`에 기록된 유튜브 효과음 모음0.0~2.8초 구간이며 새 합성은 없다.
- 카트를 쏘면 제거되지만4명 이후에도 새 물결이18초 동안 계속 나온다. 카트와 하트,탄과 카트는 양쪽의 이전·현재 좌표를 함께 쓰는 연속 충돌이다.

### 핑크 프리즘

- 시작 말풍선은 `차징해서 쏜 공격 아닌 이상 이 코어들은 무너지지 않아.`를 완독한 뒤 전투를 시작한다.
- 최미스 앞 코어 주위를 방패3개가 회전하고,0.4초 예고 뒤170px/s 볼트가 두 차선으로 지나가며 빈 차선을 바꾼다.
- 일반탄은 방패에 막힌다. C를 끝까지 충전한 탄은 닿는 방패를 깨고 뒤로 관통하며, 패널 안내가 충전 규칙을 명시한다.
- 방패3개를 모두 깨면 코어와 뒤의 보스를 쏠 길이 열린다. 코어 명중 수와 무관하게 볼트는18초까지 계속 나온다.

## Production Route

- 적 패턴 config는 `mode:'choimis_pink_round'`와 `scenario:'choso'|'kart_block'|'pink_prism'`을 사용한다.
- `battle.js`는 선택한 config를 모드에 그대로 넘기고 패턴 인덱스를 한 번만 증가시킨다.
- 장애물 명중과 보스 HP는 분리한다. 보스 완충탄 명중은 즉시, 일반탄은3회마다 `hitEnemy(enemy,null,1,{source:'pink-shot',sound:false})`를 부른다. 보스가 죽으면 즉시 위협·탄·충전음을 정리하고 공통 승리 흐름으로 복귀한다.

## Acceptance Criteria

- 세 라운드는 준비 대사/변신을 제외한 실제 전투18초가 끝날 때만 완료되며 과거 명중·제거 수를 넘어도 위협을 계속 낸다.
- 움직이는 표적·카트는 큰 `dt`에서도 관통하지 않으며, 만료된 빔은 늦은 피해를 주지 않는다.
- 카트의 비어 있는 차선과 고정된 빔 예고에는 실제 회피 경로가 남고, 천혈의 기존0.55/0.38/1.15초 난도는 바뀌지 않는다.
- 보드 트윈 전 새 아레나가 먼저 나타나지 않고, 종료 뒤 공유 전투 상태가 복원된다.
