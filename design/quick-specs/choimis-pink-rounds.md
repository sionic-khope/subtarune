# 최미스 후속 핑크 슈팅 라운드 브리프

## Overview

20초 핑크 슈터 오프닝과 별개로 일반 적 턴 순환에 들어가는 세 가지 목표형 슈팅 라운드다. 각 라운드는 보스 HP와 독립된 내부 명중 조건을 만족해야 끝나며, 같은 위/아래 이동과 C 탭·홀드 입력을 재사용한다.

## Shared Contract

- 전투 배우가 0.22초 페이드아웃한 뒤 보드가 하단 패널에서 `310×150`으로 열린다. 보드가 도착하기 전에는 표적·위협·하트를 그리지 않는다.
- 하트는 왼쪽에 고정되고 위/아래만 움직인다. C 탭은 일반탄,0.9초 홀드 후 놓기는 차징탄 한 발이다.
- 하단 패널은 현재 목표와 `↑↓ 이동 · C 탭 발사 / 길게 눌러 충전`을 공유 글꼴로 계속 보여 준다.
- 상자 안 최미스·다오·배찌는 `whiteSprite`로 흰색 실루엣화한다. 실제 승인 스프라이트가 없으면 캐릭터를 코드 도형으로 대신 그리지 않는다.
- 각 위협은 최소0.5초 고정 예고 뒤 발동하고, 피해는 최미스 표준15를 `hurtParty`에 한 번 전달한다. 프레임 건너뜀에는 이동 원의 상대 선분 충돌을 사용한다.
- 완료·패배·재도전 때 보드,하트,무적시간,최미스 포즈를 복원하고 내부 탄·효과·충전 상태를 비운다.

## Scenarios

### 쵸소우 / 천혈

- `내 추구미는 쵸소우야` 말풍선 뒤 쵸소우 복장의 최미스가 상자 오른쪽에서 4초 주기·상하38px로 움직인다.
- 첫 빔에 `천혈!`을 말하고,0.55초 점선 예고 때 경로를 고정한 뒤0.38초 발사한다. 세 번째 발리마다 위·아래 두 줄을 함께 쏜다.
- 움직이는 최미스에게 실제 탄을6번 맞혀야 종료한다. 여섯 번째 명중 프레임에 남은 빔을 즉시 제거한다.

### 막자할게

- `막자할게` 말풍선 뒤 승인된 다오·배찌 전투 스프라이트가 세 차선을 번갈아 오른쪽에서 진입한다.
- 각 카트는0.5초 차선 점선 예고 뒤 왼쪽으로 달린다. 다른 차선으로 피한 하트는 피해를 받지 않고, 놓친 카트는 왼쪽으로 빠져나가면 사라진다.
- 실제 탄으로 카트4명을 제거해야 종료한다. 카트와 하트,탄과 카트는 양쪽의 이전·현재 좌표를 함께 쓰는 연속 충돌이다.

### 핑크 프리즘

- 오른쪽 코어 주위를 방패3개가 회전하고, 세 차선 볼트가0.5초 예고 뒤 지나간다.
- 일반탄은 방패에 막힌다. C를 끝까지 충전한 탄만 방패 하나를 깨며, 패널 안내가 이 규칙을 명시한다.
- 방패3개를 모두 깬 뒤 코어에 일반 또는 차징탄을3번 맞혀야 종료한다. 마지막 명중 프레임에 남은 볼트를 제거한다.

## Production Route

- 적 패턴 config는 `mode:'choimis_pink_round'`와 `scenario:'choso'|'kart_block'|'pink_prism'`을 사용한다.
- `battle.js`는 선택한 config를 모드에 그대로 넘기고 패턴 인덱스를 한 번만 증가시킨다.
- 내부 탄은 `hitEnemy`를 부르지 않으며 강화된 최미스 방어력이나 본체 HP를 바꾸지 않는다.

## Acceptance Criteria

- 시간 경과만으로 어느 라운드도 완료되지 않고, 지정된 실제 명중 수에만 완료된다.
- 움직이는 표적·카트는 큰 `dt`에서도 관통하지 않으며, 만료된 빔은 늦은 피해를 주지 않는다.
- 카트의 비어 있는 차선과 고정된 빔 예고에는 실제 회피 경로가 남는다.
- 보드 트윈 전 새 아레나가 먼저 나타나지 않고, 종료 뒤 공유 전투 상태가 복원된다.
