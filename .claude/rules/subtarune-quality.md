# 섭타룬 프로젝트 판단 원본

구현·기획·검수는 `docs/development/quality-contract.md`에서 해당 작업 스킬을 골라 읽는다. 최신 사용자 확정과 프로젝트 공통 계약이 범용 스튜디오 템플릿의 파일별 승인 절차·엔진 가정·과거 수치보다 우선한다. 스프라이트 생성/코드 통합 담당은 `subtarune-sprite-handoff`를 따른다.
