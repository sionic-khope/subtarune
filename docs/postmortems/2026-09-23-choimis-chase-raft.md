# 최미스 추격 뗏목 고립

## 원인과 재현

벚꽃숲6 최초 횡단은 `raft_sakura6_raft=1`을 저장해 뗏목을 동쪽 x1164에 둔다. 이후 최미스 도주·나무 충돌·변신 연출은 일행만 숲5로 이동한다. 추격하며 숲6 서쪽으로 다시 들어가도 기존 동쪽 뗏목 위치가 유지되어 C로 탈 수 없었다. QA 지점만의 문제가 아니다.

실제 C 횡단과 도주/변신 스크립트 뒤 서쪽 진입을 재현했다. 플레이어 x279.86544, 뗏목 at1/x1164/visible=true/image=true/dead=false에서 탑승이 실패했고, 같은 상태의 뗏목 끝점만0으로 바꿔 재로드하면 C로 양쪽 동료와 건널 수 있었다. 상세 red/toggle 증거는 `.omc/evidence/raft306/red/run-ooQYdF`다. 중간 숲7/8·절벽 대화와 이미 지나온 길은 명시적 준비로 생략했으며, 전 게임 무보정 완주를 뜻하지 않는다.

## 수정 경계

변신 완료 후 숲6의 첫 일반 진입에서만 현재 플레이어와 가까운 강변 끝점으로 뗏목의 실제 위치·그림 위치·저장 끝점을 함께 맞춘다. 준비 완료를 별도 저장해 이후 정상 왕복을 재설정하지 않는다. `runMapEnter`는 이어하기의 저장 좌표 복원 후 호출되므로 기존 서쪽 고립 세이브도 복구하고 동쪽 세이브는 동쪽에 유지한다. 변신 전·도주 몽타주 진행 중·다른 맵에는 적용하지 않는다.

## 검증 기준

`tests/unit/choimis-chase-raft.test.mjs`는 실제 Game 맵 진입 메서드와 Raft 위치 갱신을 사용한다. 서쪽 복구·동쪽 유지·단회 처리·변신 전/다른 맵/대화 중 비개입을 확인한다. `tests/playtest/choimis-chase-raft.mjs`는 실제 최초 횡단→변신→재진입→C 추격 횡단, 서쪽/동쪽 저장 복원, 역방향 횡단, 이전 버전 세이브 양쪽 강변을 확인한다. 최종 결과와 SHA는306 증거 장부에 기록한다.

스토리 연출로 일행만 다른 맵으로 옮길 때는 일회성 대사 플래그뿐 아니라 **이동 수단의 저장 위치와 다음 접근 강변**을 함께 점검한다. 새로운 QA 지점에서 잘 된다는 결과로 기존 진행 기록이 있는 재방문 경로를 대체하지 않는다.
