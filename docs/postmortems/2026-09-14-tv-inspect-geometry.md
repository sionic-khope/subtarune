# TV 그림 전체 조사 누락

BUILD146은 TV 조사 폭을 그림과 같은 288px로 늘렸지만 높이는 바닥의 12px 띠(y196~208)로 유지했다. 바닥은 y192에서 시작하고 C 프로브는 플레이어보다 19.2px 앞이므로, 위로 끝까지 걸으면 프로브가 띠를 지나 그림 안쪽으로 들어가 조사에 실패했다.

기존 검사는 y216에서 좌우 폭만 확인해 모두 통과했다. 실제 방향키로 벽까지 접근한 좌·중·우 세 지점은 y192.5~192.7에서 target=null이었고 C가 응답하지 않았다. 같은 브라우저에서 검사 높이를 그림 전체(y32~208)로 바꾸면 대상이 잡히고 원복하면 다시 놓쳤다.

수정은 엔티티 상대 `inspectRect:{x,y,w,h}`를 C 판정에만 적용한다. 생략하면 기존 `overlaps` 동작을 유지한다. TV 화면 앵커의 충돌·연출 좌표 x528/y196/w288/h12와 개그·음악·그림은 그대로 두고 조사 사각형만 TV 그림 x528/y32/w288/h176에 맞췄다.

회귀 기준은 C가 되는 한 지점이 아니라 실제 접근로의 끝이다. 새 단위 검사 세 개는 수정 전 실패/후 통과했고, `tests/playtest/tv148.mjs`는 방향키로 전면 세 지점과 양옆에 접근한 뒤 C를 누른다. TV 뒤·윗면은 벽이라 진입 가능한 길이 없으며, 전면 접근에서 더 위로 이동할 수 없는 것도 함께 확인한다. 첫 조사 후퇴·책 개그·카메라 복귀도 검사한다. QA 시작 위치 배치는 fixture이며 전체 스토리 완주 검증은 아니다.

실제 화면·원시 결과는 `tests/playtest/shots/tv148/{before,after}/`에 보관한다. 앞으로 큰 사물의 조사 영역을 조정할 때는 그림과 조사 사각형을 대조하고, 가까이 붙었을 때 프로브가 얇은 영역을 넘어가는 경우를 포함한다.
