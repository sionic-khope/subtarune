# 포스트모텀: 컷신 배우 스프라이트가 문자 도트로 뜨고 초상화가 비던 문제 (2026-09-20)

## 사건과 영향

사용자가 GitHub Pages 빌드와 로컬 서버 양쪽에서 같은 현상을 봤다. 조종실(youngcle20)에서 영클이 작은 네모 캐릭터로, 토리이 길 합류 장면에서 청소부가 아예 보이지 않고, 나람의 초상화가 빈 얼굴로, 조종실 회복 연출의 버섯이 보라 반투명 네모로 떴다. 요플래·억빠맨·경섭은 멀쩡했다. 사용자 말 그대로 “요플래나 억빠맨 같은 건 잘 관리하면서 다르게 관리하고 있는 거냐”가 맞았다.

| 증상 | 실제 원인 | 확인한 근거 |
|---|---|---|
| 청소부(토리이)가 안 보임, 웃음 모션 없음 | 컷신 `spawn` 배우의 시트·모션이 맵 준비 목록에 없어 문자 도트 폴백(16px)으로 그려짐 | 헤드리스에서 `sprites/janitor.png` 요청 자체가 없음(초상화만 요청). `jjajang-torii-janitor` 플레이테스트가 “껄껄 모션”에서 실패 |
| 영클이 작은 네모 | 같은 폴백. 시트가 늦게/못 오면 `characterSprite` 가 폴백을 이름으로 캐시해 세션 내내 못 갈아탐 | `spriteCache.set(name, 폴백)` 경로. 늦게 시트를 넣어도 엔티티는 폴백 유지 |
| 나람 초상화 빈 얼굴 | 초상화 파일이 없는 캐릭터는 걷기 시트 얼굴을 잘라 쓰는데, 시트가 없으니 빈 얼굴 | `makePortraits` 는 `spriteOverrides[name]` 이 있어야 얼굴을 만든다 |
| 버섯 보라 네모 | 소품 그림이 맵 준비 목록에 없음 → `Prop` 의 ‘그림 없음’ 폴백 | `propImages` 에 `editor-union-mushroom.png` 없음 |
| 한 번 끊기면 계속 안 나옴 | `MapAssetCache.image` 가 실패(null)를 캐시, 로더는 재시도 없음 | Pages 에서 시트 하나만 끊겨도 그 세션은 끝까지 폴백 |

## 원인

- **준비 목록의 빈틈**: 맵을 준비할 때 받는 시트는 동료 + 맵 엔티티 `sprite` + `preload` + `MAP_RUNTIME_ASSETS` 뿐이었다. 컷신이 `{ spawn:{ sprite } }` 로 만드는 배우는 어디에도 없었다. 81개 맵을 감사하니 토리이(청소부·그림자)·청록숲3(CS)·라운지(가재맨 그림자) 세 곳이 이 빈틈에 있었다. 지금까지는 다른 맵에서 먼저 받아 둔 세션에서만 보였다(“잘 안 뜸”).
- **폴백을 영구 캐시**: `characterSprite(name, override)` 가 `override` 없이 만든 문자 도트 세트를 `name` 키로 캐시했다. 이후 시트가 도착해도 새 엔티티까지 폴백을 받는다.
- **실패를 기억하는 캐시 + 재시도 없음**: 그림 로더가 null 을 돌려주면 자산 캐시가 그 null 을 세션 내내 돌려줬다.
- **사람이 목록을 손으로 관리**: `MAP_RUNTIME_ASSETS` 에 배우를 적는 걸 잊으면 바로 재현된다. 새 맵마다 같은 실수를 반복할 구조였다.

## 재발 방지 적용 위치

- `src/main.js mapScriptAssets`: 맵의 스크립트(진입·엔티티·문·뗏목 스크립트)를 훑어 `spawn.sprite` 를 모아 준비 목록 `names` 에 넣는다 — 시트·모션·초상화가 같은 경로로 준비된다. **컷신에 배우를 spawn 할 때 더 이상 목록을 손으로 적지 않아도 된다**(적어도 되고, 빠뜨려도 준비된다).
- `src/world/world.js characterSprite`: 시트가 있어야 할 캐릭터의 폴백은 `#fallback` 키로 따로 캐시하고 `fallback` 표식을 남긴다. `Character.drawSprite` 가 폴백이면 `game.requestSheet(name)` 을 불러 도착 즉시 갈아탄다(초상화 파일 없는 캐릭터는 시트 얼굴 초상화도 갱신).
- `src/core/gfx.js loadImageOptional`: 실패 시 0.4·0.8초 뒤 두 번 더(주소에 nonce). `src/core/map-assets.js`: 실패는 캐시하지 않는다.
- `src/world/world.js Prop`: 없는 그림은 `game.requestPropImage` 로 받아 끼운다(보라 네모 대신).
- 검사: `tests/unit/asset-loading.test.mjs`(캐시·재시도·폴백 계약), 플레이테스트 `assets-late-load`(시트 첫 요청을 500으로 막고 재시도·지연 적재 확인), `jjajang-torii-janitor`(spawn 배우 시트·모션).
- 남는 규칙 하나: **필드에서 캐릭터가 작은 네모(문자 도트)로 보이면 그 자체가 버그다.** 폴백은 개발 중 임시 표시이지 완성 화면이 아니다. 스크린샷 검증 때 배우가 도트 폴백이면 통과시키지 않는다.

## 수정 범위와 상태

BUILD268(버섯 보라 네모·소품 지연 적재)과 BUILD269(spawn 배우 준비·폴백 갈아타기·로더 재시도·실패 비캐시)로 main 에 반영·배포했다. 감사한 세 맵은 모두 새 경로로 준비된다. 조종실 영클 네모는 같은 폴백 현상이라 같은 수정으로 덮이지만, 배포 뒤 사용자 화면에서 다시 보이면 그 장면의 QA 지점으로 재확인한다.
