BUILD189 를 본 사용자의 지적 7건. 셋은 **같은 날 무대 홀·대기실에서 이미 지적받은 유형의 재발**(순간이동, 시선, 자동 시작)이라 “재발 안 하게 하라고, 인간적인 자연스러움을 생각하라고”가 붙었다.

## 검수 절차에 추가 (컷신·기믹 공통)
1. **시작 조건**: 브리핑의 동사(타면·누르면·말 걸면 / 들어오면·지나가면)대로 C 또는 트리거인지 확인.
2. **순간이동 0건**: 컷신 중 사람이 화면에서 위치가 뛰는 곳이 있는가 — board/swim/spawn/맵 스폰 뒤 정렬 모두. 걸어가는 `move` 가 앞에 있어야 한다.
3. **시선**: 뒤돌아본 채 오가는 대사가 있으면 그 대사 끝까지 유지.
4. **뗏목 길은 한 줄**, 규칙이 다른 장애물은 색·굵기 다른 그림 + 안내.
5. **최신 지시 우선**: 앞 지시와 충돌하면 새 지시로 덮고, 남은 것은 만들지 않는다.
6. 그리기 코드를 만지면 다른 맵 스크린샷도 찍는다.
