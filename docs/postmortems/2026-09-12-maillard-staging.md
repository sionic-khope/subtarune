# 마이야르호 카트·일출 연출 실패 회고

2026-09-12 · BUILD .107 사용자 반려 → .108 수정

## 사용자가 겪은 문제

- 오른쪽 계단 끝에서 C가 먹지 않아 왼쪽으로 돌아봐야 갑판에 들어갔다.
- 카트 속도가 느렸고 하체가 차체 밖으로 보였다. 하차 후에는 형섭만 먼저 가고 동료가 남았다.
- 14초 음악 하이라이트 전에 이미 해와 빛이 상당히 드러났다. 화면 중간의 넓은 갑판과 인물이 원경을 가렸고, 해는 웅장한 장면의 주인공이 되지 못했다.
- 자동 탑승을 .107에서 요청했지만 이번 피드백으로 **C 탑승·첫 탑승음**이 최신 규칙이 됐다.

## 원인과 잘못된 완료 판정

구현·검토를 맡은 Codex의 실패다. 사용자의 설명이나 모델 이름으로 책임을 돌리지 않는다.

1. 문 근처의 성공 위치만 확인했다. 실제 사용자가 오른쪽 벽까지 이동한 위치에서 전방 프로브가 문을 지나치는 경계를 놓쳤다.
2. `riding:true`와 카트별 위치를 탑승 표현의 증거로 삼았다. 차체의 앞뒤 가림과 허리 아래 픽셀을 보지 않았다.
3. 하차 직후 형섭의 이동만 확인했다. 주행 전에 남은 발자국과 동료의 계속 걷기를 확인하지 않아 “조작 복귀”를 “파티 이동 복귀”로 잘못 보고했다.
4. 음악 시간을 수치로 검증하면서 기다림·첫 빛·상승·잔상을 한 장면으로 판단하지 않았다. 14초가 클라이맥스라는 설명을 해가 이미 올라온 상태로 바꿨다.
5. 리뷰 PASS를 사용자의 미적 만족으로 확대했다. 이전 리뷰의 승인에도 하체 노출과 동료 지연이 남아 있었다. 테스트 수와 리뷰 수는 장면 품질의 근거가 아니다.

## 다음 연출 작업의 완료 기준

1. 최신 지시를 **입력 → 준비 → 주요 변화 → 후속 이동** 네 단계로 적는다. 입력 조건이 바뀌면 코드·테스트·DESIGN을 같은 기준으로 갱신한다.
2. 문은 사용자가 접근하는 방향으로 끝까지 걸은 자리에서 눌러 본다. 탈것은 C 전 정지, C 후 소리와 탑승 가림, 하차 후 전원 보행까지 한 번 이어서 본다.
3. 동료가 포함된 전환은 전원의 위치·안전한 바닥·탈것 밖 배치·보행 추종·이어하기를 확인한다. 하차 프레임만 찍고 종료하지 않는다.
4. 웅장한 장면은 아래 구도·시간·크기 기준을 함께 만족해야 한다. 자체 설정값 일치와 한 장의 예쁜 스크린샷만으로 완료라고 보고하지 않는다.
5. 확인은 바뀐 연출 한 흐름과 발견된 버그의 회귀에 한정한다. 실패하면 원인을 고치고 해당 흐름을 다시 본다. 관계없는 게임 전체나 여러 리뷰 반복으로 대신하지 않는다.

## 웅장함의 기준

- **구도:** 주요 원경 앞에 충분한 빈 공간을 둔다. 이번 장면은 발 위치를 360px 화면의 약300px에 두고, 주행로는 한 타일 폭 레일로 압축한다. 상단 대부분을 하늘·수면이 차지하며 다음 층 갑판이 해를 덮지 않아야 한다.
- **크기 대비:** 주인공 얼굴보다 조금 큰 장식으로 끝내지 않는다. 이번 해 지름은196px로 화면 폭의 약41%, 인물 키의 약3배다. 작게 보이는 인물과 거대한 원경이 동시에 읽혀야 한다. 배경/보스별 실제 화면 예산에 맞춰 판단한다.
- **기다림과 공개:** 중요한 순간 전에 결과를 미리 보여주지 않는다. 이번에는14초까지 해가 수평선 아래에 있고,14~42초 동안 드러난다.후속 .109 피드백에 따라14초 이전은 훨씬 어둡게 유지하고14~30초에 밝기가 열린다. 처음부터 밝은 노을을 보여주면 밝아지는 순간의 힘이 사라진다.
- **속도 분리:** 카트의 전진감과 태양의 무게감은 서로 다른 속도다. 카트는128px/s,3072px 선로에서24초 주행한다. 해는28초 상승한다. 속도를 바꾸면 음악14~30초 탑승 구간을 유지하도록 선로 길이도 함께 계산한다. 해를 보여주려고 음악을 되감거나 탑승을 강제하지 않는다.
- **음악과 빛:** 실제 재생 시계를 쓴다. 하이라이트 전·첫 빛·중간·완료를 이어 보며 의미 있는 박자에 변화가 시작되는지 판단한다. 탑승 시계로 음악/해를 재시작하지 않는다.
- **절제:** 크기·구도·시간으로 먼저 힘을 만든다. 임의의 섬광·효과음·장식을 늘려 웅장하다고 주장하지 않는다. 요청된 탑승음은 기존 목재 충격음으로 연결한다.

## 수정과 증거

.110 추가 실패: 이동이 느리다는 피드백에 속도를 올리면서 선로를 그대로 둬 음악 약18초에 하차하게 만들었다. 노을의14~30초 전개와 탑승 구간이 겹쳐야 한다는 장면 의도를 누락했다. 속도와 선로 길이를 함께 설계하고, 이후 검사는 탑승 시간만이 아니라 음악14·24·30초의 실제 탑승 상태를 확인한다. 수정은 속도 유지·선로2.4배·24초 탑승이며 탑승8초 후 전원이 노을 쪽을 본다.

계단 판정 확장, C 탑승/목재 충격음, 속도2배, 하단 전용 레일, 승객 하체 클리핑, 안전한 전원 하차와 발자국 복원, 늦고 큰 일출을 적용했다. 실행 증거와 배포 상태는 `docs/STATE.md`의 .108 항목이 최신이다. 체감에 대한 최종 평가는 사용자의 실제 플레이 피드백을 따른다.
