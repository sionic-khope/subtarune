# 2026-09-18 색깔 게임 뒤 복귀 연출 — QA 지점은 통과하는데 실제 진행에선 쥰희·용준이 용암 위에 남음 (#22)

## 증상
사용자: “색깔 버튼 누르기 이벤트에서 성공 후에 쥰희랑 용준이 안 뜨는 버그”, “TV 내려올 때 용암에서 걸어 내려오네”. 폭발·“부활이다” 때 둘이 안 보이고, 모이기 이동에서 화면 위(용암)에서 걸어 내려온다. `tests/playtest/color-game.mjs`(QA `furnace_color`)는 통과.

## 원인
`src/world/world.js` 흔들리는 소품(`def.oscillate`)의 carry: 흔들림이 끝나는 프레임에 `lastPos`(직전 프레임 위치) 기준 이동량을 탑승자에게 통째로 태웠다. 복귀 연출(`furnace_arena.js AFTERMATH`)은 철창·둘을 `setPos` 로 360 올린 직후 흔들림을 끄므로, 그 프레임에 둘이 360 더 올라가(합 720) slide 360 으로 내려와도 360 위(y −146 → hop 뒤 −76)에 남았다. QA 지점은 인트로(흔들림)를 안 거쳐 `osOff` 가 없어서 재현되지 않았다.

## 수정
흔들림 종료 프레임의 carry 이동량을 “오프셋 걷는 만큼”으로 제한(`lastPos` 를 오프셋 걷기 직전 위치로 갱신). 재현·검증 `tests/playtest/furnace-revive-real.mjs`(갈림길 → 인트로 전부 → `furnace_panel` → `__colorgame.finish(true)` → 둘의 좌표 추적).

## 교훈
- **QA 지점 통과 ≠ 실제 진행 통과.** 앞 연출이 남기는 상태(흔들림·carry·오프셋·플래그)에 기대는 연출은 실제 경로로 한 번 더 돈다. 상태를 남기는 엔진 기능(oscillate/carry)을 쓰는 연출엔 실제 경로 플레이테스트를 하나 둔다.
- 재현 프로브는 좌표 추적(y 궤적)으로 잡는다 — “안 보인다”는 대개 화면 밖 좌표다.
