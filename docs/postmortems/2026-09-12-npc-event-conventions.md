# NPC 대화에서 기존 연출을 놓친 원인과 적용 기준

## 다음 이벤트를 만들 때

1. 보상·반복 대화·이동·소리·QA 중 해당하는 항목을 아래 표에서 찾고 실제 기존 호출을 읽는다. 완료 기준은 각 항목에 재사용한 파일과 노드를 말할 수 있는 상태다.
2. 첫 대화와 재대화의 노드 경로를 나눠 작성한다. 재대화에서는 첫 인사·이동·특수 연출·보상이 실행되지 않는지 확인한다.
3. 일반 대화는 말을 건 위치를 유지한다. 명시적인 사건에만 필요한 인물의 짧은 보행을 쓰고, 순간 재정렬을 대화 준비로 넣지 않는다. 정지 화면의 겹침을 없애려고 불필요한 행진을 만들었던 것이 이번 실패다.
4. 실제 첫 대화와 두 번째 대화, 보상 표시/소리 또는 사건 전후만 재생한다. 연출 요청에서 인물 위치와 소리 시작 순서는 테스트 수보다 직접 본 화면이 기준이다.

## 기존 구현에서 선택할 것

| 상황 | 기존 구현 | 적용 기준과 이유 |
|---|---|---|
| 아이템 획득 | `src/data/cutscenes/teal4_events.js`, `teal3_toolbox.js` | 획득 시 `{sfx:'item'}`와 `{c=yellow}아이템 이름{/c}`를 함께 사용한다. 보상 수치만 넣으면 플레이어에게 받은 순간이 전달되지 않는다. |
| 반복 가능한 상호작용 | `src/data/scripts.js`의 `living_tv`, `src/data/cutscenes/void9_events.js` | 완료 플래그 분기를 연출 앞에 둔다. 검사 이전에 카메라/이동/소리를 넣으면 재대화도 이벤트처럼 보인다. |
| 버프·동료 합류 | `teal9_boss.js`, `void4_ppaman.js`, `void11_tree.js` | 기존 획득음·노란 결과·해당 효과를 재사용한다. 연출과 실제 상태 변경, QA 상태 복원이 일치해야 한다. |
| 인물 이동·카메라 | `src/ui/cutscene.js`의 `move`, `face`, `camera` | 말을 건 사람을 불필요하게 옮기지 않는다. 사건에 필요한 이동은 상대 좌표와 실제 보행으로 표현하고, 변경한 카메라만 복귀한다. `regroup`은 필요한 파티 복원이지 기본 인사 동작이 아니다. |
| 소리·음악 | `src/core/audio.js`, `src/main.js`의 소리 등록 | 기존 소리를 먼저 찾는다. 정적→대사→효과음 순서를 지키고, 명시적인 음악 변경 없이 같은 맵 BGM을 다시 시작하지 않는다. |
| 점프·낙하·표정 | `src/ui/cutscene.js`의 `hop`, `fling`, `emote`, `motion` | 기존 노드를 사용하고 장면에 필요한 효과만 호출한다. 침묵을 위한 대사에는 `voice:'none'`을 준다. |
| Q 메뉴 | `src/core/story.js`의 `QA_POINTS` | 맵 또는 특정 연출·이벤트 단위로 추가한다. 평범한 NPC마다 '앞' 지점을 만들지 않는다. 자동 테스트의 준비 좌표는 메뉴와 분리한다. |

## 2026-09-12 스캔 범위와 분류

`src/data/cutscenes`의 32개 파일과 `src/data/scripts.js`, 관련 월드/대화/오디오/저장/전투 코드를 대상으로 보상 변경, 색상 태그, 효과음, 완료 분기와 연출 노드를 검색하고 호출 문맥을 확인했다. 모든 맵을 실제 플레이했다는 의미는 아니다.

직접 `inventory.push`는 10곳이다: `scripts.js`의 보라색 코드·테스트 열쇠, `maillard_npcs.js` 에그타르트, `void9_events.js` 먼지, `obj5_chase.js` 나무총, `obj2_events.js` 바나나, `teal4_events.js` 두 바나나 분기, `teal3_toolbox.js` 바나나2개, `void4_key.js` 열쇠. 버프 변경은 `teal9_boss.js`, 전투 돈은 적 정의와 전투 결과/스토리 복원이 소유한다.

- 이번 누락 확정: 에그타르트의 획득음·노란색. 기존 방식을 적용했다.
- 이번 연출 오류: 착검 일반 대화의 강제 재배치, 인사 이후에 있던 반복 분기, 위믹스의 너무 이른 소리와 세로로 겹친 파티. 각각 위치 유지·선행 분기·침묵과 인지 대사 뒤 재생·필요한 짧은 보행으로 수정했다.
- 별도 문맥인 곳: 나무총은 획득음이 있지만 전용 승선 연출에 노란 획득 문장이 없다. 보라색 코드는 3D 서랍 장면과 노란 결과가 있으며 일반 획득음 호출은 별도로 없다. 테스트 열쇠도 노란 문장만 있다. 이들은 검색 결과만으로 버그라고 단정하거나 사용자 대사/소리를 일괄 변경하지 않았다.

원인: 새 스크립트의 상태 변경과 화면 사각형만 맞추고, 기존 보상 표현과 실제 대화 흐름을 기준으로 삼지 않았다. 이후 작업은 위 절차로 기존 동작을 먼저 찾고 해당 장면만 확인한다.
