# 달빛 해안: 수평선 아래라는 숫자와 실제 수면의 차이

사용자는 뗏목과 수영하는 동료가 먼 바다를 배경으로 하늘을 헤엄치는 것 같다고 지적했다. 네 물길 모두 충돌용 빈칸 `! / backdrop_void`이어서 화면에 고정한 원경만 비쳤다. 뗏목의 화면 y161이 수평선 y138 아래라는 검사로는 원근과 접촉면을 검증할 수 없었다. 이전 통과 보고는 그 시각 요구를 놓쳤다.

BUILD293은 원경을 없애거나 배우만 옮기지 않고, 물길에 월드 좌표의 가까운 물과 작은 물비늘을 그린다. 파도·물가가 땅과 함께 스크롤하며, 두 동료와 뗏목의 실제 물 접촉선에 잔물결이 붙는다. 첫 시안의 긴 돌 테두리는 수영장처럼 읽혀 제거하고 원경에 섞이는 경계로 교정했다. 이동 경로와 충돌은 변경하지 않는다.

검수는 네 구간의 출발·중간·착지와 전원 추종을 각각 본다. 도형 포함/실제 렌더 알파 검사는 물이 존재한다는 보조 증거이며, 그림의 거리감과 물가 연결은 독립 화면 검수로 판단한다. 주행 중 카메라 이동까지 확인하고, 숫자 PASS를 사용자 만족으로 바꾸지 않는다.

중간 배치 검수 후 직접 귀환해 걸어가 보니 좁은 수면 다각형의 옆면이 대각선으로 드러났다. 네 물길의 가까운 물을 맵 너비보다 좌우480px 넓게 연장하고 뒤32px·아래48px를 원경에 섞었다. 마지막 뗏목 왕복 뒤320px를 더 걸어가는 캡처를 회귀 검사에 추가했다. 이전 검수 승인으로 새 수정본까지 승인하지 않고22개 새 화면으로 독립 재검수했다.

검수 도중 호스트 메모리 압박과 캡처 지연으로 중간 시점을 놓치는 별도 문제가 드러났다. 승선 화면을 찍은 다음 관찰기를 등록하면 뗏목이 이미 지나가 있을 수 있었다. 관찰기를 실제 C 입력 전에 등록하고 캡처용 정지만 명시적으로 적용했다. 캡처용 정지는 자연 주행 완료 증거와 구분하며, 위치·속도·게임 시간을 조작하지 않는다. 오래된 고아 테스트 브라우저 정리는 사용자 동의 후 확인한 대상에만 수행했다.
