# 섭리오 (SUBRIO) — 스크린 속 2D 플랫포머

2026-09-15 사용자 브리핑. 엄청 대박인 배 비데 방의 거대 게임 스크린 안으로 토관을 타고 들어가 노는 “게임 속 게임”. 마리오풍 도트 사이드뷰이지만 조작은 이 게임 규칙(C 공격·X 방어)을 따른다. 구현은 `src/scenes/subrio.js`(진행·그리기·소리)와 `src/scenes/subrio-core.js`(순수 규칙), 진입은 `bidet_pipe_enter`(토관 C) → 스크린이 화면 가운데로 잡히며 줌인 → `{ scene3d: 'subrio', flag: 'subrio_cleared' }`.

**구성(2026-09-15 사용자 확정)**: 월드 1 스테이지 형식. 들어가면 먼저 **1-0 튜토리얼**(움직여라·점프해라·공격해라 팻말, 억빠맨 밟기 시범, 훈련 토템)에 떨어지고, **1-1 트위치(보라)·1-2 치지직(청록)·1-3 숲(파랑)**(각 3분 분량, 방송 플랫폼 섬의 롤 몬스터들이 걸어 다님) → **1-4 따듯한비데 보스전**. 각 섬은 **몬스터를 다 잡은 뒤 깃발 앞에서 C** 로 넘어간다(오른쪽 위 ‘남은 몬스터 N’). 보스를 이기면 씬이 `found` 로 끝나 `subrio_cleared` 플래그가 선다(Esc 는 `cancel`, 플래그 없음).

**체력(2026-09-15 사용자 재지시: “맞으면 깎이게”)**: 주인공이 맞으면 **RPG 체력**(`game.partyHp`, 인게임 메뉴와 같은 값)이 깎인다 — 몬스터 접촉 6, 보스 도끼 12, 보스 몸 8. HUD 왼쪽 위에 `HP 막대 + 현재/최대`(맞으면 잠깐 붉게). 0이 되면 게임오버 없이 ‘쓰러졌다…’ 1.6초 → 마지막으로 서 있던 자리 위 하늘에서 **체력 가득** 재낙하(보스는 제자리로 돌아가 다시 포효). 전용 공격력은 창·불·시계·밟기 모두 1(RPG 공격력과 무관). **Tab/V** 로 인게임 메뉴가 열리고(오버레이가 잠깐 숨고 게임 메뉴가 보임, 섭리오는 정지), 닫으면 재개. 메뉴의 비상탈출은 섭리오를 접고 방으로 돌아간다.

**진입(BUILD168)**: 비데 방의 눕힌 토관 입구 앞에서 **C** → ‘토관 안으로 들어갈까?’ [들어간다/그만둔다] → 주인공이 입구로 걸어 들어가며 **몸이 0.12배로 줄어들어**(`{ scale }` 노드) 사라지고 일행이 숨은 뒤 카메라가 거대 스크린(방 오른쪽 576×480, 흰 테두리·검은 화면)으로 잡히며 오버레이가 열린다. 비데도 같은 식으로 줄어들며 들어간다.

## 위치 대사·팻말 (`CHATTER`, `PROMPTS`, 2026-09-15 사용자)

주인공이 열(`at`)을 지나면 — 또는 `see: ['red','blue']` 처럼 그 종류 몬스터가 **화면에 보일 때**, `when: 'cleared'` 처럼 남은 몬스터가 0이 될 때 — HUD 아래 상자에 화자(억빠맨 보라·경섭 빨강·요플래 하늘·나레이션)별로 한 글자씩 뜨고, 다 찍힌 뒤 1.7초 지나면 다음 줄로 넘어간다(**C 불필요**, 게임은 계속 진행). 사용자 추가 대사(‘경섭이형 시계좀 잘맞춰봐요’/‘... 노력하고있어’, ‘브랜드 성능좋네요’, ‘시크큐티kr 1초대좀’, ‘허허 재밌다’, ‘창던져서 창녀만들죠 창녀요플래’)는 1-1~1-3 에 배치. 1-0 대본은 사용자 원문(착지 3줄·점프 1줄·토템 1줄·토템 명중 뒤 2줄·밟기 시범 앞뒤), 1-1~1-3 은 자유 대사(`src/scenes/subrio-core.js` `CHATTER`, 콘티 `design/narrative/cutscenes/subrio_chatter.md`). 1-0 팻말(`PROMPTS`): `← → 움직여라!`(8열) · `↑ 점프해라!`(34열) · `C 적을 공격해라!
