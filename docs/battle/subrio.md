# 섭리오 (SUBRIO) — 스크린 속 2D 플랫포머

2026-09-15 사용자 브리핑. 엄청 대박인 배 비데 방의 거대 게임 스크린 안으로 토관을 타고 들어가 노는 “게임 속 게임”. 마리오풍 도트 사이드뷰이지만 조작은 이 게임 규칙(C 공격·X 방어)을 따른다. 구현은 `src/scenes/subrio.js`(진행·그리기·소리)와 `src/scenes/subrio-core.js`(순수 규칙), 진입은 `bidet_pipe_enter`(토관 C) → 스크린이 화면 가운데로 잡히며 줌인 → `{ scene3d: 'subrio', flag: 'subrio_cleared' }`.

**구성(2026-09-15 사용자 확정)**: 월드 1 스테이지 형식. **1-1 보라·1-2 청록·1-3 파랑** 섬(각 3분 분량, 도트로 재구성한 CS 미니언이 걸어 다님), 마지막 **1-4 따듯한비데 보스전**. 보스를 이기면 씬이 `found` 로 끝나 `subrio_cleared` 플래그가 선다(Esc 는 `cancel`, 플래그 없음).

**체력·게임오버 없음, 전용 공격력 1 (2026-09-15 사용자 지시)**: 주인공은 맞으면 튕겨나기만 하고(하트·사망·재시작 없음), 이 게임 안의 공격력은 창·불·시계·밟기 모두 1이다(RPG 공격력과 무관). CS 미니언 3, 보스 12.

**진입(BUILD167)**: 비데 방의 눕힌 토관 **왼쪽 입구로 걸어 들어가면**(`bidet_pipe_mouth` 트리거) 일행이 토관 안으로 들어가 사라지고 카메라가 거대 스크린(방 오른쪽 576×480, 흰 테두리·검은 화면)으로 잡히며 오버레이가 열린다.
