# 섭리오 (SUBRIO) — 스크린 속 2D 플랫포머

2026-09-15 사용자 브리핑. 엄청 대박인 배 비데 방의 거대 게임 스크린 안으로 토관을 타고 들어가 노는 “게임 속 게임”. 마리오풍 도트 사이드뷰이지만 조작은 이 게임 규칙(C 공격·X 방어)을 따른다. 구현은 `src/scenes/subrio.js`(진행·그리기·소리)와 `src/scenes/subrio-core.js`(순수 규칙), 진입은 `bidet_pipe_enter`(토관 C) → 스크린이 화면 가운데로 잡히며 줌인 → `{ scene3d: 'subrio', flag: 'subrio_cleared' }`.

**구성(2026-09-15 사용자 확정)**: 스테이지 형식. 1~3단계는 각각 **보라·청록·파랑** 섬, 마지막에 **따듯한비데 보스전**. 보스를 이기면 씬이 `found` 로 끝나 `subrio_cleared` 플래그가 선다(Esc 는 `cancel`, 플래그 없음).

## 보스전 — 따듯한비데 (FINAL STAGE, 2026-09-15 기본값)

사용자가 “마지막에 비데랑 거기서 보스전”이라고만 정했으므로 아래 패턴·수치는 기본값이다. 조정은 `subrio-core.js` 의 `BOSS` 상수.

| 항목 | 값 |
| --- | --- |
| 등장 | 주인공 착지 1.2초 뒤 x560 하늘에서 낙하 → 착지 쿵(`thud`, 흔들림 0.35초) → 나레이션 상자 ‘따듯한비데가 나타났다!’ → 1.4초 포효(서 있음) → 추격 |
| 몸 | 28×44, 걷기 64px/s(지상 가속 12/s), 점프 초속 430(주인공이 40px 이상 높고 140px 안이면) |
| 도끼 | 같은 높이 62px 안이면 예비 0.55초(도끼 치켜듦) → 휘두름 0.3초(앞쪽 44px·몸 높이 판정, 한 번만) → 회복 0.45초 |
| 물줄기 | 추격 2.6초 넘게 못 잡거나 세 행동에 한 번: 1.1초 동안 0.15/0.45/0.75초에 물줄기(14×8, 240px/s, 1.7초) 3발, 주인공 쪽으로 |
| 접촉 | 걷다가 몸이 닿아도 하트 하나. 맞히면 보스는 0.45초 회복 상태로 잠깐 멈춘다 |
| 피격 | 창 한 발 = HP 1 (총 12), 맞으면 0.25초 밝게 번쩍(아픈 프레임)·0.2초 무적. HP 0 → 쓰러짐(아픈 프레임 깜빡) 2.2초 → 사라짐 + `CLEAR!` |
| 승리 | `explosion`+흔들림 → 2.2초 뒤 `vaporized`+`won`(전투 승리음) → 3.6초 뒤 검게 → 방으로 복귀, `subrio_cleared` |
| 소리 | 점프 `mario_jump`(0.8배), 휘두름 `whoosh`(0.8배), 물줄기 `splash`(1.3배), 창 명중 `hit`, 막기 `cannon_guard_block`, 피격 `hurt` |

주인공(판테온) 규칙: 하트 5개(`HERO_HP`). 맞으면 반대쪽으로 튕기고(170px/s·위 220) 0.35초 조작 불가, 1.2초 무적(깜빡임). **X 방패로 피해가 오는 쪽을 보고 있으면 도끼·물줄기·접촉 모두 막힌다**(살짝 밀림, `block`). 하트 0 → 쓰러짐 1.6초 → 무대 시작점에 다시 낙하(하트 5, 무적 1.5초, 착지 0.6초 뒤 조작). 그동안 보스는 제자리(x560)로 돌아가 다시 포효하고 **HP 는 유지**된다. 동료 둘은 따라오기만 하고 맞지 않으며 공격도 없다(사용자 지시 대기).
