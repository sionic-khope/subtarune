# 섭리오 (SUBRIO) — 스크린 속 2D 플랫포머

2026-09-15 사용자 브리핑. 엄청 대박인 배 비데 방의 거대 게임 스크린 안으로 토관을 타고 들어가 노는 “게임 속 게임”. 마리오풍 도트 사이드뷰이지만 조작은 이 게임 규칙(C 공격·X 방어)을 따른다. 구현은 `src/scenes/subrio.js`(진행·그리기·소리)와 `src/scenes/subrio-core.js`(순수 규칙), 진입은 `bidet_pipe_enter`(토관 C) → 스크린이 화면 가운데로 잡히며 줌인 → `{ scene3d: 'subrio' }`.
