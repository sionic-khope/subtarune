# 용광로 색깔 기억 게임 (BUILD198)

2026-09-16 사용자 브리핑(파피 플레이타임 2 ‘뮤지컬 메모리’ 느낌, 참고 영상 https://www.youtube.com/watch?v=-FfZmCpW0PE 9:40~11:00 · 12:58~13:02). 구현 `src/scenes/colorgame.js`(1인칭 오버레이 씬, `{ scene3d: 'colorgame', flag: 'furnace_color_done' }`) + `src/scenes/colorgame-core.js`(순수 규칙, `tests/unit/colorgame.test.mjs`). 진입은 용광로 광장 조작 패널(`lava_panel`, C → `furnace_panel`), QA `furnace_color`.

## 화면 (480×360, 1인칭)
- 위 282px **용광로**: 뒷벽(`youngcle_furnace` 배경 일부) 앞에 용암 웅덩이가 원근(띠 4개 배율 0.55~1.35, 흐름·거품·불티)으로 펼쳐지고, 앞엔 짧은 철 울타리(1.5배). 오른쪽에 **쥰희·용준이 든 밧줄 철창**(`lava_cage.png` 0.8배, 좌우 데롱데롱 ±6px, 정면 정지 프레임을 철창 뒤에). **영클 TV**(프레임 0.75배 + 모니터암)가 위(−230)에서 3.4초에 걸쳐 가운데(y 26)로 천천히 내려온다.
- 아래 78px **조작 콘솔**(노란 테두리): 왼쪽 아래 **김형섭 초상 칸**(스타크래프트 초상처럼 96px 얼굴을 48px 로 + 이름표; 맞으면 통통, 틀리면 붉게 흔들림), 가운데 **버튼 7개** 빨·주·노·초·파·남·보(36×34, 누르면 내려앉고 맞으면 환하게 + 색별 음), 오른쪽 아래 **카메라 모니터**(92×92 정사각형, 마지막 판에만 1.8초 페이드인 — `assets/video/gajaeman_cam.mp4` 를 소리 없이 반복, 빨간 점 깜빡임).
- **마우스**: 커서를 숨기고 **형섭 손**(`hand_point.png`/`hand_press.png`, `tools/art/furnace_memory_set.py`)이 따라다닌다. 클릭하면 검지가 눌린 프레임 + 3px 내려감. 대사도 클릭이나 C 로 넘긴다. Esc 로 나가면 맵 브금 복귀.

## 흐름
1. (브금 꺼진 채) 페이드인 1.2초 — 철창만 데롱데롱 → 0.8초 뒤 TV 가 드르르륵(`rumble`) 내려옴 → 켜짐(`youngcle_tv_on`, 가로선 0.8초).
2. **튜토리얼 대사**(원문, TV 에 영클 그림): ㅎㅇ(greet) / 자 그러면 튜토리얼 따위는 필요없고 / 내가 부르는 색깔 그대로 누르면 됨 ㅇㅇ / 제한시간안에, 그를 살려라(taunt) / 준비~~(laugh) / 시작 ~~~!(yes) → 2초 뒤 화면 꺼짐(`click`) → 0.6초 → 1판.
3. **판**(`makeRound`): TV 가 색을 **1초에 하나씩**(`callGap` 1.0) 로봇 음성과 함께 보여준다 — 화면은 그 색, 가운데 영문 이름(32px). 같은 색 연속을 구분하려고 0.72초 켜졌다 잠깐 꺼진다. 호출이 끝나고 0.8초 뒤 **입력 차례**: 화면에 진행 점(누른 순서대로 색이 채워짐)·`n / N`·남은 시간 띠. 제한 시간 = 3.0 + 1.4 × 정답 개수. **철창이 제한 시간만큼 천천히 내려가고**(최대 44px, 다 되면 용암에 닿음) 통과하면 **드르륵(`chain_extend`) 위로 되돌아간다**(사용자). 통과: `great_shine` + 영클 yes 그림 1.15초 → 다음 판.
4. **8판**: 1 빨 / 2 빨초 / 3 빨초노 / 4 빨초노파파 / 5 주빨초노파보 / 6 빨초노파파파보 / 7 남초빨주노보파남 / **8 광기**: `빨 초 파 노 하트 nasdf pi 레전드 응아잇어 보 하트 남 레전드 주 응아잇어 파`(사용자 원문 단어) 를 **0.5초 간격으로 계속 반복**(입력 차례 없음). 이상한 말은 화면이 지직거리며 아무 색이나 번쩍이고 글자만 뜬다. 광기 판이 시작되면 오른쪽 아래 카메라가 페이드인.
5. **느낌표 버튼**(사용자): 광기 3초 뒤 빨간 동그라미 `!`(반지름 24)가 화면 가운데 높이에서 **좌우로 역동적으로**(±150px, 2.9rad/s + 위아래 10px) 움직인다. 누르면 통과 → 딸깍(`click`) → 0.45초 → **삐요오오오오옹**(톱니파 320→1500Hz 1.5초) → 2.0초부터 **주변 폭발**(0.3초마다 `assets/fx/explosion.png` 31프레임 + `furnace_blast` 0.5, 속도 ±8%, 흔들림·번쩍) → 2.6초 TV 켜지며 영클 **shock** “오 ㅅㅂ 이게 머노” / oh “정지 정지 장비를 정지” / shock “안대잔아 씨바”(폭발 계속) / 쥰희 “하하 꼴좋다 쓰레기색기” → **큰 폭발**(철창 자리 3발, 0.95) → 0.35초 뒤 철창이 **삐요옹**(520→1700Hz 0.7초) 위로 날아감(가속) → 1.5초 페이드아웃 → 2.4초 `finish(true)`.
6. **실패**: 틀린 색(`WRONG`) 또는 시간 초과(`TIME OVER`, 철창 덜컹 + `chain_extend`) → `error`·붉은 번쩍·흔들림·영클 laugh 그림 → `C 다시` 로 **1판부터**(카메라 모니터도 꺼짐).

## 뒤 연출 (맵 `furnace_panel`, 사용자 원문)
돌아온 광장은 철창이 날아가 없고 TV 도 올라가 있다(무음) → 페이드인 → 억빠맨 “...” → 오른쪽을 보고 카메라 [17.5,10.2] → **철창이 떨어지며 폭발**(`boom` explosion 2.2배 + `furnace_blast`, 흔들림) → 철창은 `fling` 으로 날아가 사라지고 쥰희·용준이 울타리 앞 바닥으로 `hop` → 용준 “어? 살 살았다!!!” → 쥰희 웃음 동작(`laugh_junhee`) “으하하 이몸 부활이다.” → TV 가 웅덩이 가운데(383,96)로 3초에 걸쳐 내려오고 다섯이 그 아래 모여 위를 본다 → 영클 facepalm “큭.. 그래 인정하마” / smirk “뭐 일단 이제 얼굴보면 되겠군” / bye “왼쪽으로갔다가 올라오면 됨 이따보자 ㅂㅇ” → 꺼지고 접혀 올라감, 브금 꺼짐 → `furnace_aftermath_done`. 재입장: 철창 없음, 둘은 울타리 앞, TV 없음. (왼쪽 길·다음 맵은 다음 브리핑.)
