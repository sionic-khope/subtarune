## 흐름
1. (브금 꺼진 채) 페이드인 1.2초 — 철창만 데롱데롱 → 0.8초 뒤 TV 가 드르르륵(`rumble`) 내려옴 → 켜짐(`youngcle_tv_on`, 가로선 0.8초).
2. **튜토리얼 대사**(원문, TV 에 영클 그림): ㅎㅇ(greet) / 자 그러면 튜토리얼 따위는 필요없고 / 내가 부르는 색깔 그대로 누르면 됨 ㅇㅇ / 제한시간안에, 그를 살려라(taunt) / 준비~~(laugh) / 시작 ~~~!(yes) → 2초 뒤 화면 꺼짐(`click`) → 0.6초 → 1판.
3. **판**(`makeRound`): TV 가 색을 **1.2초에 하나씩**(`callGap` 1.2 — 사용자 “간격 0.2초 정도 늘려”) 로봇 음성과 함께 보여준다 — 화면은 그 색, 가운데 영문 이름(32px). 같은 색 연속을 구분하려고 0.72초 켜졌다 잠깐 꺼진다. **마지막 색이 꺼지면 0.1초 뒤 바로 입력 차례**(사용자 “레드 그린 하면 바로 시작”): TV 가 하얗게 번쩍이며 `GO!`(0.6초) 하고 버튼이 켜진다. 그 전엔 버튼이 꺼져 있어 눌러도 아무 일도 없다. 화면에 진행 점·`n / N`·남은 시간 띠. **제한 시간은 모든 판 12초**. **철창이 실시간으로 정비례해 내려가고**(84px) 통과하면 **드르륵(`chain_extend`) 위로 되돌아간다**. **틀린 색을 누르면 실패가 아니라** 버저·흔들림과 함께 **철창이 내려가는 속도가 1.5배**(누적, 화면에 `x1.5`). 통과: `great_shine` + 영클 yes 그림 1.15초 → **준비 쿨다운 2초**(`clearReady`, TV 에 `ROUND n` + `준비...` + 차오르는 띠 — 사용자 “성공 효과음과 함께 준비시간 2초 쿨다운”) → 다음 판.
4. **8판**(사용자 “존나 어렵다 — 전 단계랑 이어져서 하나 추가”): 기본 순서 `SEQUENCE` = 빨 초 노 파 보 주 남, n판 = 앞 n개(1 빨 / 2 빨초 / 3 빨초노 / … / 7 빨초노파보주남). **8 광기**(사용자 2026-09-16 정정, 시간표 `CHAOS`): **빨·초·노까지는 보통처럼**(1.2초) → **파랑에서 버벅**(3초: 끊긴 “BL-/BLU-/B-BLUE” 호출이 불규칙하게 열 번, 음성은 잘라서 빠르기 제각각, 화면·TV 떨림) 사이사이 **영클이 한 번씩 웃는 화면**(laugh 0.38초 ×3) → **화면이 꺼진 채 `. . .`**(1.7초, 딸깍) — **오른쪽 아래 카메라는 꺼지기 1초 전(버벅 중, `CHAOS.camLead`)부터 페이드인**(사용자 “얼굴 1초만 더 빨리”) → **폭주**(rampage): `치이이익` 잡음(`sizzle` + `static_loop` 루프)과 함께 이상한 말 24개(`빨 초 하트 노 파 nasdf pi 보 레전드 주 응아잇어 남 하트 파 레전드 응아잇어 빨 pi 초 nasdf 노 하트 보 응아잇어` — “더 장황하게”)를 **0.3초 간격**(“회전률 더 빠르게”)으로 계속 반복, 화면 찢김·TV 떨림. 입력 차례 없음.
5. **느낌표 버튼**(사용자): **폭주 4초 뒤**(판 시작 12.3초 — “뜨는 타이밍 더 늦춰”, `CHAOS.passAfter`) 빨간 동그라미 `!`(반지름 24)가 화면 가운데 높이에서 **좌우로 역동적으로**(±150px, 2.9rad/s + 위아래 10px) 움직인다. 누르면 잡음이 끊기고 통과 → 딸깍(`click`) → 0.45초 → **삐요오오오오옹**(톱니파 320→1500Hz 1.5초) → 2.0초부터 **주변 폭발**(0.3초마다 `assets/fx/explosion.png` 31프레임 + `furnace_blast` 0.5, 속도 ±8%, 흔들림·번쩍) → 2.6초 TV 켜지며 영클 **surprise**(느낌표만 있는 얼굴 — 사용자 “19책 들고 있는 shock 말고 느낌표만”) “오 ㅅㅂ 이게 머노” / oh “정지 정지 장비를 정지” / surprise “안대잔아 씨바”(폭발 계속) / 쥰희 “하하 꼴좋다 쓰레기색기” → **큰 폭발**(철창 자리 3발, 0.95) → 0.35초 뒤 철창이 **삐요옹**(520→1700Hz 0.7초) 위로 날아감(가속) → **계속 폭발**(0.2초마다 + 큰 폭발 둘 1.3·2.6초)하며 **화면이 0.6초부터 4.2초에 걸쳐 천천히 하얘짐**(`WHITEOUT`, 사용자 “더 오래 폭발하고 더 천천히 화면이 하얘지게”) → 다 하얘진 채 0.5초 → 1초 페이드 → `finish(true)`(큰 폭발 뒤 약 6.3초).
6. **시간 초과**: 밧줄이 끊겨(`chain_extend`) **철창이 가속으로 떨어져 용암에 풍덩**(`splash`+`sizzle`, 불티 40개, 흔들림, 용암 면 아래는 잠겨 안 보임) → `TIME OVER` + `C 재시도` → **실패한 그 판부터**(사용자 최종 “실패하면 그 단계부터”, “풍덩 빠지는 연출, 재시도 C”; 앞의 ‘처음부터·자동 재시작’은 이 지시로 덮음). 철창은 드르륵 위로 되돌아온다.
