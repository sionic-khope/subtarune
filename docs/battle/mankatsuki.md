# 만카츠키 쥰희 전투 (BUILD133)

현재 본체 발 홈은(406,210), BUILD129의(384,210)에서 오른쪽22논리px 이동했다. 배율1.15·피벗(64,119)·원본 시트는 유지한다. 대기 잔상은 오른쪽 공간이 부족하면 왼쪽으로 펼쳐 화면 안에 둔다. 현재 공격 수치는 아래 BUILD133 탄막 표가 우선하며 BUILD130/129/126 설명은 제작 이력이다.

## BUILD130 추가 규칙

- 새 생성 이미지/프롬프트/추출 기록: `assets/source/mankatsuki130/`. 아래129/126 숫자는 당시 기록이고 최신 설정은 이 항목과 enemies.js를 따른다.

## BUILD129 추가 규칙

- 본체는 연보라 피부, 기존 검정 머리/망토·붉은 눈/구름을 유지한다. 배율1.15, 발 위치384,210(이전보다24px 오른쪽). 기본 쥰희는 변경하지 않는다.
- 일반 공격: 표창·화염·주가 공격4→6회, 타코 얼굴6→9개. 낙하 피난 삼각형70→58px. 이는 횟수 약50% 증가 또는 안전면적 약31% 감소로 압박을 높인 것이며 주관적 난도가 정확히50%라는 의미는 아니다. HP100·피해11·기존 예고 시간을 유지한다.

- HP50% 이하부터 `enragedPatterns`의 타코+화염7.4초 / 타코+주가7.4초 / 표창+타코7.8초를 순서대로 쓴다. 처음 넘어갈 때 후반 첫 패턴부터, 재도전은 일반 첫 패턴부터다. 같은 보스의 공격을 배치·간격을 조절해 합쳤고 다른 몹 패턴을 가져오지 않는다.
- `reactive`는 선택형 적 설정이다. 모션 속도는 `1 + 0.4 × (1 - HP비율)`로 최대1.4배이며 연속 시계를 누적해 피격 순간 프레임이 튀지 않는다. 남은HP70/50/20%에서 대기 잔상2/3/4개를 오른쪽 뒤에 표시한다. 잔상은 충돌/별도 적이 아니며 순간이동·공격 포즈에서는 숨긴다.
- 실제 양수 피해마다 기존 쥰희 음성을 낮추고 에코를 준 `mankatsuki_hurt`를 한 번 재생한다. 다른 적의 피격음은 그대로다. 추가 잡담은 ‘아 삼전사라고 삼전’, ‘우욱 우욱 우욱 이거 빤쓰아녀유?’다.
- 전투 중앙 회전은0.768rad/s, 바깥 띠−0.308rad/s. 상하 반대 위상 비틀림과 작은 반경/원근 변화로 이질감을 더하며 화면/입력/탄속에는 적용하지 않는다.

## BUILD129 선장실 연출

어둠 전이는4.8초+감싸기1.8초이며 쥰희가 떨고 전원 그쪽을 본다. 요플래는 기존 검 공격4프레임과 짧은 준비/돌진을 사용한다. 가재맨 대사는 ‘어이구야 날 막으려는건가? 의미없는짓을.. {c=yellow}요플래{/c}..’. 반격은 진동/충격음/낙하, 이후 가재맨은72px/s로 화면 밖까지 이동한 뒤 숨긴다.

파티가 돌아온 뒤3.6초 감싸기→0.5초 흰 전환→0.7초 유지→1초 공개다. 목재 방의 어두운 보라색과 쥰희 몸 주변 보라 오라는 변신 뒤에도 남고, 완료 저장 재진입에서도 복원한다. 전투 전환이 불투명해진 뒤 정리하며 보스 처치 뒤에는 복원하지 않는다.

마지막 대사 뒤에는 기존 `vortex` 공격 대신 새 생성 `assets/fx/mankatsuki-vortex.png`6프레임을 쓴다. 전체8초 중5.8초 동안41→287px로 커지고 진동도 단계적으로 세진다. 중심 카메라를 맞춰 원형 전체가 화면에 들어오게 한다. 이후 표준 전투 진입 효과/규칙은 유지한다. `boom`의 선택형 `duration/endScale/grow`는 다른 장면에서도 재사용할 수 있다.

새 스프라이트 원본·프롬프트·NEAREST 추출·피부 편집 기록은 `assets/source/mankatsuki129/`다. 아래 BUILD126 설명은 초기 패턴 설명이며 횟수·시간·크기의 최신 값은 위와 `enemies.js`를 따른다.

사용자 요청: HP100, 순간이동 타코 표창·대각선 아래 피난 돼지 낙하·프라이팬 화염·주식 그래프. 후속 기믹은 별도 요청을 기다린다.

## 재사용 경계

적 `actions`에 별도 액션 시트를 선언하면 미리 로드한다. 패턴 `api.present({hidden,x,y,scale,sheet,frame,clones})`는 그림만 움직이고 전투 홈을 바꾸지 않는다. x/y는 발 피벗, sheet는 idle 또는 액션 이름, actor는 홈 위치/배율이다. 선택형 `clones`는 `{x,y,scale,sheet,frame,flipX,hidden}` 배열이며 렌더러는 앞의 최대3개만 그린다. 최상위 `hidden:true`여도 분신은 먼저 표시하고 본체만 숨긴다. 분신별 `hidden:true`는 해당 그림을 건너뛰며 `flipX`는 발x를 기준으로 좌우 반전한다. 분신은 기존 적의 시각 복사이고 별도 HP·목표·충돌·게임 개체를 만들지 않는다. 분신에 중첩된 분신은 전달하지 않는다. `present(null)`·패턴 종료·턴 종료·패배·재시도·종료 시 본체/분신 표현을 함께 지우고 기본 모습으로 복원한다. 새 입력/목표/성공·실패가 필요한 기믹은 기존 `registerBattleMode`/support 구조에 분리한다. 동료 피해·쓰러짐/부활·전체 패배·아이템 규칙을 복사하지 않는다.

## 배경·소리

BUILD133 최신 배경은 좁은 중앙 허리의 위·아래가 비대칭으로 굽고 강하게 비틀리는 모래시계다. 반경/면 높이/원근의 느린 변형과 약19.6초 주기의 어두운 보라~자홍 색 변화를 더했다. 바깥은 기울기/높이/깊이가 다른 끊어진 띠3개(−0.308/+0.24/−0.19rad/s)이며 중앙72면+외곽336면으로 제한한다. 목재 캐시는 재사용한다. `enemy-prep`/`bullets`/`board-close`에서 면 알파0.62배+검정 보라38%로 대비를 낮추고 배우·하트·UI는 이후에 정상 표시한다. 아래 BUILD127의 단일1536면 띠는 이전 이력이다. 화면 진동/빠른 점멸/입자 추가는 없다.

BUILD127은 사용자 추가 GIF를 기준으로 원반 깔때기를 위·아래 넓은 각면이 좁은 허리로 연결된 수직축 회전 공간으로 교체했다. 중앙72면은+0.48rad/s, 바깥 검정 오오라 띠1536면은−0.22rad/s로 따로 돌아 깊이순으로 그린다. `game.time`으로 턴 사이에도 이어지며 목재 바닥은 y88부터 보인다. 아래 각면의 alpha0.64로 나무결을 보존한다. GIF/영상 이미지를 그대로 붙이지 않는다.

공통 전투 파티의 발은3인104/164/224,2인164/224,1인190이며75→60px 간격이다. 원본크기·공격 접근/복귀·쓰러짐/부활 홈을 유지하고 작은 발 그림자로 지면에 붙인다. 돼지 낙하음은 기존 `baron_slam`으로 보강했으며 나머지 분신/표창/화염/레이저도 공격당1회 기존 소리를 쓴다.

`darkSmoke.veil`은 나무결/명도를 남기는 보라색 합성과 검정 어둠을 함께 변화시킨다. 대화창은 영향 없고 기존 연기 정리와 함께 해제한다. 전투곡 `Z01Tsgwe2dQ` 전체곡과0.36초 분신음 출처는 `design/audio/references.md`.
