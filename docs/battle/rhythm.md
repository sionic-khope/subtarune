## BUILD184 — 곡 뒤 대사 분리·기립 환호·동전·보X팜 환호·둥가둥가 (사용자)
- **대사**: 첫 곡 뒤 ‘너무 감동적인 곡이군요...’ → ‘이제 이게 끝이 아닙니다.’ → ‘두번째곡... 바로 가볼까요?’ → ‘바로 보X팜 입니다~~’ (앞 두 줄을 사용자 문구대로 나눔).
- **기립 환호(ovation)**: 곡이 끝나면 `ovation` 3초 — `cheer(4)`: 함성 0.95 + 박수 0.75, 1.5초 뒤 함성·환호 한 번 더, 3.2초 뒤 박수, 관객 점프 7초, 플래시. 꽃 36·**동전 28**(관객석에서 포물선, 무대 바닥에 두 번 튀며 ‘팅’ 삼각파 톤)·불꽃 30·색종이 80. 두 곡 모두. 그 뒤 첫 곡은 대사, 둘째 곡은 결과.
- **보X팜 시작 환호**: 두 번째 곡 제목 카드가 뜰 때 `cheer(3)` + 꽃 14 + 불꽃 16.
- **둥가둥가(idle groove)**: 밴드 시트를 256×512 로 늘려 셀 4~7 = 다운·업·왼쪽·오른쪽(gpt-image-2, `assets/source/band184/`, 참조 = 기존 raw 시트 512 축소본, `process.py` 가 기존 idle 높이에 맞춰 붙임). 사용자 최종 “숨 쉬듯이”: groove 프레임은 쓰지 않고 기본 자세에서 두 박 주기로 1px 만 오르내린다(시트의 셀 4~7 은 보관). 박은 곡 중엔 차트 박자, 아니면 126bpm. 시트에 groove 가 없으면 프레임 0 을 |sin| 3px 바운스(폴백). **관객 띠**는 32px 세로 조각 15개가 서로 어긋난 위상으로 0/1px 만 천천히 숨 쉬듯 움직이고(가만히 있을 때), 환호 땐 다 같이 점프.

## BUILD182 — 패드 복구·멜로디 리드·믹스·홀드 규칙 (사용자 지적 4건, 대부분 BUILD183 에서 뒤집힘)
- **양옆 패드 복구**(“경섭이랑 빠맨쪽 패드는 왜 없앤거야”): 가운데 기둥 양옆에 같은 스타일의 좁은 기둥(경섭 x126 w44 분홍 / 빠맨 x310 w44 연두), 같은 흰 박자선, 자동 노트가 판정선에서 반짝(`sidering`), 위에 경섭/형섭/빠맨 라벨. 노트·박자선은 기둥 사각형 안으로 클립.
- **기타가 노래를 따라감**(“기타 소리가 노래랑 안 조화롭고 너무 시끄럽다”, “음이 노래 음이랑 아예 똑같이 같이 가게 — 보X팜도”): `chart.py` 가 노트마다 그 순간의 보컬 음높이를 추적(16384점 FFT 하모닉 곱 스펙트럼 80~1000Hz, 보컬 대역 가중) → D3~D5 로 옥타브 접기 → 앞 음과 8반음 넘게 뛰면 옥타브로 당김 → **곡 키 음계로 스냅**(키는 크로마×Krumhansl 상관: 노앰토리 Dm, 보X팜 Am) → `notes[].pitch`(Hz). 씬은 리드 샘플 `guitar_lead_a2/a3/a4`(Karplus-Strong, 게인 18) 중 가장 가까운 기준음을 골라 `playbackRate`(±6반음, `Sound.sfx` 의 `pitch:true` 로 `preservesPitch=false`)로 이조. 홀드는 `guitar_sustain`(E3) 을 그 음의 옥타브로 접어 이조.
- **믹스** `MIX`: 영상 1.0(0.85→), GREAT 리드 0.42, 홀드 0.28, 긁기 0.22, MISS 데드 노트(`guitar_dead`, 음정 없는 툭) 0.32, 곡 중 관객 소리 0.6배. 파워코드 E/A·팜뮤트 척은 더 안 쓴다(파일은 남김).
- **홀드 규칙**(“꾹 누르다 뗐으면 성공”): 머리를 맞히고 누르다 중간에 떼도 MISS 가 아니라 성공(`holdEnd` early). 보너스는 누른 비율만큼(최소 절반), 끝까지 누르면 전부.
- **노앰토리는 ‘만원 주면~’부터**(“앰토리는 만원주면~ 부터 들어가야지”): 영상 파일을 18.2초부터 잘라 재인코딩(69.6초, libx264 crf24 + aac 128k; 원본 전체본은 git 82e80a8). seek 로 하지 않은 이유: 개발 서버 `python3 -m http.server` 가 HTTP Range 를 안 줘 브라우저가 영상 안에서 seek 를 못 한다(확인함). QA `seek()` 훅도 seek 불가면 시계 모드로 넘어간다. 하이라이트는 33.1~46.8초.

생성 배경(`rhythm_backdrop.png`: 위 가운데 매달린 꺼진 대형 스크린 106,34 264×148, 좌우 스포트라이트·스피커 스택, 바닥 조명 웅덩이 — 받침 없음) 위에 반투명(검정 0.78) 리듬 칸 셋이 스크린을 타고 내려온다(위 42 → 판정선 200). 밴드는 절반 크기(64px)로 무대 뒤쪽(발 y284)에 서고 생성 관객 띠(평소/환호 2프레임, 콤보 때 위아래로 뛰며 글로우스틱)가 맨 아래를 덮는다. 홀드 노트는 굵은 꼬리(테두리·눈금·HOLD 표시), 스포트라이트 빔이 천천히 흔들리고 큰 환호 땐 화면이 살짝 밝아진다.

(이전) 꺼진 거대 TV(400×225) 위에 반투명 리듬 칸 셋: **경섭 드럼(왼쪽 60px) | 형섭 ←/→ 두 칸(가운데 42+42) | 빠맨 보컬(오른쪽 60px)**. 칸마다 위에 이름(분홍·하늘·연두), 판정선 y258. 왼쪽 위 POPU, 오른쪽 위 LARITY 세로 게이지(인기), 아래 왼쪽 SCORE, 오른쪽 MAX COMBO, 가운데 판정 글자(GREAT!/MISS)와 `n COMBO`. 무대 바닥 위에 밴드 시트(`band_*.png` 2×2, 셀 128, 발 y122: 0 idle, 1~3 연주), 그 아래 관객 실루엣 두 줄.

## 규칙 (`RHYTHM`)

| 항목 | 값 |
| --- | --- |
| 노트 | 탭·홀드 둘. 유저는 가운데 두 칸만(←/→). 양옆 드럼·보컬은 차트의 `side` 시각에 자동으로 연주 애니 |
| 접근 시간 | 1.5초(맨 위 → 판정선) |
| 판정 | ±0.12초 GREAT, 0.16초 지나면 MISS. 둘뿐 |
| 홀드 | 시작을 GREAT 로 잡고 끝나기 0.15초 전까지 누른 채. 일찍 떼면 MISS, 완주하면 +50 |
| 빈 입력 | 노트 없는 데 누르면 판정 없이 ‘툭툭 긋는’ 소리 + 스트로크 애니(콤보 유지) |
| 점수 | GREAT 100 × (1 + min(콤보,50)/50) |
| 인기 | 0.45 시작, GREAT +0.022, MISS −0.07, 0~1 |
| 게임오버 | **5연속 MISS** → 영상 정지, ‘무대가 엉망이 됐다...’ + 재도전 [C] → 곡 처음부터 |
| 등급 | S(정확도 97%·인기 90%) / A 90% / B 75% / C / F(게임오버) |

## 소리 (BUILD180)

전부 샘플: GREAT = 고게인 파워코드 `guitar_pc_e/a` 번갈아(사운드 체크는 음정 `guitar_c4/g4/a4`), **홀드는 누르는 동안 `guitar_sustain` 이 쭈욱**(떼거나 끝나면 30ms 간격으로 줄여 끊음, `Sound.sfx` 가 요소를 돌려준다), 빈 입력 `guitar_scratch`, MISS `guitar_mute`, 곡 시작 전 `guitar_feedback` 2.2초, 콤보 10 `applause` · 20 `crowd_cheer`+박수 · 50 `crowd_roar`+박수+화면 밝아짐+꽃, ‘즐길 준비되셨나요?’와 곡 끝 함성+꽃, 밴드 낙하 `thud`, 게임오버 `damage`, 결과 `won`. 차트 좌우는 무게중심 중앙값으로 반반, 같은 칸 3연속 넘으면 반대 칸.

## 곡·영상·차트

`assets/video/<id>.mp4`(유튜브 360p, 소리 포함)를 `<video>` 로 재생해 TV 에 그리고 `video.currentTime` 이 차트 시각. 자동재생이 막히면 음소거로 재시도, 그래도 안 되면 내부 시계로 진행. 차트는 `tools/rhythm/chart.py`(onset → 1/2박 양자화, 무게중심으로 L/R, 긴 간격은 홀드, 밀도 ≤ 2.5/s, 저역 onset = 드럼, 중역 = 보컬). 튜토리얼 `TWINKLE`(작은별 첫마디, 음정 포함)은 코드 상수.
