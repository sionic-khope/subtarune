2026-09-15 사용자 브리핑. 델타룬 3장 테나 리듬 게임 참고. 구현 `src/scenes/rhythm.js`(오버레이 씬, `{ scene3d: 'rhythm', flag: 'rhythm_stage_done' }`) + `src/scenes/rhythm-core.js`(순수 규칙, `tests/unit/rhythm.test.mjs`).

## 화면

꺼진 거대 TV(400×225) 위에 반투명 리듬 칸 셋: **경섭 드럼(왼쪽 60px) | 형섭 ←/→ 두 칸(가운데 42+42) | 빠맨 보컬(오른쪽 60px)**. 칸마다 위에 이름(분홍·하늘·연두), 판정선 y258. 왼쪽 위 POPU, 오른쪽 위 LARITY 세로 게이지(인기), 아래 왼쪽 SCORE, 오른쪽 MAX COMBO, 가운데 판정 글자(GREAT!/MISS)와 `n COMBO`. 무대 바닥 위에 밴드 시트(`band_*.png` 2×2, 셀 128, 발 y122: 0 idle, 1~3 연주), 그 아래 관객 실루엣 두 줄.

## 규칙 (`RHYTHM`)

| 항목 | 값 |
| --- | --- |
| 노트 | 탭·홀드 둘. 유저는 가운데 두 칸만(←/→). 양옆 드럼·보컬은 차트의 `side` 시각에 자동으로 연주 애니 |
| 접근 시간 | 1.5초(맨 위 → 판정선) |
| 판정 | ±0.12초 GREAT, 0.16초 지나면 MISS. 둘뿐 |
| 홀드 | 시작을 GREAT 로 잡고 끝나기 0.15초 전까지 누른 채. 일찍 떼면 MISS, 완주하면 +50 |
| 빈 입력 | 노트 없는 데 누르면 판정 없이 ‘툭툭 긋는’ 소리 + 스트로크 애니(콤보 유지) |
| 점수 | GREAT 100 × (1 + min(콤보,50)/50) |
| 인기 | 0.45 시작, GREAT +0.022, MISS −0.07, 0~1 |
| 게임오버 | **5연속 MISS** → 영상 정지, ‘무대가 엉망이 됐다...’ + 재도전 [C] → 곡 처음부터 |
| 등급 | S(정확도 97%·인기 90%) / A 90% / B 75% / C / F(게임오버) |

## 소리

GREAT = 합성 일렉 스트로크(사운드 체크는 음정대로), 빈 입력 = 90Hz 툭, MISS = 62Hz 버즈, 곡 시작 전 지이이잉 2초, 콤보 10마다 관객 박수 `maillard_applause`, 밴드 낙하 `thud`, 게임오버 `damage`, 결과 `won`.

## 곡·영상·차트

`assets/video/<id>.mp4`(유튜브 360p, 소리 포함)를 `<video>` 로 재생해 TV 에 그리고 `video.currentTime` 이 차트 시각. 자동재생이 막히면 음소거로 재시도, 그래도 안 되면 내부 시계로 진행. 차트는 `tools/rhythm/chart.py`(onset → 1/2박 양자화, 무게중심으로 L/R, 긴 간격은 홀드, 밀도 ≤ 2.5/s, 저역 onset = 드럼, 중역 = 보컬). 튜토리얼 `TWINKLE`(작은별 첫마디, 음정 포함)은 코드 상수.
