# 청록숲6 와드·마나의 샘

청록숲6의 기존 소품 PNG를 생성 아트로 교체한다. 블루는 몬스터가 아니라 돌로 둘러싸인 파란 생명·마나의 샘이다. 소품 이름 `blue_buff`는 기존 런타임 연결을 유지하기 위한 파일명이다.

| 런타임 PNG | 셀 / 프레임 | 속도 | 이미지 하단 중앙 pivot |
|---|---|---|---|
| `assets/props/ward.png` | 20×36 / 2 | 2fps | (10,36) |
| `assets/props/blue_buff.png` | 40×44 / 3 | 4fps | (20,44) |

실제 맵의 `ix`, `iy`, 히트박스, 대사와 이벤트는 기존 값을 사용한다. 와드 첫 프레임은 눈 뜸, 둘째는 눈 감음이다. 샘은 물줄기·물방울·물결이 변하고 돌 받침은 같은 바닥 기준점에 놓인다.

## 재추출

```bash
uv run tools/sprites/import_teal6_props.py
```

원본과 프롬프트는 `assets/source/teal6-props-v1/`의 `*-raw.png`, `*-prompt.txt`다. `before/`는 교체 전 PNG, `runtime/`은 재생성 때 사용하는 정규 PNG다. `manifest.json`은 2×2 원본 셀 크기, 0부터 시작하는 행 우선 프레임 번호, 원본별 바닥 중앙 기준점, 공통 crop·배율·배치, 최종 경계 및 해시를 기록한다.

선택 프레임은 와드 `[0,1]`, 샘 `[0,1,2]`다. 각 소품의 모든 프레임을 같은 바닥 중앙에 맞추고 하나의 공통 crop과 최근접 배율을 적용한다. 가장자리와 이어진 마젠타 배경만 기존 `key_cell`로 투명화하며 원본 색을 평균내거나 팔레트 양자화하지 않는다. 물방울도 보존한다. `tools/art/teal_set.py`를 실행해도 이 두 소품은 정규 사본에서 복원된다.

게임 확인 진입점은 `?qa=teal6`이다. 와드의 눈 깜박임과 샘의 물 움직임을 확인하고 두 소품에 C로 상호작용한다.
