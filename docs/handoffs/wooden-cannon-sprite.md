# 용준·쥰희가 만든 나무 대포 스프라이트

강해 보이는데 뭔가 웃긴, 용준·쥰희의 목제 대포입니다. 바론 스프라이트와 함께 이미지 자산으로 전달합니다. 아래 파일을 사용해 주세요.

- 파일: `assets/source/yongjun-junhee-wooden-cannon-v1/cannon-1.png`
- 투명 RGBA128×128, 오른쪽을 향한 3/4 정지 모습 1장입니다. 시트로 나누지 마세요.
- 돼지코를 연상시키는 분홍 쌍포구, 용준의 검정 둥근 머리와 웃는 얼굴 제작자 표식, 거대한 통나무 포신, 밧줄·삐뚤어진 보강판·작은 나무 바퀴로 구성했습니다. 이 세부 디자인은 이번 제작 제안입니다.
- 캐릭터가 올라탄 그림이 아닌 무기 단독 자산입니다. 발사/반동/탄환/이동 애니메이션은 포함하지 않습니다.
- 스무딩을 끄고 표시하세요. 셀 전체를 유지하며 바닥 중심 앵커는 `(64,119)`입니다. 실제 충돌 크기나 배치·장비 방식은 구현 세션에서 정합니다.
- `prompt.txt`는 내장 이미지 생성 프롬프트입니다. 원본은 이미지 스튜디오의 `output/sprites/yongjun-junhee-wooden-cannon-v1/`에 보존했습니다.

![나무 대포](../../assets/source/yongjun-junhee-wooden-cannon-v1/cannon-1.png)

이 PR은 이미지와 사용 지침만 전달합니다. 게임 코드·맵 배치·발사 시스템·바론 전투 연출은 변경하지 않습니다. 바론 사용 규격은 [바론 안내](baron-boss-sprites.md)를 따르세요.
