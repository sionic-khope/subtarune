# 바론 추격씬: 이 스프라이트를 사용하세요

이 PR은 **자산과 사용 지침만** 전달한다. 추격 이벤트, 이동 AI, 탄 충돌·피해량·발사 간격은 게임을 개발 중인 세션에서 구현한다. 기존 바론 정면/전투 대기 파일은 교체하지 않는다.

## 파일

기준 폴더: `assets/source/baron-chase-v1/`. 정확한 셀·앵커·타이밍은 같은 폴더의 `manifest.json`을 따른다. PNG는 투명 배경이며 원본 픽셀을 최근접 확대한 결과다.

manifest의 `grid`는 `[열, 행]`, bbox는 `[왼쪽, 위, 오른쪽, 아래)`이다. 본체 셀은256×256, 피벗은 `(128,240)`이며 탄 셀은64×64, 피벗은 `(32,32)`이다. 이동은160ms/프레임, 발사는 `[160,180,120,100,140,160]`ms 단발, 탄은100ms/프레임 반복을 제안한다.

| 용도 | 파일 | 구성 |
| --- | --- | --- |
| 뱀처럼 이동 | `slither/sheet-transparent.png` | 4열×4행. 위에서부터 down, left, right, up. 방향마다 4프레임 반복 |
| 완전히 엎드려 이동 | `prone-slither/sheet-transparent.png` | 4열×4행. down, left, right, up. 머리·목·배를 지면에 붙인 방향별4프레임 |
| 왼쪽 발사 | `shoot-left/sheet-transparent.png` | 2열×3행, 좌→우·위→아래 6프레임. 준비→충전→입 벌림→발사→반동→복귀 |
| 날아가는 탄 | `projectile-left/sheet-transparent.png` | 2열×2행, 4프레임 반복. 밝은 핵이 왼쪽, 꼬리가 오른쪽 |

각 폴더에 분리 PNG, GIF 미리보기, 내장 이미지 생성에 사용한 `prompt.txt`가 있다. 보라색/연보라 몸통, 다수의 녹색 눈, 송곳니·큰 발톱은 기존 바론 외형을 이어간다. 탄의 청록빛 핵과 보라색 꼬리는 이번 시각 제안이며 공격 속성·스탯을 확정하지 않는다.

### 추가 요구: 머리까지 완전히 낮춘 이동

사용자 추가 지시(2026-09-12): 목을 세운 코브라 자세뿐 아니라 **얼굴까지 내리고 온몸을 길게 눕혀 기어가는 모션**도 필요하다. 추격 중 낮게 기어가는 구간에는 `prone-slither`를 사용한다. 살아 있는 이동 자세이며 쓰러짐/사망이 아니다. 앞의 `slither`는 목을 세운 기존 선택지로 보존한다.

`prone-slither`는256×256 셀, **지면 몸통 중심 피벗 `(128,128)`**,160ms×4 반복이다. 이 동작에 한해 action별 `pivot`을 사용하고 전역 `body_pivot=(128,240)`을 그대로 적용하지 않는다. 옆모습은 길고 납작하고 상하 방향은 길이가 화면 세로로 이어지는 것이 정상이다. 방향별 bbox를 따로 확대해서 동일한 높이로 만들지 않는다.

발사는 기존 목을 세운 `shoot-left`를 유지한다. 엎드림→일어섬 전환 애니메이션은 포함하지 않았다. 씬에서 자세를 바꿀 때는 이동을 멈추고 두 동작의 지면 위치를 맞춰 전환하거나, 별도 전환 연출을 구현한다. 서로 다른 피벗을 무시해 캐릭터가 위아래로 튀지 않게 한다.

## 추격씬에서 연결하는 방법

1. 플레이어 일행이 바론을 추격하는 장면에서 진행 방향에 맞는 이동 행을 재생한다. S자 굴곡이 바뀌는 **제자리 애니메이션**이므로 실제 월드 좌표 이동은 엔진이 별도로 처리한다.
2. 바론이 화면 왼쪽으로 공격할 때 잠시 이동 모션을 `shoot-left`로 전환한다. 이동 방향과 발사 방향은 별도 상태로 관리하며, 필요하면 발사 중 이동을 멈춘다. 이번 시트는 왼쪽을 보며 쏘는 자세이지 오른쪽을 보며 뒤로 쏘는 자세가 아니다.
3. 발사 시트의 **4번째 프레임(0-based index 3)에 진입할 때 딱 한 번** 입 앞에서 탄을 생성한다. 탄은 분리된 `projectile-left`를 반복하며 화면 왼쪽으로 이동시킨다. 해당 프레임이 유지되는 매 tick마다 탄을 만들지 않는다.
   `mouth_spawn=(44,94)`는 발사 셀 좌상단 기준이다. 본체 피벗의 월드 좌표가 `(x,y)`, 표시 배율이 `s`라면 탄의 중심 생성 지점은 `(x-84*s, y-146*s)`다. 이동과 탄 충돌 위치를 투명 여백 기준으로 계산하지 않는다.
4. 발사 6프레임을 한 번만 재생한 뒤 이동 방향의 slither로 복귀한다. 정지 중에는 그 방향의 첫 프레임을 유지해도 된다. GIF는 확인용이며 게임에서는 PNG 프레임과 manifest의 시간을 사용한다.
5. 바론 본체는 보스 크기를 유지한다. 일반 적의 64×64 정규화 경로에 넣지 않고, 이동과 발사에 같은 표시 배율·앵커를 사용한다. 프레임마다 bbox를 다시 맞추거나 독립 확대하면 크기가 출렁인다. `imageSmoothingEnabled=false`와 정수 배율을 사용한다.
