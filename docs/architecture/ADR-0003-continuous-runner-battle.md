# 연속 달리기 전투의 수명주기 소유권

BUILD310은 토리이의 이동·점프·베기·제동을 기존 `runner-core`와 `runner-render`에서 재사용하고, 피해·재도전·보상·저장은 기존 `Battle`에 남긴다. 독립 미니게임으로 승패/세이브를 복제하면 강화 상태와 중단 경로가 갈라지므로, 화면상의 연속성만 `preemptiveMode()`·`preserveFinalFrame`·`skipVictoryText`의 선택적 계약으로 연결했다. 일반 전투의 기본 흐름은 변경하지 않으며, 다음 기믹도 입력 물리를 복제하지 않고 [구간 설정과 연결 규칙](../../design/gdd/malzahar-runner.md)을 따른다.

`runnerState`는 진입 때 복제하여 필드 러너와 전투가 동시에 움직이지 않게 하고, 반격 성공 횟수와 잔여 체력을 구분한다. 종료는 현재 동작/착지→공통 제동→정지→마지막 그림 보존→암전→맵 이동→명시적인 필드 BGM→페이드인 순서다. 컷신 중 `changeMap`은 자동 BGM 재생을 하지 않으므로 도착 곡은 후속 노드가 소유한다. 공통 옵션은 완료된 전투만 마지막 그림을 보존하며, 실패/재도전은 새 러너 상태를 만든다.
