# 강퇴폐기창고 조우 연출

2026-09-13 · BUILD119 · Established: 사용자 대사·창고 조우·HP66 전투.

`storage_viewer`는 요청한 첫 대화와 공개/춤 연출을 맡는다. 기존 `battleEntry` 이후 정규 `battle` 노드로 들어가며 지정곡을 재생한다. 후속 사용자 요청으로 HP66 및 전용 패턴 전투가 추가되었으므로 최초 대치 화면 초안은 연결하지 않는다.

전투는 기존 `Battle`의 공격/아이템·회피·다운/부활·패배/재도전 규칙을 그대로 사용한다. 이기면 `storage_viewer_defeated`가 서고 창고·바람으로 돌아간다. 악질맨 "... 아 안돼" → 억빠맨 "넌니애미따라가라" → 기존 thud·붉은 강퇴! 도장·새 knockdown 모션 뒤 누운 정지 그림으로 남는다. 다시 말 걸면 나레이션 "강퇴당했다"만 표시한다. 재방문에도 조건부 누운 NPC가 복원된다.

`storage_viewer_intro_seen`은 마지막 대사를 마친 사실만 나타내며 승리 플래그가 아니다. 첫 연출/전투 중 타이틀로 중단하면 임시 위치를 저장하지 않는다. 승리 복귀 후 기존 `runScript` 완료 저장이 안전한 필드 위치와 플래그를 함께 기록한다. 미승리 상태에서 intro 플래그만 가진 경우 C는 긴 개그를 반복하지 않고 진입 연출·전투로 간다. Q에는 기존 창고 맵 지점만 유지한다.

NPC `idleMotion`은 `CHARACTER_MOTIONS`의 반복 대기 동작이며 `faceOnInteract:false`는 공개 전 뒷모습을 유지한다. `loopCharacterMotion`의 `flipEvery`와 `pop`은 컷신 대사와 동시에 춤을 반전/통통 튀게 한다. 기존 일회성 `motion`은 컷신 waiter가, 반복 동작은 NPC update가 갱신해 중복 재생하지 않는다.

## 전용 전투 패턴

`src/battle/viewer-patterns.js`는 기존 적 패턴을 호출하지 않고 문자·새 생성 PNG로 일곱 타임라인을 등록한다. HP66, 피해11, 보상666원, 회피 상자216×156은 `src/data/enemies.js`에 있다. `STATE_FROM_FLAGS`는 승리 플래그에서666원을 유도한다.

| 패턴 | 예고와 회피 |
| --- | --- |
| `viewer_eom` | 0.6초 세로 줄 예고 뒤 큰 엄/준/식 낙하. 다른 줄로 이동한다. |
| `viewer_names` | 0.55초 두 가로 줄 예고 뒤 닉네임이 양쪽에서 글자씩 진입한다. 매 번 바뀌는 빈 줄로 이동한다. |
| `viewer_rock` | 착지 자리 예고·포물선 바위·3초 붉어지는 퓨즈 뒤 두 겹 파편. 바위에서 거리를 두고 파편 사이를 통과한다. |
| `viewer_explain` | 상단 빈 칸이 바뀌는 해명 문자 비. 0.4초 예고를 읽고 빈 열을 찾는다. |
| `viewer_chicken` | 0.55초 현재 하트 위치를 예고하고 닭3개 부채꼴 조준탄. 예고 뒤 자리를 옮긴다. |
| `viewer_breath` | 오른쪽 위/아래 입구를 예고하고 2기 문자를 부채꼴로 연속 분사한다. 분사 방향과 반대쪽으로 이동한다. |
| `viewer_timeout` | 0.65초 예고된 차단 아이콘이 제한된 회전 속도로 추격하고 사라진다. 아이콘을 크게 돌아 따돌린다. |

기존 Battle API의 이미지 프리로드와 패턴 `api.say`를 연결해 바위/차단 대사를 회피 영역 위에 표시한다. 문자 판정은 글자 사각형, PNG는 그림 크기 안쪽이며 원본형태를 바꾸는 기존 몹 재사용은 없다.

검증: `tests/unit/storage-viewer.test.mjs`, `tests/playtest/storage-viewer.mjs`. 경고/네·아니오·X, 첫 C/뒷모습, 공개/박수/음악, 중간 말 끊기, 춤/반전, 표준 전투 진입을 변경 구간만 확인한다. 전투 패턴·승패 검증은 전투 테스트가 맡는다.
