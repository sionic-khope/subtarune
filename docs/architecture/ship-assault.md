# 영클 전함 습격 표시와 진행 경계

2026-09-13 · Accepted · `captain_attack.md`.

습격은 새 전투가 아니라 선장실과 바다를 오가는 컷신이다. 기존 `ScriptRunner`/`TextBox`가 대사·음악·페이드·이동을 소유하고, `ShipAssault`는 반복 충격·먼지·바다의 두 선박·폭발·접현 다리만 표시한다. 수치·이미지 경로·선박 상대 부착점은 `src/data/ship-assault.js`에 둔다. 기존 바다·항적·폭발을 사용하며 피해·아이템·승패 규칙은 만들지 않는다.

회상 마지막 줄은 출력 완료0.5초 뒤 끝나고 다음 update에서 습격을 시작한다. 완료 콜백 안에서 다른 러너를 중첩 시작하지 않는다. 회상 완료 저장은 `runMapEnter`에서 새 습격으로 이어지되500원 보상과 과거 회상을 재실행하지 않는다. 타이틀·QA·맵 변경은 활성 습격 러너와 임시 장면을 같이 정리하고 일반 컷신 러너에는 영향을 주지 않는다.

`captain_attack_done` 뒤 `maillard_saloon`의 입장 이벤트가 문 공사를 한 번 실행한다. `maillard_starboard_open`이 타일 교체·문 그림·NPC 퇴장 상태를 함께 복원한다. 새 갑판은 기존 일출 원경의 `animated:false`를 사용한다. 새 전투·다음 사건은 후속 사용자 요청 전까지 추가하지 않는다.
