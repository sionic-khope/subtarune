# 봉인 구체의 읽기 전용 대문 시점

BUILD311의 멀리 있는 대문 공개는 실제 `changeMap`이 아니라 기존 로비 정의와 소품으로 그리는 별도 화면이다. 실제 맵 전환은 파티 복원·입장 이벤트·자동 저장·음악을 함께 바꾸므로, 카메라만 이동하는 이번 요구에는 사용하지 않는다. 구체 방의 좌표와 BGM 시계는 유지한다.

`CastleOrbScene`이 준비→접촉→암전→대문 공개/이동→지직/점등→암전→방 복귀의 시간과 임시 커튼/음원 핸들을 소유한다. 준비 완료가 늦게 도착해도 장면/대사 identity가 달라졌다면 시작하지 않는다. 점등 플래그는 한 번 적용하고 전체 복귀 완료 때 확정한다. 도중 취소는 이번 장면의 플래그만 되돌리며 기존 저장 API의 컷신 중 저장 금지를 우회하지 않는다.

상시 광원/실루엣 그림자와 완료된 오른쪽 봉인은 월드 렌더 훅으로 표시한다. 왼쪽 봉인/전체 대문 개방 조건은 아직 구현하지 않는다. 위치·자산·대사·검증 계약은 [구체 방 기획](../../design/gdd/castle-orb.md)이 소유한다.
