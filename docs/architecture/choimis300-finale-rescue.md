# BUILD300 · 최미스 최종전과 구조의 상태 소유

- Battle은 피해 적용 후1HP 하한과 finalePending/Started/Complete만 소유한다. 일반 행동 경계와 적 패턴 정리 경계에서 전환한다. 다른 적의 사망 규칙은 변경하지 않는다.
- choimis_finale 모드는 대사·손 올림·꽃 모임·60초 공격·4초 자동 충전·명중·연기·변신 해제·추락을 소유한다. 전투 승리는 추락 완료 뒤 공통 경로에 반환한다.
- final-assault 컨트롤러는 상하 조작·C 사격·위협·피격과60초만 소유한다. 명중 수는 시간 종료와 분리하고 최미스 HP를 더 줄이지 않는다.
- 후속 구조는 기존 컷신 DSL 대사와 전용 장면 렌더러로 분리한다. battle 노드 완료 뒤 이어지며 임시 배우/카메라/음악을 정리하고 구조 완료 단계와 라운지로 넘긴다.
- 구조 완료는 choimis_rescued, 라운지 브리핑 완료는 ship_lounge_briefed로 구분한다. 구조 직후와 기존 구조 완료 세이브의 맵 진입은 같은 브리핑 노드를 사용한다. 연출 소유 웃음/동작은 완료·취소·스크립트 교체 시 정리한다.
- 귀환 이후에는 뒤통로를 막고 라운지 내부 상점과 새 NPC 상호작용을 사용한다. 과거 라운지 동선과 상점 영구 강화는 보존한다. 영클 준비 선택지는0.6초 뒤 열리며 네는 ship_invasion_ready만 저장한다. 다음 연출은 아직 구현 범위가 아니다.

검증 경계: 일반/핑크/먹방 막타, 추가 피격 중복, 패배/재시도/타이틀 취소, 실시간60초, 충전0~4초, 구조 종료 후 전원 보행, 저장 재입장, 구매/사용/취소/기존 업그레이드. 승인 증거는 동일 최종 소스 및 커밋에만 유효하다.
