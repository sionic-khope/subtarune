# 마이야르호 연출 화면 분리

2026-09-12, Accepted.

바다 사격은 필드 좌표 대신 화면 좌표로 렌더링한다. 후속 거대 전함 낙하도 같은 바다 화면을 유지해야 하므로, 맵 엔티티나 전투 코드를 확장하지 않고 `MaillardArrival`을 기존 장면 인터페이스(update/draw/dispose)에 맞춘다.

대사·음악·지연·페이드는 `obj5_maillard`의 기존 컷신 노드가 소유한다. 표시 클래스는 그림자·낙하·줌아웃·작은 쥰희·섬 이미지에만 관여하고, 공격·아이템·승패를 수정하지 않는다. `Game`은 이전 컷신 대기자가 풀린 다음 시작하고, 흰 화면 안에서 완료 플래그와 갑판 맵 전환을 수행한다.

새 커스텀 DSL 명령은 필요 없다. 기존 `{action}`이 장면 비트를 선택하며 `{wait}`, `{bgm}`, `{sfx}`, `{shake}`, `{fade}`를 그대로 재사용한다. 타이틀·맵 전환 시 늦은 이미지 로드 완료가 장면을 되살리지 않도록 disposal을 확인한다.
